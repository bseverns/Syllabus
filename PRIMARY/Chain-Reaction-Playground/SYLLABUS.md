# Chain-Reaction Playground

> **PILOT syllabus.** Start with the shared [K–2 operating model](../K2-PILOT-OPERATING-MODEL.md). The direct local source is the legacy [Chain Reaction Mini](../../PRIMARY/SMM/archive/Chain%20Reaction%20Mini.doc.docx), written for ages 13–16 with electronics. This pilot keeps only the large-part, visible cause-and-effect logic.

## Course snapshot

- **Promise:** learners connect ramps, balls, blocks, levers, and loose parts so one action causes the next, then test, reset, and improve the chain.
- **Group / staffing:** 8–12 learners; one lead, with an assistant recommended for full-group chains or learners needing close physical support.
- **Final share:** a group chain with at least two connected actions; a reliable two-action chain is a complete success.
- **Community agreement:** *When the chain stops, we find the next thing to test.*

## Materials for 12 learners

**Core tote:** 12 low floor trays or cardboard bases; 24 foam balls; 24 cardboard ramps; blocks or large DUPLO/LEGO; 24 paper tubes; 24 cups; painter's tape; masking tape; domino-sized blocks; fabric scraps; large binder clips held/managed by adults; cardboard wedges; markers; and 12 parking labels.

**Do not use for this pilot:** motors, programming, marbles, small loose parts, sharp hardware, glass, or any material unsuitable for the age group present.

**Prep:** make three reliable starter actions (roll into cup, knock block, slide down ramp); tape a test boundary; keep replacement ramps/balls in the fast-fix bin; stage one intentionally unreliable chain for debugging talk.

## Four-session sequence

### Session 1 — One cause, one effect

**Target:** make one action reliably cause another visible action.
**Prompt:** *What can roll, tip, slide, drop, or knock?*
**Demo:** roll a foam ball down a ramp into a cup, then reset it the same way.
**Build/play:** learners choose one starter action and repeat it until it works twice.
**Evidence / parking:** facilitator notes `I start with ___; then ___.` Learners park parts in labeled trays.

### Session 2 — Join two actions

**Target:** connect two working actions.
**Prompt:** *What needs to touch what?*
**Demo:** connect a ramp to a block knock-down; test slowly, then at normal speed.
**Build/play:** pairs connect two actions using one bridge material; adult limits each pair to one change at a time.
**Evidence / parking:** mark one successful connection with a tape flag or photo; name the first place it broke.

### Session 3 — Make a group chain

**Target:** contribute one dependable link to a shared chain.
**Prompt:** *How can my action help the next builder?*
**Demo:** join two prepared links and show the reset order.
**Build/play:** each learner/pair owns one tray-sized link; facilitator connects only links that have worked twice in a row.
**Evidence / parking:** draw or point to `my link`; record the reset job for that link.

### Session 4 — Test, change, perform

**Target:** run the chain, identify one failure point, and improve it.
**Prompt:** *What should we change so the next action can happen?*
**Demo:** model a calm reset after a stop: name the link, change one thing, run only that section.
**Build/play:** test links in order, repair one variable at a time, then run the full chain for visitors or another group.
**Evidence / share:** capture a before/after note and celebrate the chain's working connections, not only a perfect final run.

## Safety, access, and failure backup

Keep chains low, contained in trays or a marked floor area, and away from exits. Learners may be builders, testers, reset callers, observers, or documentation helpers. Do not require fast reactions or a full-chain performance.

If the group chain becomes too complex, separate it into two reliable mini chains and run them one after the other. Reliability and explanation beat scale.

## Assessment and public description

Use the shared four look-fors, plus: **the learner predicts, tests, or changes one link after observing an effect.**

**Partner description:** A fully unplugged engineering-play workshop where young learners turn ramps, blocks, and loose parts into shared cause-and-effect machines.

Record: which starter actions worked most reliably, how much floor/tray space each link needed, whether reset jobs helped the group recover, and what material created the most avoidable failures.
