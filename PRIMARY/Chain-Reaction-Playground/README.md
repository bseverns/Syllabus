# Chain-Reaction Playground

A four-session, fully unplugged pilot workshop for Pre-K–Grade 2. Learners use large ramps, balls, blocks, and loose parts to create shared cause-and-effect machines.

> **PILOT READY:** the package is complete enough for a lead facilitator to deliver. It remains off the public-ready shelf until one real delivery confirms starter actions, materials, safety/access needs, and revision notes.

## Quick start

1. Read [SYLLABUS.md](SYLLABUS.md) and the [K–2 operating model](../K2-PILOT-OPERATING-MODEL.md).
2. Test three large-part starter actions twice each and stage them in low floor trays.
3. Mark the test boundary and keep replacement ramps/balls in a fast-fix bin.
4. Run four 60-minute sessions; preserve one before/after repair note from the final chain.
