# Code With Your Body

A four-session, fully unplugged pilot workshop for Pre-K–Grade 2. Learners use picture commands, movement or tabletop routes, and debugging talk to make instructions clearer.

> **PILOT READY:** the package is complete enough for a lead facilitator to deliver. It remains off the public-ready shelf until one real delivery confirms timing, command cards, accessibility routes, and revision notes.

## Quick start

1. Read [SYLLABUS.md](SYLLABUS.md) and the [K–2 operating model](../K2-PILOT-OPERATING-MODEL.md).
2. Tape a short, wide path and prepare an equivalent tabletop-token route.
3. Pick a command/action menu that works for the actual learners before Session 1.
4. Run four 60-minute sessions; preserve one before/after debug example per pair.
