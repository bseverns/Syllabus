# Course visual

## Flap creature

- **File:** [flap-creature.svg](flap-creature.svg)
- **Creator and source:** original illustration created for this repository with Hermes Agent, not copied from an external image.
- **License:** repository default for curriculum media, [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); see [repository license](../../../LICENSE.md).
- **Alt text:** A cardboard creature with a raised wing attached to its body by a paper fastener, allowing the wing to pivot.
- **Use:** Sessions 1 of Machines That Move and Tiny Machines; invite learners to find the fixed body, movable wing, and pivot before the live demonstration.
- **Scope:** an illustrative idea, not an assembly plan or permission to handle sharp tools or small parts. Follow each course’s adult preparation and safety guidance; tape hinges are an alternative.
