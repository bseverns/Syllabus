# Machines That Move

A four-session Grades 3–5 pilot studio for mechanisms, automata, moving sculptures, and playable machines.

> **PILOT READY:** a lead facilitator can deliver this package as written. Keep it off the public-ready shelf until one delivery confirms build pacing, material quantities, tool safety, and the final share.

## Quick start

1. Read [SYLLABUS.md](SYLLABUS.md).
2. Pre-build one working mechanism and one intentionally flawed version for each session.
3. Pre-punch cardboard where a pivot or axle is required; keep sharp cutting and dowel preparation adult-managed.
4. Treat motors and 3D-printed components as enrichment, not prerequisites.
