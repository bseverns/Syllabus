# Template Project Architecture

## Suggested screens

- Title
- Instructions
- Stage1
- Stage2
- FinalChallenge
- Win
- GameOver

## Suggested sprite roles

- Player
- Enemy or Hazard
- Collectible or Goal
- PowerUp
- Boss or Final Challenge
- UI text or buttons

## One important rule

Try to keep one main job per sprite. Projects stay easier to debug when one sprite is not secretly doing six unrelated things.
