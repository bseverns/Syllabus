# Session 09: Playtest Lab + Bug Hunt

**Mission:** use real player feedback to find confusing spots and bugs.

## Demo

- how to write a useful bug card
- difference between "I do not like it" and "I could not tell what to do"

## Build goals

- run at least two playtests
- collect one bug card and one design note
- fix one real issue before the end of class

## Checkpoints

- student can explain one bug clearly
- one change was made because of testing

## Extensions

- A/B test two power-up ideas
- difficulty poll from players
