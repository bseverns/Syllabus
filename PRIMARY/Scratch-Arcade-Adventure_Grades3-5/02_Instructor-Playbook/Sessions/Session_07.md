# Session 07: Boss Battle or Final Challenge Design

**Mission:** build a final challenge that feels different from the earlier game.

## Demo

- boss health variable
- weak point idea
- pattern change after a score or timer threshold

## Build goals

- define what makes the final challenge special
- add boss or final challenge logic
- connect success to the win path

## Checkpoints

- final challenge exists
- player can win it
- challenge is hard but understandable

## Extensions

- second boss phase
- warning text
- dramatic backdrop change
