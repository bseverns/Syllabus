# Session 02: HUD Systems — Score, Health, Energy, Timer

**Mission:** build a clear heads-up display that tells the player how the game works.

## Demo

- make and reset variables
- show how a variable changes during play
- explain that a HUD is part of game design, not decoration

## Build goals

- choose at least two variables
- make sure both reset correctly on green flag
- connect one variable to a real gameplay rule

## Checkpoints

- two working variables
- variables reset correctly
- player can explain what each variable means

## Extensions

- energy bar idea
- countdown timer
- collectible counter for stage clear
