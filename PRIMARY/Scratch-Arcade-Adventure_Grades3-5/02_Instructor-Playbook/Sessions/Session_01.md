# Session 01: Pick Your Arcade Idea + Rebuild the Core Loop

**Mission:** choose a game concept and get a working player, goal, and fail state started.

## Teacher prep

- prepare 3 to 4 example genres:
  - maze chase
  - dodge survival
  - collection race
  - platform-lite obstacle run

## Agenda (60 minutes)

**Launch:** explain that this class is for students ready to build bigger systems.  
**Demo:** show a tiny loop: move -> collect -> lose health -> restart.  
**Sprint A:** students choose a concept and draw a one-screen pitch.  
**Sprint B:** create player + one goal + one hazard.  
**Sprint C:** test whether the game can be won or lost in any way.

## Checkpoints

- project has a name
- player moves
- game has one goal and one danger
