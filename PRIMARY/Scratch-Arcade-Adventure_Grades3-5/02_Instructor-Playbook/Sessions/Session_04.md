# Session 04: Power-Ups and Temporary Abilities

**Mission:** create a power-up that changes the rules for a short time.

## Demo

- collect star -> speed boost
- collect shield -> ignore enemy damage briefly
- collect key -> unlock special door

## Build goals

- one power-up sprite
- one temporary or special effect
- clear visual cue when power mode is on

## Checkpoints

- power-up can be collected
- power-up changes gameplay
- the effect turns off correctly

## Extensions

- random spawn
- sound cue
- power-up meter
