# Scratch Arcade Adventure Studio (Grades 3–5)

A 12-week, 1-hour/week Scratch (MIT) course for grades 3–5 built for students who already know the basics of Scratch and are ready for a bigger game-design challenge.

This course is a standalone packet with its own identity. It assumes students can already:

- add sprites and backdrops
- use events, loops, and simple conditionals
- make basic movement
- save and reopen projects

## What students make

A polished arcade-style Scratch game with:

- a title screen and instructions
- a heads-up display using variables
- at least one enemy pattern
- at least one power-up
- multiple challenge areas, waves, or rooms
- a final challenge or boss-style moment
- clear win and game-over states

## Course personality

This course emphasizes:

- game systems, not just decoration
- fair challenge and readable rules
- debugging as part of design
- playtesting as kindness
- polish that helps the player, not polish for its own sake

## Capstone requirement

Students publish a Scratch game that includes:

- a clear beginning
- a HUD with at least two variables
- one power-up or temporary ability
- one meaningful enemy or hazard pattern
- three stages, waves, or challenge sections
- one final challenge or boss moment
- a win screen and restart path
