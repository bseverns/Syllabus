# Starter Project Build Recipe

## In 10 teacher minutes

1. Create backdrops: `Title`, `Stage1`, `Stage2`, `FinalChallenge`, `Win`, `GameOver`.
2. Add variables: `score`, `health`, `stage`, `gameState`.
3. Add a Player sprite with basic movement gated by `gameState = play`.
4. Add a start button that:
   - sets starting values
   - switches to `Stage1`
   - broadcasts `start game`
5. Add simple win and game-over screens.

## Why this helps

It keeps the class focused on new systems instead of spending the whole first day rebuilding the same menu and reset flow.
