# Public Course Overview: Build Your Block

Course slug: build_your_block
Title: Build Your Block: A Neighborhood Makers Lab
Short title: Build Your Block
UI Level: elementary
Grade band: 3-7
Duration: 7 weeks
Session count: 28
Typical session length: 2.5 hours, 4 meetings per week
Subject tags: maker, engineering, art, neighborhood, circuits, coding, design, public showcase

Summary:
Build Your Block is a neighborhood-rooted maker intensive where students build with light, motion, sound, sensing, simple coding, cardboard construction, and everyday materials. From the first week, they begin imagining projects for real people and real places. Early sessions build toolkit confidence quickly. Later sessions focus on prototype, revision, user testing, station design, and public showcase.

Who this is for:
- Students in grades 3-7 with mixed prior experience
- Partner sites that want hands-on making with public purpose
- Programs that need low-floor, high-ceiling work that can still adapt to uneven staffing or tool access

What students do:
- Build visible projects every week
- Practice troubleshooting, revision, explanation, and documentation
- Connect making to neighborhood memory, need, joy, and future imagination
- Develop and present a capstone project for families, peers, staff, or community visitors

Core outcomes:
- Use basic maker materials and tools safely
- Explain simple systems in plain language
- Test and revise after failure
- Document process in writing, speech, diagrams, photos, or audio
- Connect invention to neighborhood life
- Share finished work with an audience

Studio rhythm:
- launch / prompt
- short demo
- build sprint 1
- break / reset
- build sprint 2
- share / document / park

Implementation notes:
- Mixed-age adaptations are built into the weekly plans.
- One coding platform is enough for the full course.
- The course can run in a lower-resource version with cardboard, paper, tape, markers, LEDs, simple motors, and limited device access.
- The public showcase is part of the curriculum, not an extra event.
