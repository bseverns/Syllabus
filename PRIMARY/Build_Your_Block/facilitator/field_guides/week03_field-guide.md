# Week 3 Field Guide

## Focus
Move from many ideas to one chosen project with a real audience, a real purpose, and a first mockup.

## What absolutely must happen this week
- Every student or team chooses a project direction.
- Audience and purpose get named clearly.
- A mockup or first low-tech test exists.

## What can be cut if time slips
- extra backup ideas after one strong choice is clear
- over-polished mockups
- long written planning if drawing or speaking will do

## Top 3 materials to prep first
- capstone planners
- cardboard and mockup materials
- project bins, status cards, and labels

## Top 3 failure points to watch for
- vague project statements
- endless restarting
- teams leaving the week without a first prototype target

## Room-shape advice
- keep conference space quiet enough for short check-ins
- give mockup-building table space, not only writing space
- keep project parking visible and ready

## Mixed-age caution
Younger students need concrete audience language and a buildable first step. Older/faster students should justify tradeoffs or first-use logic.

## Fatigue / reset note
If planning talk gets mushy, send students back to cardboard, labels, and mockups. Talking alone will not save the week.

## What to photograph or capture
- one mockup or storyboard
- one project statement with audience
- one first-prototype goal

## What students should have by the end of the week
- one chosen project
- a named audience and purpose
- a smallest version worth testing first
