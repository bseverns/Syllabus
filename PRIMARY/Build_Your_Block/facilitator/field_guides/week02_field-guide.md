# Week 2 Field Guide

## Focus
Keep interaction week coherent. Use sound, sensing, and code to narrow project direction, not to open unlimited branches.

## What absolutely must happen this week
- Students make or test one clear interaction sample.
- The room stays on one coding platform, one sound path, and one sensing path.
- Every student or team ends with one likely project direction.

## What can be cut if time slips
- extra platform options
- deep independent coding variations
- extra interaction branches after one sample already works

## Top 3 materials to prep first
- one sound pathway
- one sensing or trigger pathway
- one coding platform with devices or shared access ready

## Top 3 failure points to watch for
- platform shopping
- modality overload
- no clear weekly deliverable by Friday

## Room-shape advice
- zone sound work carefully
- keep coding in one visible area or one shared pattern
- post the weekly deliverable where everyone can see it

## Mixed-age caution
Younger students need one obvious trigger and one obvious response. Older/faster students should compare interaction pathways or improve user flow, not add random features.

## Fatigue / reset note
Use the break block to close extra tool branches and relaunch the one thing that matters: one interaction sample plus one likely project direction.

## What to photograph or capture
- one interaction sample in use
- one input/output or code sketch
- one “most likely project” note per team

## What students should have by the end of the week
- one clear interaction idea they can explain
- one likely project direction
- a stronger sense of audience and visitor action
