# Materials Setup Checklist

## Before class
- tables cleared
- consumables portioned
- kits counted
- batteries checked
- glue guns plugged in only when needed
- demo sample working
- projector / screen tested if using digital tools

## During class
- materials runners appointed if helpful
- sharp tools monitored
- broken parts isolated quickly
- photo documentation captured

## After class
- reusable items sorted
- battery-powered tools turned off
- project shelf labeled
- notes made for next session
