# Staffing and Scheduling

## Recommended staffing ratio
- up to 12 students: 1 lead facilitator can work, though support helps
- 12–18 students: 1 lead + 1 assistant strongly recommended
- above 18 students: split into stations or add another adult

## Time models

### Model A — 2-hour weekly session
- Arrival / challenge — 15 min
- Demo — 20 min
- Build — 60 min
- Share / cleanup / reflection — 25 min

### Model B — two 75–90 minute sessions per week
Session 1:
- Warm-up + demo + build start

Session 2:
- build continuation + reflection + documentation

## Prep rhythm for staff
- pre-sort materials the day before
- test all electronics ahead of class
- keep a “fast fix” bin for repairs
- pre-print prompts or labels for project weeks
