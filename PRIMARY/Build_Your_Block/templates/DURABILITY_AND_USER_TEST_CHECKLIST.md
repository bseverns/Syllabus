# Durability and User Test Checklist

Project name:

Date:

Tester:

## Physical sturdiness

- [ ] The project body stays together when moved or touched.
- [ ] Loose parts are attached securely.
- [ ] Edges, handles, and touch points feel safe.

## Wiring and attachment stability

- [ ] Wires, tape paths, batteries, and clips stay in place during use.
- [ ] The project still works after repeated tries.
- [ ] Connections are easy to find and fix if something comes loose.

## Clarity of interaction

- [ ] A visitor can tell where to stand, touch, press, or look.
- [ ] Labels or cues match what the project actually does.
- [ ] The main action is easy to notice.

## Reset routine

- [ ] The project can be reset between visitors.
- [ ] The team can explain the reset in a few short steps.
- [ ] Needed reset materials are nearby.

## Public use

- [ ] A visitor understands what to do without a long explanation.
- [ ] The visitor understands who the project is for or what it is about.
- [ ] The visitor can describe what happened after using it.

## Repeated use

- [ ] The project survives repeated use.
- [ ] The project still works after 3 tries.
- [ ] The project still works after 5 tries.

## Showcase readiness

- [ ] The station is easy to approach.
- [ ] The labels help instead of confuse.
- [ ] The team can host and reset the project calmly.
