# 8-Day Age-Band Stack Adaptation

This adaptation tunes **Build Your Block** for three separate groups that each meet for **8 days**:

- **K–2:** *Our Block Comes Alive*
- **Grades 3–4:** *Block Inventions*
- **Grades 5–7:** *Neighborhood Prototype Studio*

The full Build Your Block course remains a 7-week intensive. This folder is the deployable version for a program where the same neighborhood-maker spine needs to serve three age-disparate groups.

## Core idea

Do not teach one course three identical ways. Teach one shared neighborhood studio stack at three depths.

- K–2 builds the **sensory / symbolic layer**: places, characters, lights, motion, sound, memory, and belonging.
- Grades 3–4 builds the **working interaction layer**: simple input/output inventions that visitors can understand.
- Grades 5–7 builds the **public prototype layer**: tested stations with purpose, user flow, reset logic, and explanation.

The shared spine stays the same:

1. Welcome and notice the block
2. Build with light
3. Build with motion
4. Build with sound, sensing, or interaction
5. Choose and mock up a project
6. Prototype
7. Test, clarify, and reinforce
8. Share, reflect, and archive

## What must stay true

Every age band should still feel like Build Your Block:

- students make visible things quickly
- projects connect to place, people, joy, memory, need, or future possibility
- technical effects serve meaning and audience
- testing and revision matter
- students explain their work in age-appropriate ways
- the final day includes some form of publicness

## How to use these files

- Start with [SHARED_8_DAY_SPINE.md](SHARED_8_DAY_SPINE.md).
- Use the age-band file for the group you are teaching.
- Use [MATERIALS_BY_AGE_BAND.md](MATERIALS_BY_AGE_BAND.md) to stage materials.
- Use [SHOWCASE_STACK_MODEL.md](SHOWCASE_STACK_MODEL.md) if the three groups will contribute to one shared exhibition.
- Use the `classhub_import/` files if importing the age-band versions into ClassHub.
- Use the adapted templates in `templates/` when the main course templates are too text-heavy for the shorter format.

## Design stance

Same course soul. Different cognitive load.

- K–2 asks: **What can we make that belongs here?**
- Grades 3–4 asks: **How can we make something that works for someone?**
- Grades 5–7 asks: **How can we design, test, and explain a public prototype?**
