## Design changes

The full 7-week Build Your Block intensive remains intact.

This adaptation adds a deployable 8-day format for three age-disparate groups:

- K–2: shared sensory neighborhood installation
- Grades 3–4: small team working block inventions
- Grades 5–7: public prototype stations

## Core tuning

- preserved the Build Your Block spine
- shifted capstone language to age-appropriate forms
- reduced cognitive load for K–2
- made grades 3–4 the main working-invention band
- made grades 5–7 accountable for public use, user testing, reset, and station design
- added ClassHub-ready 8-session teacher plans
