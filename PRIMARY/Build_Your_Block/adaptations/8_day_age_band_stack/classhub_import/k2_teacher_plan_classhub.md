# Teacher Session Plan: Build Your Block K–2: Our Block Comes Alive

Course slug: build_your_block_k2
Grade level: K-2
Session length: 2.5 hours
Total sessions: 8
UI Level: elementary

Use `Session NN: Title` headings exactly so ClassHub syllabus ingest can parse this file.

All sessions follow the same studio rhythm:
- launch / prompt
- short demo
- build sprint 1
- break / reset
- build sprint 2
- share / document / park

Protect the final 20–25 minutes for documentation, cleanup, and project parking.

# Session 01: Welcome to Our Block

Mission: Launch routines, make a first object, and name something that belongs on the block.
Lesson slug (for course.yaml): s01-welcome-to-our-block

Teacher prep
- Prepare project parking spots.
- Pre-cut simple shapes or tags.
- Stage one complete example.

Materials
- cardstock or cardboard
- markers and tape
- optional one-light demo materials

Checkpoints
- Students make one first object.
- Students practice parking and cleanup.
- Students name one place, person, sound, animal, or feeling for the block.

Common stuck points + fixes
- Too much abstraction -> use pictures and objects.
- Slow start -> offer three concrete choices.
- Cleanup drift -> rehearse parking with one sample project.

Documentation / archive
- Photo plus dictated sentence: I made __. It belongs because __.

# Session 02: What Should Glow?

Mission: Use light to show welcome, memory, safety, or wonder.
Lesson slug (for course.yaml): s02-what-should-glow

Teacher prep
- Pre-test LEDs and batteries if used.
- Prepare simple light templates.

Materials
- paper circuit supplies or planned-light cards
- cardboard
- markers
- tape

Checkpoints
- Students choose where light belongs.
- Students make or mark one glowing element.

Common stuck points + fixes
- Circuit frustration -> switch to planned-light drawing or guided table build.
- Decoration takes over -> ask where the light goes first.

Documentation / archive
- Pointing label or photo: Light goes here.

# Session 03: What Moves on the Block?

Mission: Explore motion as behavior through creatures, vehicles, helpers, or weather.
Lesson slug (for course.yaml): s03-what-moves-on-the-block

Teacher prep
- Mark one test lane.
- Pre-test motors if used.

Materials
- motors and battery packs or hand-motion materials
- cardboard
- tape
- wheels or wobble parts

Checkpoints
- Students make one moving or motion-planned object.
- Students test in short turns.

Common stuck points + fixes
- Motion chaos -> park all moving builds and restart with two test turns.
- Motor frustration -> use hand-powered motion or teacher-assisted motor station.

Documentation / archive
- Student says or records: It moves like __.

# Session 04: Touch, Listen, Try

Mission: Make a simple cause/effect object or invitation.
Lesson slug (for course.yaml): s04-touch-listen-try

Teacher prep
- Choose one interaction path only.
- Prepare picture cue examples.

Materials
- sound makers or Makey Makey/littleBits if available
- cardboard
- labels
- markers

Checkpoints
- Students make one touch/listen/look invitation.
- Students can show another person what to do.

Common stuck points + fixes
- Too many options -> narrow to touch here/listen here/look here.
- Sound chaos -> test by table.

Documentation / archive
- Short video/photo of the action.

# Session 05: Choose a Piece for the Block

Mission: Choose a final contribution to the shared neighborhood installation.
Lesson slug (for course.yaml): s05-choose-a-piece-for-the-block

Teacher prep
- Prepare project starter cards.
- Set up shared block base or table plan.

Materials
- cardboard
- paper
- markers
- tape
- student pieces from prior days

Checkpoints
- Students choose a place/helper/sign/creature/light/sound/dream piece.
- Students begin a rough version.

Common stuck points + fixes
- Indecision -> offer starter choices.
- Overbuilding -> ask what belongs first.

Documentation / archive
- I am making __ for our block.

# Session 06: Build the Final Piece

Mission: Build a final contribution with one clear action, image, or story.
Lesson slug (for course.yaml): s06-build-the-final-piece

Teacher prep
- Prepare reinforcement supplies.
- Set clear project parking zones.

Materials
- chosen project materials
- tape/glue
- labels
- optional electronics

Checkpoints
- Students can place their piece in the shared block.
- Students can say what it is.

Common stuck points + fixes
- Fragile builds -> add cardboard backer or tape base.
- Too many loose parts -> simplify to one main piece.

Documentation / archive
- Photo before adding to installation.

# Session 07: Try It With a Friend

Mission: Test whether someone else understands or enjoys the piece.
Lesson slug (for course.yaml): s07-try-it-with-a-friend

Teacher prep
- Prepare arrows, picture labels, and repair materials.

Materials
- labels
- markers
- tape
- repair supplies

Checkpoints
- Students show a friend their piece.
- Students make one clarity or strength change.

Common stuck points + fixes
- Friend does not know what to do -> add an arrow or picture cue.
- Piece breaks -> treat repair as the build goal.

Documentation / archive
- I changed __.

# Session 08: Our Block Comes Alive Showcase

Mission: Install, share, reflect, and archive the shared block.
Lesson slug (for course.yaml): s08-our-block-comes-alive-showcase

Teacher prep
- Set up shared display area.
- Prepare reflection sentence cards.

Materials
- finished pieces
- labels
- camera
- reflection cards

Checkpoints
- Students share their contribution.
- Students help clean and archive.

Common stuck points + fixes
- Showcase excitement swallows reflection -> do one-sentence reflection before teardown.
- Students freeze -> allow pointing and adult dictation.

Documentation / archive
- Photo with piece plus dictated sentence.
