# Teacher Session Plan: Build Your Block Grades 3–4: Block Inventions

Course slug: build_your_block_grades3_4
Grade level: 3rd-4th
Session length: 2.5 hours
Total sessions: 8
UI Level: elementary

Use `Session NN: Title` headings exactly so ClassHub syllabus ingest can parse this file.

All sessions follow the same studio rhythm:
- launch / prompt
- short demo
- build sprint 1
- break / reset
- build sprint 2
- share / document / park

Protect the final 20–25 minutes for documentation, cleanup, and project parking.

# Session 01: Maker Studio Welcome and Block Sparks

Mission: Launch routines, make a first light build, and collect project sparks.
Lesson slug (for course.yaml): s01-maker-studio-welcome-and-block-sparks

Teacher prep
- Stage paper circuit materials.
- Prepare block-spark board.

Materials
- LEDs/coin cells/copper tape
- cardstock
- markers
- tape

Checkpoints
- One first working build.
- Two or three project sparks per student/team.

Common stuck points + fixes
- Circuit frustration -> model battery/LED check aloud.
- Perfectionism -> praise working function first.

Documentation / archive
- Photo + project spark notes.

# Session 02: Light-Up Signs and Signals

Mission: Use light with a job: signal, welcome, memory, warning, or celebration.
Lesson slug (for course.yaml): s02-light-up-signs-and-signals

Teacher prep
- Pre-test LEDs and batteries.
- Prepare switch examples.

Materials
- paper circuit supplies
- cardboard
- markers
- tape

Checkpoints
- One light object with purpose.
- Student can identify battery/path/light/switch.

Common stuck points + fixes
- Light as decoration only -> ask who needs to see it and why.
- Broken circuit -> troubleshoot power, orientation, connection.

Documentation / archive
- Circuit photo or labeled diagram.

# Session 03: Motion With a Job

Mission: Build motion that communicates behavior or purpose.
Lesson slug (for course.yaml): s03-motion-with-a-job

Teacher prep
- Mark motion test lane.
- Pre-test motors.

Materials
- motors/battery packs
- cardboard
- wheels/weights
- tape

Checkpoints
- One motion build.
- One tested change.

Common stuck points + fixes
- Motion chaos -> short test turns.
- Object won't move -> change weight, surface, or attachment.

Documentation / archive
- What changed / what happened note.

# Session 04: Input and Output

Mission: Build one clear cause/effect interaction.
Lesson slug (for course.yaml): s04-input-and-output

Teacher prep
- Choose one interaction technology path.
- Prepare input/output chart.

Materials
- buttons/touch points/Makey Makey/littleBits/Scratch or SPIKE
- labels
- cardboard

Checkpoints
- One interaction sample.
- One likely project direction.

Common stuck points + fixes
- Tool sprawl -> close extra branches.
- Visitor confusion -> add touch/press/look label.

Documentation / archive
- Input/output diagram.

# Session 05: Choose and Mock Up the Invention

Mission: Choose a team project and rough it out.
Lesson slug (for course.yaml): s05-choose-and-mock-up-the-invention

Teacher prep
- Print planners.
- Prepare cardboard mockup materials.

Materials
- project planner
- cardboard
- tape
- markers
- index cards

Checkpoints
- Project has audience, purpose, visitor action, and smallest first test.
- Mockup exists.

Common stuck points + fixes
- Idea too big -> shrink to first test.
- No audience -> ask who would use this first.

Documentation / archive
- Project planner + mockup photo.

# Session 06: Prototype Sprint

Mission: Build the smallest working version of the invention.
Lesson slug (for course.yaml): s06-prototype-sprint

Teacher prep
- Set up project bins and status cards.
- Stage must-have materials only.

Materials
- chosen project materials
- electronics as needed
- status cards

Checkpoints
- Core action visible or tested.
- Project parked with next step.

Common stuck points + fixes
- Decoration first -> core action before surfaces.
- Team imbalance -> rotate roles.

Documentation / archive
- Status card: worked/broke/next.

# Session 07: Peer Test and Make It Clear

Mission: Test with peers, repair, label, and prepare for sharing.
Lesson slug (for course.yaml): s07-peer-test-and-make-it-clear

Teacher prep
- Prepare simple user-test cards and label materials.

Materials
- labels
- arrows
- repair supplies
- testing checklist

Checkpoints
- One peer test.
- One revision from feedback.
- One label draft.

Common stuck points + fixes
- Feedback vague -> ask what was confusing.
- Fragile build -> reinforce before adding features.

Documentation / archive
- One revision story.

# Session 08: Block Inventions Showcase

Mission: Present the invention and explain how it changed.
Lesson slug (for course.yaml): s08-block-inventions-showcase

Teacher prep
- Set up mini showcase stations.
- Prepare label/reflection cards.

Materials
- finished projects
- showcase labels
- camera

Checkpoints
- Team presents title, audience, action, and revision.
- Project is archived.

Common stuck points + fixes
- Students overscript -> use cue-card frame.
- Project fails -> explain what changed and demo partial function.

Documentation / archive
- Photo + label + revision note.
