# ClassHub Import Files for 8-Day Age-Band Stack

These files adapt Build Your Block for three separate 8-day groups.

- `k2_teacher_plan_classhub.md`
- `grades3_4_teacher_plan_classhub.md`
- `grades5_7_teacher_plan_classhub.md`

Each file uses `Session NN: Title` headings so ClassHub ingest can parse the sessions.

## Recommended import stance

Import each age band as its own course or course section rather than trying to combine all three into one class.

Suggested slugs:

- `build_your_block_k2`
- `build_your_block_grades3_4`
- `build_your_block_grades5_7`

The three imports share a course spine, but their outputs and student-facing language differ.
