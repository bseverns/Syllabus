# Assessment and Documentation

## What to assess

This course values process, experimentation, care, and explanation.

### Core categories
1. Participation
2. Safe tool use
3. Persistence and revision
4. Collaboration
5. Communication
6. Final project contribution

## Suggested rubric language

### Emerging
Student participates with support, experiments with materials, and can describe some parts of the process.

### Developing
Student completes builds, tests ideas, makes revisions, and explains how key parts work.

### Strong
Student works independently or collaboratively with care, troubleshoots effectively, supports peers, and clearly communicates design decisions.

## Documentation methods
- quick photo of each weekly build
- 1–2 sentence reflection at end of class
- simple “what changed?” note during project weeks
- final showcase label or artist-engineer statement

## Reflection prompts
- What worked today?
- What did not work yet?
- What changed from your first idea?
- What did you learn from someone else?
- What would you try next?

## Showcase evidence
Each team should be ready to answer:
- What is your project called?
- What does it do?
- How does it work?
- What problem, place, or story inspired it?
- What did you have to change along the way?
