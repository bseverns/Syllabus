# Week 11: Make It Durable

## Big idea
If a project is going to be used by other people, it has to survive contact with the real world.

## Weekly learning goals
- strengthen structures, connections, and interfaces
- improve project safety, durability, and reset ability
- test how the build holds up across repeated use

## Weekly rhythm
- Day 1 — launch and explore
- Day 2 — build the core skill
- Day 3 — extend and personalize
- Day 4 — share, document, and connect

## Materials
Use core materials from `docs/MATERIALS_AND_EQUIPMENT.md` plus reinforcements such as stronger cardboard, zip ties, hot glue, velcro, labels, and spare replacement parts.

## Must-have materials this week
- repair and reinforcement supplies
- spare batteries, motors, connectors, and labels
- durability checklist or test routine
- clear storage and reset space for in-progress projects

## Nice-to-have materials
- velcro dots, cable ties, gaff tape, or label sleeves
- simple guards, handles, or stands
- phone or tablet for repeated-use documentation
- bins for emergency replacement parts

## Fastest successful build
One fragile area reinforced and one repeat-use routine tested successfully several times.

## Grades 3–4 adaptation
Keep the goal to strengthening the single most fragile area and practicing a reset routine someone else can follow. Younger students can use colored flags or stickers to mark weak spots before repairing them.

## Grades 5–7 extension
Invite students to strengthen multiple weak points, add clearer user contact points, or create a repair plan that someone else could follow. Older students can also compare which reinforcements actually improve repeated use.

## If tech fails, do this instead
Focus on structure, labels, handles, guards, and reset instructions. Even without powered testing, students can strengthen the body and clarify how visitors interact safely.

## Documentation target for the week
Capture one durability test record showing what was tested, what failed or held, and what was reinforced.

## This week, success looks like...
- projects survive repeated handling better than they did at the start of the week
- students treat reinforcement as design work, not a side task
- teams know how to reset their own project between users

## This week, success sounds like...
- "This part was the weak point."
- "Now it can handle more than one user."
- "Here is how we reset it."

## Day 1 — Launch and explore
### Warm-up prompt
What parts of your project feel loose, messy, or easy to break?

### Mini-demo focus
Examples of durable vs. fragile attachment methods for student-built projects.

### Build activity
Students inspect their project using a durability checklist and mark weak points with tape flags.

### Exit question
What is the riskiest part of your build right now?

## Day 2 — Build the core skill
### Warm-up prompt
What should happen after your project is used five times in a row?

### Mini-demo focus
How to reinforce structure, secure wires, protect moving parts, and create simple reset instructions.

### Build activity
Students reinforce the project body, tidy connections, and improve one repeated-use interaction.

### Exit question
What became stronger today?

## Day 3 — Extend and personalize
### Warm-up prompt
How can a durable project still feel inviting and playful?

### Mini-demo focus
Adding handles, prompts, guards, or clearer contact points without losing visual appeal.

### Build activity
Students refine the interface so visitors know where to touch, stand, press, or look.

### Exit question
What change made your project safer or easier to use?

## Day 4 — Share, document, and connect
### Warm-up prompt
How do you test durability fairly?

### Mini-demo focus
Model a short stress test and a reset checklist for public use.

### Build activity
Students run repeat-use tests with classmates, record failures, and create a quick repair or reset guide.

### Exit question
What still needs attention before an audience uses this project?

## Differentiation
- **Younger-leaning path:** reinforce one fragile area, run a repeat-use test, and practice one reset routine.
- **Older/faster path:** strengthen multiple failure points and document a clearer repair or reset guide.
- **Dignified low-floor move:** stronger, safer repeated use is a major accomplishment even without adding new features.

## Facilitator notes
- frame reinforcement as design, not as boring cleanup
- encourage students to think about younger siblings, families, and visitors using the project
- keep repair materials organized so testing can loop quickly into revision
- test batteries and moving parts before students arrive so failures are easier to diagnose
