# Build Your Block visual pack

Project these sheets during the short demo block. They replace generic “pull examples” prep, not the live tool or build demonstration.

| Weeks | Visual | Use |
| --- | --- | --- |
| 1–2 | [`systems-and-interaction.svg`](systems-and-interaction.svg) | Name light, motion, sound, and code; trace visitor action from input to output. |
| 3 | [`audience-and-first-test.svg`](audience-and-first-test.svg) | Turn a broad idea into audience, purpose, rough mockup, and one test. |
| 4–5 | [`prototype-revision.svg`](prototype-revision.svg) | Run the build-test-observe-fix loop before adding features. |
| 6–7 | [`station-and-showcase.svg`](station-and-showcase.svg) | Design visitor flow, team roles, reset, backup, and archive capture. |

## Alt text

- **Systems and interaction:** Light, motion, sound, and code surround an interaction chain from visitor to input to output.
- **Audience and first test:** A sentence frame names audience, action, and purpose beside a cardboard mockup and one test question.
- **Prototype revision:** Build, test, observe, and fix form a loop beside a checklist for function, durability, clarity, and reset.
- **Station and showcase:** A visitor path moves through wait, read, use, and exit beside station, hosting, backup, and archive checks.
