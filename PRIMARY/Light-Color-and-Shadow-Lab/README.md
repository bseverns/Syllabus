# Light, Color and Shadow Lab

A four-session, screen-light pilot workshop for Pre-K–Grade 2. Learners test light, distance, color film, and silhouettes, then stage a simple shadow scene.

> **PILOT READY:** the package is complete enough for a lead facilitator to deliver. It remains off the public-ready shelf until one real delivery confirms room conditions, materials, safety/access needs, and revision notes.

## Quick start

1. Read [SYLLABUS.md](SYLLABUS.md) and the [K–2 operating model](../K2-PILOT-OPERATING-MODEL.md).
2. Test the room-light conditions and every low-heat LED before Session 1.
3. Pre-cut silhouettes, stage a safe light-test zone, and prepare a normal-room-light fallback.
4. Run four 60-minute sessions; preserve one test trace and one final-scene note per learner/team.
