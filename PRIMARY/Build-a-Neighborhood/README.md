# Build a Neighborhood

A four-session, screen-light pilot workshop for Pre-K–Grade 2. Learners build places people use, connect them into a shared block, and give visitors a tour.

> **PILOT READY:** the package is complete enough for a lead facilitator to deliver. It remains off the public-ready shelf until one real delivery confirms timing, materials, safety/access needs, and revision notes.

## Quick start

1. Read [SYLLABUS.md](SYLLABUS.md) and the [K–2 operating model](../K2-PILOT-OPERATING-MODEL.md).
2. Choose a low, reachable shared footprint and pre-sort building, connecting, and decorating trays.
3. Print place/user picture cards and make one readable model before Session 1.
4. Run four 60-minute sessions; preserve one photo, quote, or sketch per learner/team.
