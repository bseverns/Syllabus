# Friendly City Lab

A four-session Grades 3–5 pilot studio where learners notice confusing public messages, prototype clearer signs or maps, test them with users, and explain a helpful design choice.

> **PILOT READY:** a lead facilitator can deliver this package as written. Keep it off the public-ready shelf until one delivery confirms site access, observation logistics, print needs, and revision notes.

## Quick start

1. Read [SYLLABUS.md](SYLLABUS.md).
2. Choose a school, library, or program-space observation route; secure site permission before learners leave the room.
3. Gather 3–5 existing signs/maps plus the printable materials in the syllabus.
4. Keep all final work as prototypes unless the host approves installation or replacement of actual signage.
