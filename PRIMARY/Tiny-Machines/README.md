# Tiny Machines

A four-session, screen-light pilot workshop for Pre-K–Grade 2. Learners use cardboard and loose parts to make motion visible, test it, and turn it into a tiny story.

> **PILOT READY:** the package is complete enough for a lead facilitator to deliver. It remains off the public-ready shelf until one real delivery confirms timing, material quantities, safety/access needs, and revision notes.

## Quick start

1. Read [SYLLABUS.md](SYLLABUS.md).
2. Pre-punch the Session 1 panels and build both a working and half-working demo.
3. Stage one labeled tray per learner or pair; keep brads, dowels, and cutting prep adult-managed.
4. Run the four 60-minute sessions; end every session with one trace and a parked next step.
5. Record the pilot review at the bottom of the syllabus before changing readiness.
