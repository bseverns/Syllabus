# Portfolio Evidence List (What to Collect)

Keep this light. Evidence should take **under 60 seconds** per student when possible.

## Best (if you can)
- Scratch project link (shared)
- Project title + student name
- One screenshot per month (optional)

## If links aren’t possible
Collect **one** item each week:
- Week 1–4: screenshot of code area (or stage + score/lives visible)
- Week 5–8: screenshot of level switch/cutscene
- Week 9–12: screenshot of instructions + final scene

## Minimum viable evidence (paper roster)
A roster with weekly checkboxes for:
- [ ] Saved correctly
- [ ] Controls work
- [ ] Level 1 goal exists
- [ ] Cutscene exists
- [ ] Level 2 exists
- [ ] Final runs start-to-end
