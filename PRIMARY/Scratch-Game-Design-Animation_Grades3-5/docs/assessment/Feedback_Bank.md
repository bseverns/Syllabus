# Feedback Bank (Copy/Paste Phrases)

Keep feedback short, kind, and specific:
**Glow + Grow + Choice**.

## Game Artifact
### Glow
- “Your game starts cleanly every time.”
- “Your controls feel fair and predictable.”
- “Your level switch feels like a real ‘next chapter’.”
- “That cutscene made me understand the story.”

### Grow
- “Add a win/ending moment so players know they finished.”
- “Make Level 2 different by changing one rule (speed, enemy, gravity, timer).”
- “Add a reset that always returns the player to a safe start spot.”
- “Hide/show sprites per backdrop so the room stays clear.”

## Design Thinking
### Glow
- “You can explain the goal in one sentence — that’s strong design.”
- “You changed something after feedback — that’s real game-making.”
- “You found a bug and named what caused it.”

### Grow
- “Tell the player the goal within 10 seconds (sign, arrow, text, UI).”
- “Pick one bug and fix it all the way.”
- “Add one tiny tutorial moment at the start.”

## Studio Habits
### Glow
- “You saved without a reminder.”
- “You gave kind playtest feedback.”
- “You helped without taking over.”

### Grow
- “Do one small build sprint before decorating.”
- “Ask: ‘Do you want a hint or do you want me to watch you try?’”
- “Take turns: 2 minutes driver / 2 minutes navigator.”

## Mini-script (10 seconds)
- “Show me one thing that works.”  
- “Great — that’s your core loop.”  
- “Next step: ____.”  
- “Pick: story / challenge / polish.”
