# Observation Checklist (Quick Teacher Tool)

This checklist is built for a lively room.  
Use it like a camera: quick snapshots, not long essays.

## How to use (2-minute sweep)
Pick **one column** for the day:
- **Build** (artifact)
- **Habits** (studio behaviors)
- **Support** (who needs what)

Then walk and mark quick symbols:
- ✅ = got it
- ➜ = almost there / next step
- 🛟 = needs help right now
- ⭐ = standout / student can mentor

## Build look-fors (rotate weekly)
- [ ] Green flag starts game
- [ ] Player moves
- [ ] Score changes
- [ ] Lives changes
- [ ] Win condition triggers
- [ ] Level changes
- [ ] Cutscene plays
- [ ] Reset works

## Habits look-fors
- [ ] Uses save ritual
- [ ] Uses kind language in playtesting
- [ ] Shares tools and takes turns
- [ ] Stays in “build mode” during sprints

## Support cues (fast interventions)
- **🛟 Login/Navigation** — gets stuck finding the right sprite/tab  
- **🛟 Attention drift** — needs a smaller task (one block)  
- **🛟 Frustration spike** — needs a “working version” backup  
- **🛟 Social spark** — needs a role (timer, helper, tester)

### Micro-interventions (10–30 seconds)
- “Show me only the green flag script.”  
- “Make it work once, then we decorate.”  
- “Swap seats for one sprint.”  
- “You’re my tester—find one confusing thing.”  
- “You’re my helper—teach the save ritual.”
