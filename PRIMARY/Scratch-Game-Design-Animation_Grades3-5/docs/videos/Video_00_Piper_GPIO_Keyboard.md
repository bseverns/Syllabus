# Video 00 — Build a GPIO Keyboard (Piper) + Test Controls in Scratch

**Length:** ~3–4 minutes  
**Purpose:** Students start with *no physical keyboard* and build one via GPIO using the Piper app + a mouse.

**Standard format:** Hook → Today’s Goal → Build Steps → Common Bug → PAUSE & BUILD → Save Ritual

---

## HOOK (0:00–0:10)
Show a sprite moving in Scratch using the DIY keys.

Lower-third: **“No keyboard? Build one.”**

---

## TODAY’S GOAL (0:10–0:20)
“Today we are building a keyboard using GPIO so we can play our Scratch games.”

Lower-third: **Goal: Build 5 keys + pass the Scratch control test**

---

## BUILD STEPS (0:20–2:10)

### Step 1 — Open Piper (mouse only)
- Open the Piper app.
- Choose the **Keyboard / GPIO Keyboard** activity.

Lower-third: **Open Piper → Keyboard activity**

### Step 2 — Connect ground first
- Find **GND** on the diagram.
- Attach ground firmly.

Lower-third: **Ground first (GND) — the return path**

### Step 3 — Build 5 keys (minimum set)
Build:
- Left / Right / Up / Down / Action (Space)

If Piper uses WASD, that’s okay.

Lower-third: **Build 5 keys: ← → ↑ ↓ + ACTION**

### Step 4 — Test keys in Piper
Press each key and confirm it registers.

Lower-third: **Test in Piper first**

---

## COMMON BUG (2:10–2:35)
“If nothing works, it’s almost always **ground**. Reattach GND.”

Lower-third: **Bug: loose ground**

---

## PAUSE & BUILD (2:35–3:05)
“Pause the video now. Build the keyboard and test all five keys.”

Lower-third: **PAUSE & BUILD — 10 minutes**

---

## SCRATCH TEST (3:05–3:40)
Show the tiny Scratch test blocks:
- when right arrow → change x by 10
- when left arrow → change x by -10
- when up arrow → change y by 10
- when down arrow → change y by -10
- when space → say “hi” for 1 second

Lower-third: **Scratch Test: 5 key scripts**
