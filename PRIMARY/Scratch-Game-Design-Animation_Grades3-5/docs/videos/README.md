# Scratch Game Studio — Video Pack (Grades 3–5)

These short videos are designed to keep the room moving: **2–5 minutes**, one clear build goal, then students pause and build.

**Standard format (every video):** Hook → Today’s Goal → Build Steps → Common Bug → Pause & Do → Save Ritual

## How to use
- Play the video at the start of class (or post for home catch-up).
- After the “**PAUSE & BUILD**” cue, students stop watching and build.
- Keep a timer visible for the build sprint.
