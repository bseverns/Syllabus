## Purpose
Set the tone: games as tiny worlds with rules, and a culture that keeps everyone safe, included, and proud to share.

## Lower-third captions for BUILD (paste into editor)
1. 3 Studio Agreements: fun, safe, kind

- A simple slide with 3 studio agreements
- 10 seconds of a sample Scratch project (menu → level → cutscene)

## Script (read aloud)
**HOOK (10s):**  
“Welcome to Scratch Game Studio. We’re going to build tiny worlds—levels, stories, and cutscenes. And in this room, our games are made with care.”

**TODAY’S GOAL (10s):**  
“Today you learn how our studio works: we create boldly, and we design kindly.”

**STUDIO AGREEMENTS (45s):**  
1) “We make games that are fun for everyone to play.”  
2) “We tell stories without hurting people.”  
3) “We playtest like helpers, not hecklers.”

**CONTENT BOUNDARIES (45s):**  
“In this class we don’t use hate symbols, targeted bullying, or graphic violence. If a big intense idea shows up, I won’t shut you down—I'll help you *translate* it into a safer mechanic.”

**TRANSLATION MENU (40s):**  
- “‘Kill’ becomes: **reset, lose a life, teleport, captured**.”  
- “Real weapons become: **bubble wand, magnet, paint splash, freeze ray**.”  
- “Enemies can be: **storm, maze, timer, tricky jump, puzzle**.”

**PLAYTEST CULTURE (30s):**  
“When we test games, we use: **Two Stars and a Wish**. Two things you liked, and one helpful idea.”

**CLOSE (20s):**  
“Your imagination is welcome here. We just shape it into games we can all share.”  
“Next up: how to navigate Scratch and save your work every time.”
