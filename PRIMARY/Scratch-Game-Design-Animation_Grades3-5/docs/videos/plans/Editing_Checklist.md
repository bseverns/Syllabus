# Editing Checklist (fast + consistent)

## Must-do (1–3 minutes per video)
- Trim dead air at start/end
- Add chapter captions at each shift:
  HOOK → GOAL → BUILD → COMMON BUG → PAUSE & BUILD → SAVE
- Paste the **Lower-third captions for BUILD** as quick cards or subtitles
- Ensure blocks are readable (add a zoom-in if needed)

## Nice-to-have (optional)
- Add “PAUSE & BUILD” full-screen card (3 seconds) before the build sprint cue

## Audio
- Normalize volume to a consistent level across all videos
- Remove one loud click or pop if present

## Quality check
- Can you read variables/broadcast names on a phone?
- Does the build produce the promised result?
- Are we under 5 minutes?

## Export
- 1080p, 30fps
