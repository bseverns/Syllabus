# Video Plans (12-week Scratch Game Studio)

This folder is the production brain:
- **Run-of-show** for each video (timecodes + on-screen actions)
- **Recording day plan** (batch capture workflow)
- **Editing checklist** + upload metadata templates

Recommended workflow:
1) Open the corresponding script in `docs/videos/Video_XX_*.md`
2) Open the matching plan in `docs/videos/plans/VideoPlan_XX_*.md`
3) Record in one pass following the timecode table
