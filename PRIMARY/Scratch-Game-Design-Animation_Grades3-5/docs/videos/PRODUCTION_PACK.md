# Video Production Pack (Scratch Game Studio)

This file standardizes **titles, thumbnails, and on-screen chapter captions** so the video set feels like one coherent season.

## Naming convention

> **Note:** If you record the optional setup video for building a Piper GPIO keyboard, label it **W00**.

**Video title format (YouTube / LMS / file):**  
`Scratch Game Studio — W##_ <Topic>`

**Recommended upload filename:**  
`SGS_W##_Topic.mp4`

## Thumbnail template
Use the same layout every time:

**Top line (series):** `SCRATCH GAME STUDIO`  
**Big center (week/topic):** `W##: <TOPIC>`  
**Small bottom (promise):** 3–6 words like “Build a coin”, “Freeze controls”, “Cutscene time”

## Chapter caption system
Drop a quick caption at each shift:
HOOK → GOAL → BUILD → COMMON BUG → PAUSE & BUILD → SAVE

## Audio + pacing
- Keep it **2–5 minutes**
- Speak slightly slower than feels natural
- Show the **cursor** clearly
- Zoom in when dragging blocks

## Accessibility
- Avoid tiny text; zoom in for variables and broadcasts
- Say block names out loud (“When I receive… broadcast…”)
- Repeat the save ritual exactly the same way every time

## Lower-third caption cards
Each video script includes a **Lower-third captions for BUILD** section.  
These are one-line caption cards you can paste into your editor as on-screen text cues.
