# Video 00 — Piper StoryMode: Mars → Cheeseteroid (Build a Movement Controller)

**Length:** ~4–6 minutes  
**Purpose:** Students can start mouse-only, then build a **physical controller** that makes Piperbot move (Mars) and jump (Cheeseteroid).  
**Format:** Hook → Goal → Steps → One Common Bug → PAUSE & BUILD → Wrap + Link to Scratch

---

## HOOK (0:00–0:15)
Show Piperbot moving and jumping using the physical buttons.

On-screen text:
- “We built a controller.”
- “Now Piperbot can move + jump.”

---

## TODAY’S GOAL (0:15–0:30)
“Today we’re building a controller using GPIO and a breadboard. First we do Mars (movement), then Cheeseteroid (jump). The rules are: follow the pin diagram, test one button at a time, and if it’s weird—check ground.”

---

## STEPS (0:30–3:30)

### Step 1 — Open StoryMode
- Open Piper app → **StoryMode** → **Mars**.

### Step 2 — Mars: wire movement
- Follow the on-screen diagram.
- Build **one button at a time**:
  - wire it
  - test it
  - then move to the next

### Step 3 — Cheeseteroid: add jump
- Return to the map → open **Cheeseteroid**.
- Add the jump input as instructed.
- Test: movement still works and jump works.

---

## COMMON BUG (3:30–4:15)
**Bug:** “Nothing works / it’s random.”
**Fix:**
- re-check the exact GPIO pins
- confirm a shared **ground**
- reseat loose jumper wires

---

## PAUSE & BUILD (4:15–4:45)
“Pause the video. Build the controller. When your buttons work reliably, come back.”

---

## WRAP + SCRATCH BRIDGE (4:45–end)
“In Scratch, we’ll use the same idea: a button is a message. Next video we’ll build on-screen controls so your games work even without a keyboard.”
