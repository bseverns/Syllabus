# Scratch Game Design + Cutscenes Lab (Grades 3–5) — One-Page Course Summary

**Audience:** Grades 3–5 • **Duration:** 12 weeks • **Cadence:** 1 hour/week

## What students make
A playable Scratch game with:
- 2+ levels (Level 1 and Level 2 minimum)
- 1+ cutscene (animated story moment between levels)
- score or goal, obstacles, and an ending

## Optional hardware on-ramp
If kits are available, students can start by building a simple **motion controller** with GPIO (Piper StoryMode). This makes “inputs → actions” concrete before we build controls in Scratch.

## Skills students learn
- Core coding blocks: events, loops, conditionals, variables
- Animation: costumes, timing, show/hide, effects
- Game design: goals, difficulty ramp, feedback, instructions
- Debugging + iteration: playtest, revise, publish

## Class flow (every session)
- Short demo (7 minutes or less)
- Build sprints (timed, hands-on)
- Playtest rotation (students test each other’s games)
- Share + save (celebrate progress + name next steps)

## Studio culture + story content
We don’t pretend games are neutral. Each project is a little world with rules—so we practice building worlds that are **welcoming, funny, and fair**.

We may discuss:
- **Heroes + helpers** (community, teamwork, and who gets agency)
- **Feelings + motivation** (what characters want, fear, and learn between levels)
- **Representation** (names, roles, and designs that avoid stereotypes)
- **Conflict without cruelty** (puzzles, races, chase-and-escape, protect-and-rescue, “tag” mechanics)
- **Feedback as kindness** (playtesting norms: “Two Stars + One Wish”)

**Boundaries:** no hate symbols or targeted bullying; no graphic content; and we steer away from realistic weapons. When a big, intense idea shows up, we help students *translate it* into a safer, more creative mechanic.

## Why it works for energetic groups
- predictable weekly routine
- tiny “demo bites” instead of long lectures
- frequent movement (playtest rotations)
- roles (Debugger, Artist, Storykeeper, Playtester)

## Final showcase
Week 12: game festival + short creator talk.
