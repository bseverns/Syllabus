# Piper controller visuals

Project these at the start of the Piper controller work. They orient students to the workflow and hardware; they do **not** replace the current Piper app's local pin diagram or a live instructor check.

| Activity | Visual | Use | Alt text |
| --- | --- | --- | --- |
| StoryMode Mars → Cheeseteroid; GPIO Keyboard | [`piper-controller-loop.svg`](piper-controller-loop.svg) | Establish the one-input-at-a-time routine before students handle wires. | Four cards show: open Piper and keep its pin diagram visible; connect ground and one input; test in Piper; label the input and add the next one. |
| StoryMode Mars → Cheeseteroid; GPIO Keyboard | [`raspberry-pi-3-gpio-header.jpg`](raspberry-pi-3-gpio-header.jpg) | Name the GPIO header as the place the Piper app will identify; do not use it as a pinout. | Close-up of the Raspberry Pi 3's two-row GPIO header and Raspberry Pi logo on the circuit board. |
