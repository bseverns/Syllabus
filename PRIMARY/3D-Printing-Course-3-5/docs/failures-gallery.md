# Failures Gallery (Learn From These)
- **First-layer detachment:** inspect this [real failed print](../assets/course-visuals/cc-images/first-layer-detached-failure.jpg); improve bed adhesion and stop the print before it becomes a tangle.
- **Spaghetti:** adhesion failed; try brim or more squish.
- **Elephant’s foot:** first layer too squished; raise Z-offset slightly.
- **Layer splits:** too cold or draft; increase temp or walls.
