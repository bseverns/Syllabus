# Week 02 — Measure & Scale + Key Tag
**Time:** 90 min

### Goals
- Use mm, grid snap, align tool; understand real-world scale.
- Practice export and submission.

### Agenda
- **Warm-up (10):** Estimation game: "How big is 20 mm?"
- **Mini-lesson (10):** Caliper basics (outside jaws). Project the [outside-measurement example](../assets/course-visuals/cc-images/digital-caliper-outside-measurement.jpg), then make a **20 mm cube** together and use the [course visual pack](../assets/course-visuals/README.md) for pre-submit checks.
- **Make (55):** Design a **personalized key tag** (flat back, max 60×20×5 mm, add hole Ø 3 mm). Encourage fillets/chamfers.
- **Queue (5):** Submit STLs; teacher checks time estimates and orientation.
- **Share/Cleanup (10):** Show 3 efficient designs and why.

### Teacher Prep
- Have 4–6 calipers; shared stations.

### Deliverables
- `Firstname_KeyTag_v1.stl` (≤ 45–60 min).
