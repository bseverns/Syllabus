# Week 01 — Hello, Tinkercad! + First Print (Nameplate)
**Time:** 90 min

### Goals
- Learn class norms and safety.
- Log into Tinkercad and move/scale/align shapes.
- Export STL and understand the path to printing.

### Agenda
- **Warm-up (10):** Names + “What would you print if anything?”
- **Mini-lesson (10):** Safety (hot parts, pinch points), mm vs inches, what is a *slice*? Compare the [FDM diagram](../assets/course-visuals/cc-images/fdm-layer-deposition.png) with a [real printer in progress](../assets/course-visuals/cc-images/fdm-print-in-progress.jpg), then use the [course visual pack](../assets/course-visuals/README.md).
- **Make (55):** Tinkercad tour → build a **nameplate tag** (block letters extruded ≥3 mm; add a 3 mm hole).
- **Queue (5):** Teacher collects STLs (naming rule). Pick 6–8 for overnight print.
- **Share/Cleanup (10):** 2 quick demos, save work, shut down.

### Teacher Prep
- Create Tinkercad class, test student logins.
- Ensure Digital Factory workspace is ready; confirm Fast‑Draft profile.

### Deliverable
- `Firstname_Nameplate_v1.stl` (≤ 60 min estimate; footprint ≤ 100×40×6 mm).
