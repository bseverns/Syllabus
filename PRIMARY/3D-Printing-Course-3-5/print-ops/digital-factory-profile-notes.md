# Digital Factory Profile Notes (MakerBot SKETCH)

**Class Fast‑Draft (default):**
- Layer height: ~0.28–0.32 mm (0.30 mm typical)
- Walls: 2
- Top/bottom: 3
- Infill: 10–12%
- Supports: Off unless necessary (teacher approval)
- Adhesion: None (use brim only if adhesion issues appear)

**Why:** Keeps most student prints ≤ 60 minutes with acceptable quality.
