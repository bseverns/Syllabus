# 3D Printing course visual pack

Project these sheets during the mini-lesson. Keep physical print samples and the live Tinkercad/Digital Factory demonstration; diagrams cannot replace touching a real fit, failure, or articulated print.

| Weeks | Visual | Use |
| --- | --- | --- |
| 1–4 | [`pipeline-and-printability.svg`](pipeline-and-printability.svg) | Trace model-to-print steps and check measurement, clearance, orientation, and estimates. |
| 5–7 | [`remix-time-and-motion.svg`](remix-time-and-motion.svg) | Frame responsible remixing, print-time choices, and gaps for moving parts. |
| 8–9 | [`relief-and-iteration.svg`](relief-and-iteration.svg) | Turn flat art into relief, then use evidence to move from v1 to v2. |
| 10–11 | [`user-capstone.svg`](user-capstone.svg) | Move from user need to a bounded prototype and short final explanation. |

## Reuse existing course assets

- Use the existing [`tolerance ladder`](../stl-templates/tolerance-ladder.README.md), [`spinning top`](../stl-templates/spinning-top.README.md), and [`keytag`](../stl-templates/keytag-template.README.md) notes instead of adding duplicate starter files.
- Keep model-level creator, source, and license details in the print request. The remix sheet is a reminder, not an attribution record.

## Alt text

- **Pipeline and printability:** Imagine, model, slice, print, and check form a pipeline beside measurement, gap, orientation, and estimate checks.
- **Remix, time, and motion:** A source plus a meaningful change requires title, creator, source, and license; print-time controls and linked-part clearance appear beside it.
- **Relief and iteration:** Flat art gains a base and raised detail; a failed first version leads to one change and a second version.
- **User capstone:** User, need, ideas, small prototype, and constraint check form a path beside a four-part presentation prompt.
