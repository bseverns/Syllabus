# Public Course Overview: 3D Printing Course (Grades 3-5)

Course slug: printing_course_grades_3_5

Short title: 3D Printing
UI Level: elementary
Grade band: 3-5
Duration: 11 weeks
Session count: 11
Typical session length: 90 minutes
Subject tags: 3d-printing, tinkercad, design, engineering, measurement, iteration, makerspace

Summary:
This elementary 3D printing course teaches students the full design-to-print pipeline: imagine, model, slice, print, evaluate, and iterate. Students use Tinkercad and MakerBot SKETCH printers to build small, time-aware designs while learning measurement, safe makerspace behavior, print ethics, and how to design for a real user.

Who this is for:
- Students in grades 3-5 who are new to 3D design or early digital fabrication
- Schools and partner programs that need reliable print throughput and visible weekly wins
- Labs that want a structured path from first print to empathy-based capstone

What students do:
- Learn Tinkercad basics, measurement in millimeters, and STL export
- Practice slicing and print-queue decision-making with class constraints
- Build short weekly projects such as tags, tops, bookmarks, badges, and useful objects
- Iterate from failed or rough prints into improved versions
- Complete a capstone for a real user

Core outcomes:
- Understand the end-to-end 3D printing workflow
- Design within size, time, and material constraints
- Use safe, kind, and ethical classroom printing habits
- Explain how a design changed after testing
- Present a finished object built for someone else

What makes the course work well in an LMS:
- clear weekly artifacts
- consistent design-print-reflect rhythm
- strong alignment between lessons, print ops, and handouts
- built-in safety, naming, and throughput rules
