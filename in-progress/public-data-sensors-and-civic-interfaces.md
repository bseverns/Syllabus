## Why
This course would braid together threads already alive in the repo: robotics, sensing, interface design, civic media, and data storytelling. It would help secondary students move from “look, the sensor works” to “what does this measurement mean, for whom, and how should it be communicated?”

## Core idea
Students work with data that has an actual local referent:
- room noise
- hallway movement
- bus timing
- garden moisture
- library traffic
- classroom energy use
- air / light / temperature conditions
- sign-up flow or waiting patterns

The emphasis is not on big datasets. It is on **small public truths** and what happens when they are turned into interfaces.

## Suggested arc
### Phase 1 - What can be sensed or counted?
- introduce counts, observations, and simple sensor inputs
- compare hand-collected vs electronic data
- ask whether a thing should be measured at all

### Phase 2 - Data is not meaning yet
- logs, tables, charts, simple visualizations
- what gets lost when a number leaves its context
- critique bad public charts and confusing displays

### Phase 3 - Civic interfaces
- signs, dashboards, kiosks, map layers, display cards, scoreboards
- design for a real local public
- test readability and usefulness

### Phase 4 - Prototype and public legibility
- build one bounded interface or intervention
- document setup and audience assumptions
- include an ethics / privacy memo

## Assessment mix
- data journal
- sensor or counting experiments
- interface prototypes
- critique notes on readability and public use
- final civic-facing display / dashboard / interface with documentation

## Teacher notes
The class should resist two temptations:
1. treating all measurement as automatically useful  
2. building surveillance machines in the name of “information”

Keep asking:
- who benefits?
- who is burdened?
- what does a stranger actually understand from this display?
