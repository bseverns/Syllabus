# Chain-Reaction Playground

> **PILOT skeleton.** The only direct local source is the legacy [Chain Reaction Mini](../../PRIMARY/SMM/archive/Chain%20Reaction%20Mini.doc.docx), written for ages 13–16 with motors and Pico Crickets. This version keeps only the visible cause-and-effect build logic.

## Promise

Children connect ramps, balls, blocks, levers, and loose parts so one action causes the next, then celebrate, diagnose, and rebuild the chain.

## Smallest delivery shape

1. **One cause, one effect** — roll, tip, knock, slide, or drop.
2. **Join two effects** — connect two reliable actions with tape, ramps, or blocks.
3. **Make a group chain** — each learner owns one small link.
4. **Test and perform** — name the first break, change one thing, then run the whole chain.

## Tote

Foam balls, cardboard ramps, blocks/LEGO, cups, tape, domino-like pieces, paper tubes, fabric scraps, clips, and low tables or floor trays. No motors, programming, or small loose parts that create a choking risk.

## Keep it K–2

- Start with reliability, not complexity: two linked actions are a valid success.
- Use large, soft, high-contrast pieces and stable trays.
- Expect resets; protect time for rebuilding rather than framing a failed run as an error.

## Reuse, do not copy

Borrow the historical source's sketch, team-build, test, and performance rhythm. Do not use its programming, electronics, age level, or full-day pacing.

## To promote to GO

- [ ] Four run sheets with a safe materials list by age
- [ ] Floor/tray layout and reset routine
- [ ] Photo build cards for three reliable starter chains
- [ ] Observation rubric: `predicts / connects / tests / changes one link`
