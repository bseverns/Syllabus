# Starter Project Build Recipe

This folder contains a **build recipe** for a Scratch starter project you can assemble quickly and then remix/share with students.

- `Starter_Project_Build_Recipe.md` — full step-by-step with block stacks
- `Build_Checklist_10min.md` — rapid build checklist
- `Block_Stacks_TextGuide.md` — block-by-block script stacks in text form
- `Teacher_Customization_Menu.md` — simple swaps to change the game without breaking the structure
