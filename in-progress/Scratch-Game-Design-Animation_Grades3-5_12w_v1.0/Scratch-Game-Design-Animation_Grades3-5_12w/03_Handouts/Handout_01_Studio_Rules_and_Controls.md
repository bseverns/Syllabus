# Handout 01 — Scratch Studio Rules + Controls (Grades 3–5)

## Today’s goal
Make something that moves and reacts.

## Studio rules (we keep the room fun and fair)
1. **Hands off keys** when the teacher is talking.
2. **Test it** after every small change.
3. **Ask 3 then me** (ask 3 classmates before teacher).
4. Be a **kind playtester** (help the game improve).
5. Save often. Name your project clearly.

## Scratch basics
- **Stage** = where the game happens
- **Sprites** = characters/objects
- **Scripts** = code blocks
- **Costumes** = frames for animation
- **Backdrops** = rooms/levels

## Controls checklist (choose one)
- Arrow keys move
- WASD moves
- Mouse click to interact
- Spacebar to jump/action

## Save + name your project
Project name format:
`FirstName_GameTitle_Wk01`
