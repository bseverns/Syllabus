# Weekly Checkpoints (Teacher Look-Fors)

Use this as a quick room-scan checklist.  
Each week has **2–4** “look-fors” to keep things attainable.

## Week 1 — Studio + Saving
- [ ] Student can open Scratch and find the Stage/Sprites/Scripts areas
- [ ] Project is named correctly and saved
- [ ] One sprite moves when green flag is clicked

## Week 2 — Animation
- [ ] Sprite has 2+ costumes
- [ ] Student can trigger costume changes (walk cycle or simple animation)
- [ ] Student can adjust timing (wait value)

## Week 3 — Controls + Score
- [ ] Player moves with keys (or clicks/taps, if chosen)
- [ ] `score` exists and changes when collecting something
- [ ] Student can explain what makes score go up

## Week 4 — Hazards + Lives + Reset
- [ ] `lives` exists
- [ ] Touching a hazard decreases lives once (cooldown)
- [ ] Player resets to a start position

## Week 5 — Win Condition (Level 1 complete)
- [ ] The game has a clear goal (door/score/timer)
- [ ] Winning triggers a “level complete” moment (broadcast or equivalent)
- [ ] Win does not repeat endlessly

## Week 6 — Levels (Room switching)
- [ ] Backdrop/room switching is working
- [ ] `level` variable exists (or rooms are clearly separated)
- [ ] Sprites show/hide correctly per room

## Week 7 — Cutscene
- [ ] Cutscene backdrop exists
- [ ] At least one character acts (say/glide/animate)
- [ ] Controls are off during cutscene (freeze/unfreeze)

## Week 8 — Level 2 + New Mechanic
- [ ] Level 2 exists (different room/backdrop)
- [ ] One new mechanic appears in Level 2
- [ ] Level 2 mechanic is hidden outside Level 2

## Week 9 — Audio + UI (Optional polish week)
- [ ] Sound effect or music is used intentionally
- [ ] UI element exists (score/lives/level, or instructions)
- [ ] Student can explain what the UI tells the player

## Week 10 — Balance + Clarity
- [ ] Level 2 is playable (not impossible, not trivial)
- [ ] Player knows what to do within 10 seconds
- [ ] Reset loop works reliably

## Week 11 — Playtest + Debug
- [ ] Student playtests with a partner
- [ ] Student writes one bug card (or dictates it)
- [ ] Student fixes one bug completely

## Week 12 — Publish + Showcase
- [ ] Title + instructions present
- [ ] Full loop works: Level 1 → Cutscene → Level 2 → Ending (or win)
- [ ] Credits included (Made by ___; assets notes if needed)
