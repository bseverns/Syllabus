# Final Showcase Rubric (Levels + Cutscene)

This is a **celebration checklist + feedback guide** (no grades).

## Required elements (baseline “Meets”)
- [ ] Game starts reliably (green flag)
- [ ] Player control works
- [ ] **Level 1** exists and has a clear goal
- [ ] A **cutscene** plays between levels (or at start/end)
- [ ] **Level 2** exists (second playable room)
- [ ] Win/ending exists (level complete / game over / final scene)
- [ ] Instructions are visible or spoken at the start

## Craft + clarity (pick one sentence)

### Player clarity
- “I knew what to do quickly.”
- “I figured it out after a bit.”
- “I got stuck because ______.”

### Stability
- “It ran start-to-end smoothly.”
- “It worked, but one part was glitchy.”
- “It broke here: ______.”

### Design sparkle (optional)
- “Your best moment is ______.”
- “If you polished one thing, polish ______.”
