# Student Self-Assessment (Fast Reflections)

Students can **write, draw, or dictate**.

## Weekly (pick one)
- Today I built: ______________________
- One thing that works now is: ______________________
- One bug I’m still chasing is: ______________________
- My next step is: ______________________
- One thing I’m proud of is: ______________________

## Mid-course (Week 6–7)
- My game is about: ______________________
- The player’s goal is: ______________________
- My levels are different because: ______________________
- My cutscene is about: ______________________

## Final reflection (Week 12)
- The coolest part of my game is: ______________________
- One thing I changed after playtesting: ______________________
- If I had one more week, I would add: ______________________
