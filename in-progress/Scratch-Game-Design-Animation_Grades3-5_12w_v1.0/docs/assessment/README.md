# Assessment

This course uses **friendly, growth-based assessment**:
- Students are assessed on what they **can show** (their project), what they **can explain** (their choices), and how they **work with others** (studio habits).
- Most assessment is **formative**: quick check-ins that keep momentum and reduce frustration.
- The final showcase uses a simple rubric with **clear “level + cutscene” expectations**.

Files:
- `Assessment_Framework.md` — philosophy, grading options, what evidence to collect
- `Weekly_Checkpoints.md` — week-by-week “what should exist by now”
- `Rubrics.md` — student-friendly 4-level rubric (project + habits)
- `Observation_Checklist.md` — quick teacher look-fors (focus supports included)
- `Peer_Feedback_Two_Stars_and_a_Wish.md` — playtest feedback protocol
- `Student_Self_Assessment.md` — short reflection prompts (fast!)
- `Final_Showcase_Rubric.md` — final project rubric aligned to levels + cutscenes
- `Portfolio_Evidence_List.md` — what to collect each week (screenshots/links)
- `Feedback_Bank.md` — quick “Glow/Grow/Choice” phrases
- `Mini_Conferences.md` — 2-minute student check-ins (Weeks 4/7/10/12)
