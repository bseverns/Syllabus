# Peer Feedback — Two Stars and a Wish (Playtesting)

## The rules
We test games like helpers, not hecklers.

### A “Star” is…
Something you liked **specifically**.
- “I like the way the coin sound feels like a reward.”
- “Level 2 surprised me because the wind pushes you.”

### A “Wish” is…
One idea that would make the game clearer or more fun.
- “I wish the door was easier to see.”
- “I wish I knew the goal sooner.”

## 3-minute playtest format
1) **Play (1:30)** — no talking during the first run  
2) **Stars (0:45)** — two specific compliments  
3) **Wish (0:45)** — one helpful suggestion

## Sentence starters (for young designers)
- “One part that felt fun was…”  
- “One thing that surprised me was…”  
- “One thing that confused me was…”  
- “I wish the game would…”  
- “A helpful instruction would be…”

## Teacher tip (for active groups)
Assign roles:
- Player
- Note-taker
- Time-keeper
Then rotate.
