# Recording Day Plan (Batch capture all 12 videos)

## Goal
Capture the full season efficiently with consistent visuals, pacing, and audio.

## Setup (15–20 minutes)
- Screen recorder: 1080p, 30fps, cursor visible
- Audio: external mic if possible; record in a quiet room
- Scratch: open in browser; sign in; close extra tabs
- Zoom: set browser zoom to 110–125% so blocks are readable
- Prepare a “Demo Project” you can reset quickly (or duplicate before each recording)

## Reusable overlay cards (create once)
- HOOK
- TODAY’S GOAL
- BUILD
- COMMON BUG
- PAUSE & BUILD
- SAVE

## Batch order (reduces context switching)
**Phase A — Foundations**
- Video 01 (culture)
- Video 02 (basics + save)
- Video 03 (controls + freeze)
- Video 04 (animation)

**Phase B — Core mechanics**
- Video 05 (score + collectibles)
- Video 06 (lives + reset)
- Video 07 (win condition)
- Video 08 (level variable + backdrops)

**Phase C — Narrative + finish**
- Video 09 (cutscenes)
- Video 10 (level 2 mechanic)
- Video 11 (playtest + debug)
- Video 12 (publish + showcase)

## Capture strategy
- Record each video in **one clean take**
- If you flub a line: pause 2 seconds, re-say the sentence, keep rolling (easy to cut)
- Keep the mouse movements slow and deliberate

## “Reset between videos” checklist (30 seconds)
- Stop recording
- Duplicate/restore demo project
- Confirm correct sprite is selected
- Make sure variables are visible (when needed)
- Take a breath, then hit record

## Audio consistency
- Start every take with: “Scratch Game Studio — Week __”
- End every take with the same save ritual
