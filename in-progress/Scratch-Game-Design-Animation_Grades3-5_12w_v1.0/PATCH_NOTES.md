# Patch Notes — Piper GPIO Keyboard “Start From 0” Setup

This patch adds a **mouse-only → DIY keyboard** setup flow for classrooms using **Piper + GPIO**
so students can access “keyboard controls” by building them.

## What changed
- New handout: `03_Handouts/Handout_00_Piper_Keyboard_Build.md`
- New video script: `docs/videos/Video_00_Piper_GPIO_Keyboard.md`
- Video index updated: `docs/videos/README.md` (adds Video 00)
- Production pack updated: `docs/videos/PRODUCTION_PACK.md` (notes W00 setup episode)
- Session 01 updated to include a **keyboard build setup sprint**:
  `02_Instructor-Playbook/Sessions/Session_01.md`
- Instructor playbook teacher-prep updated:
  `02_Instructor-Playbook/Syllabus_PlayByPlay.md`

## How to use in a recorded classroom flow
1. Record **Video 00** as the tech setup “Day 0 / Week 0” (or play live on Session 1).
2. Print Handout 00 for pairs.
3. Run Session 01 with the revised timing.

## Notes
- The materials intentionally say “follow the Piper app pin map” rather than pin numbers
  so this remains correct across Piper hardware revisions.
