**Learning outcomes:**
- Build time-based media that responds to sound, timing, input, or performance cues.
- Distinguish between video as a file and media as a live event in a room.
- Make projection or screen works that are legible to an audience under real conditions.
- Document setup, signal flow, and performance timing so the work can be run again.

## Why
This course would bridge several existing strengths in the repo: sound design, imaging, controller thinking, projection logic, and experimental media. It gives secondary students a way to move from isolated clips or sounds toward events, rooms, and systems.

## Core idea
Students make moving-image systems that live **with sound and time**.

Possible forms:
- projection loops
- sound-reactive visuals
- simple generative scenes
- stage backdrops
- portable video objects
- screen installations
- live score + image pairings

## Suggested arc
### Phase 1 - Image, sound, and timing
- understand loops, cues, and beats
- sync a visual event to sound or rhythm
- compare passive playback to responsive media

### Phase 2 - Generative and reactive studies
- p5.js / Processing experiments
- microphone or audio-driven input
- simple rules, repetition, drift, change over time

### Phase 3 - Projection and rehearsal
- room tests
- scale, brightness, audience angle, cable reality
- setup diagrams and run-of-show habits

### Phase 4 - Live piece or installation
- students create one bounded event, projection work, or audiovisual setup
- document what must happen before, during, and after the piece runs
- present in a classroom, hallway, black box, or pop-up site

## Assessment mix
- moving-image studies
- sync / timing experiments
- projection or screen tests
- rehearsal notes
- final live / semi-live media piece with documentation

## Materials / access notes
Minimal setup:
- laptops
- projector or shared screen
- headphones / speakers
- p5.js or Processing
- optional phone cameras or microphones

Expanded setup:
- multiple projectors
- audio interface
- MIDI or controller input
- simple sensors
- blackout / low-light room conditions

## Artifacts
- visual experiment set
- sound-reactive or generative prototype
- setup / signal flow diagram
- rehearsal run sheet
- final piece and documentation bundle

## Teacher notes
Do not let the class become a “cool effects” lab. Keep returning to:
- what does the audience actually perceive?
- what has to happen in the room for this to work?
- can another student run this after you?
