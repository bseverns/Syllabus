# Differentiation + Behavior Supports

## Differentiation by “difficulty dial”
Students can all be building the same *kind* of thing, with different complexity.

### Level 1 (Foundational)
- 1 player sprite
- 1 collectible type
- 1 hazard type
- score OR lives (not both, yet)

### Level 2 (Core)
- score + lives
- door transition
- cutscene freeze/unfreeze
- Level 2 introduces a new mechanic

### Level 3 (Extension)
- clones for enemies or collectibles
- boss phase
- second cutscene
- combo scoring / timer ranking

## Pair programming norms
- Driver uses mouse/keyboard.
- Navigator reads the recipe, checks logic, and watches for bugs.
- Switch roles every 7 minutes.

## Behavior supports (practical)
- Micro-goals: “Make the score go up once.”
- Visible timers.
- Physical role cards.
- “Show me” checkpoints to earn the next step.

## Fast finisher menu (always available)
- Add instruction screen / tutorial
- Add sound effects
- Add a more polished animation sequence
- Add a win screen and game over screen
- Add one extra level or optional secret room
