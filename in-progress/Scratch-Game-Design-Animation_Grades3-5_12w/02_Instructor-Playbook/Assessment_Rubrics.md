# Assessment + Rubrics

## Weekly milestone unlocks (fast)
Mark each student as:
- ✅ Working
- ⏳ Not yet

Milestones:
1. Can move a sprite with keys.
2. Can animate with costumes.
3. Score increases using a variable.
4. Lives decrease on hazard + reset works.
5. Level 1 has a clear win condition.
6. Level transition works (door/backdrop switch).
7. Cutscene freezes controls and resumes.
8. Level 2 adds a new mechanic.
9. Win/GameOver screens exist.
10. Playtest notes → revisions.

---

## Final project rubric (student-friendly)

### Game Structure
- ☐ Beginning/menu
- ☐ Level 1 + Level 2
- ☐ Cutscene between levels
- ☐ Ending (win and/or game over)

### Game Logic
- ☐ Controls work reliably
- ☐ Score/lives/goal are understandable
- ☐ Level 2 changes the challenge

### Animation + Story
- ☐ Cutscene advances story or mission
- ☐ Character animation is visible and timed

### Polish
- ☐ Instructions are visible
- ☐ No game-breaking bugs in playtest
