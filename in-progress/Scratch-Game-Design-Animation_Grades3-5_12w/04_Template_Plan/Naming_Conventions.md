# Naming Conventions (Kid-friendly, teacher-readable)

## Sprite names (examples)
- `Player`
- `Door`
- `Coin`
- `Hazard`
- `Enemy1`
- `UI_Text`

## Costume names
- `walk1`, `walk2`, `walk3`
- `idle1`, `idle2`
- `enemy_walk1`, `enemy_walk2`

## Backdrop names
Use the exact scene names:
- `Menu`, `Level1`, `Cutscene1`, `Level2`, `Win`, `GameOver`

## Project naming (save hygiene)
`FirstName_GameTitle_WkXX`
