# Demo-Proof: Single STL → MakerBot + LulzBot (Color Swap)

Use one canonical STL (`assets/MECH-demo-token_40x3.stl`, 40 × 3 mm) to generate:
- a MakerBot SKETCH **job package** with a scheduled **pause** for color swap, and
- a LulzBot Mini 2/3 **G-code** (Cura LE) with **Pause at height**.

Baseline: 0.25 mm layers; pause ≈ **1.25 mm** → around **Layer 5**.
