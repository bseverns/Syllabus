# Dual‑Fleet Pipeline: MakerBot (SKETCH) + LulzBot (Mini 2/3)

Keep **slicing pipelines separate** but **unify inputs/outputs**:
- Canonical STL/3MF in `assets/` feeds both slicers.
- MakerBot produces a **job package**; LulzBot uses **G‑code** from Cura LE.
- Use the same naming key so jobs match across fleets.
