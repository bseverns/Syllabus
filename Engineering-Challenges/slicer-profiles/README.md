# Slicer Notes

Use **draft** for coupons/rigs and **balanced** for functional parts. Aim for:
- Layer 0.25–0.32 mm (0.5 mm nozzle) or 0.20 mm (0.4 nozzle) for gears/cams.
- Perimeters 3–4 for gears; infill 20–35% gyroid; top/bottom 4–5.
- Holes print undersized; plan to **ream/drill** or build clearance into models.
See prior course repos in this bundle for **fleet‑specific** presets (LulzBot Mini 2/3, MakerBot SKETCH).
