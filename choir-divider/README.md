# Choir Divider
**Clock division + step chorus** (AE Modular BRAEDBOARD)  
2-session lab workshop (90–120 min each)

This workshop builds a **musical clock divider** using classic CMOS logic. A single pulse becomes a small “choir” of related rhythms.
Students learn how counting, division, and state become patchable structure.

**IC count:** 2–3  
- **NE555** (master clock, optional if using external AE clock)  
- **CD4017** (decade counter / step outputs)  
- **CD40106** (optional: clock cleanup + extra pulse shaping)

## What students will build
- Internal clock (optional) with rate knob + LED
- Divider outputs (subdivisions) from the 4017
- Optional “pulse conditioning” stage for cleaner gates
- Patch recipes for polyrhythm, swing illusion, and rhythmic “masking”

## Sessions
- **Session 1:** Build clock + prove counting (LED stepping)
- **Session 2:** Turn steps into divisions + patch as composition

See `syllabus/2-session-block.md`.
