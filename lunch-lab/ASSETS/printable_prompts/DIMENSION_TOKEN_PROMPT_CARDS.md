# Dimension Token Prompt Cards

Cut these into small cards.

## Use-case prompts

- Make a tiny cart label.
- Make a desk marker for a project team.
- Make a prototype badge for a fictional product.
- Make a tag that says where an object belongs.
- Make a token that marks “ready,” “needs review,” or “prototype.”
- Make a tiny sign that would help someone navigate a room.

## Constraint cards

- Use only initials or 1–3 letters.
- Add a 4 mm hole.
- No hole; maximize readability.
- Make the mark readable from across a table.
- Make it print without supports.
- Make one change that reduces print time.

## Reflection cards

- What does the slicer know that CAD does not?
- What did the first layer reveal?
- What would change if you needed 100 copies?
- What would fail first if this token were used every day?
