# AI Workflow Prompt Cards

Cut these into cards for AI Workflow Arcade.

---

## Source Before Style

What sources did you give the model? What claims does the output make that are not in those sources?

---

## Format Is a Constraint

Ask for a table, checklist, JSON-like object, run sheet, or decision matrix. Structure makes output easier to inspect.

---

## Local vs Hosted

Which parts of this workflow would benefit from a local model? Which parts need a stronger hosted tool? Which parts should use neither?

---

## Generated Is Not Approved

A generated image, title, or plan is a draft. Mark what needs human review before it leaves the room.

---

## Approval Gate

Where should the workflow stop and ask a person to decide?

---

## Boundary

What information should not be entered into this tool at all?
