# Lunch Labs visual pack

Project one sheet in the first 3–5 minutes of the matching lab. Each sheet names the activity loop without replacing the live demonstration or participant artifact.

| Lunch Lab | Visual | Use |
| --- | --- | --- |
| Signal Postcards | [`signal-postcards.svg`](signal-postcards.svg) | Turn room observations into a compact visual recommendation. |
| FPV Flight School | [`fpv-flight-school.svg`](fpv-flight-school.svg) | Practice the recover-and-repeat loop before a simulator turn. |
| Sound Logo Sprint | [`sound-logo-sprint.svg`](sound-logo-sprint.svg) | Give each sound a job: impact, texture, motion, then silence. |
| Robot Mood Machines | [`robot-mood-machines.svg`](robot-mood-machines.svg) | Translate a mood into observable robot behavior. |
| Dimension Token | [`dimension-token.svg`](dimension-token.svg) | Keep the dimensions and printability constraints visible during design. |
| Tiny Code Creatures | [`tiny-code-creatures.svg`](tiny-code-creatures.svg) | Map a human input to one clear creature response. |
| AI Workflow Arcade | [`ai-workflow-arcade.svg`](ai-workflow-arcade.svg) | Make the source-to-human-decision chain inspectable. |

## Alt text

- **Signal Postcards:** A room observation becomes a three-point dot map, then a postcard message with an evidence-based recommendation.
- **FPV Flight School:** A pilot follows the simulator practice loop: hover, pass a gate, reset calmly, and repeat with one recorded goal.
- **Sound Logo Sprint:** Impact, texture, and motion object sounds form a short sound logo, with a small silence before the final mark.
- **Robot Mood Machines:** Speed, pause, turn, light, and sound controls combine into different observable robot moods.
- **Dimension Token:** A 30 by 18 by 3 millimeter token shows a raised mark, optional hole, flat back, and no-support print constraints.
- **Tiny Code Creatures:** Button, shake, and tilt inputs lead to a micro:bit creature's face, sound, or movement response.
- **AI Workflow Arcade:** A brief moves through a supplied source, constrained tool, inspectable output, verification desk, and human decision.
