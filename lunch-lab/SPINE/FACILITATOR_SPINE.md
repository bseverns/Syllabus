# Facilitator Spine

Use this rhythm for every Lunch Lab. The lab-specific guides provide details, but this shared structure should remain consistent.

## 45-minute rhythm

| Time | Segment | Facilitator job |
|---:|---|---|
| 0:00–0:05 | Welcome + artifact demo | Show the thing participants will make. |
| 0:05–0:10 | Tool orientation | Name the tool, the constraint, and the safety note. |
| 0:10–0:32 | Main making sprint | Keep people moving; answer practical questions. |
| 0:32–0:40 | Finish + label | Help participants title, label, save, or score the artifact. |
| 0:40–0:44 | Micro-share | Invite 2–3 examples; no critique spiral. |
| 0:44–0:45 | Mission bridge | Connect to youth learning and next steps. |

## 60-minute rhythm

| Time | Segment | Facilitator job |
|---:|---|---|
| 0:00–0:05 | Welcome + artifact demo | Start with evidence, not explanation. |
| 0:05–0:12 | Tool orientation | Keep vocabulary tight: 3–5 terms maximum. |
| 0:12–0:42 | Main making sprint | Use timed checkpoints. |
| 0:42–0:50 | Finish + document | Photograph, export, label, stamp, or save. |
| 0:50–0:56 | Micro-share | Ask what changed between first attempt and final attempt. |
| 0:56–1:00 | Mission bridge + invitation | Link back to createMPLS and volunteer/follow-up pathways. |

## Opening language

> Today is a compressed creative technology lab. The point is not to master the tool. The point is to make one small thing, notice how the system behaves, and leave with a clearer sense of how learning happens when people can touch the material.

## Closing language

> This is the lunch-break version. In youth programs, the same activity becomes a longer path: learn the tool, build the prototype, document choices, test with peers, revise, and share.

## Facilitation rules

- Do not over-explain before participants touch the tool.
- Keep all setup pre-staged.
- Use printed prompts so late arrivals can join.
- Celebrate repair and iteration.
- Protect lunch energy: no shaming, no cold-calling, no jargon pileups.
- End on time.
