# Target Lunch Labs with createMPLS

Version: `v0.4`  
Date: 2026-05-04  
Format: 45–60 minute creative technology experiences for Target team members on lunch breaks

## What this is

This package breaks the workshop/demo pile into a reusable set of **Lunch Labs**: compact, adult-facing, hands-on creative technology experiences that can be delivered at a corporate workplace during lunch.

Each lab is designed to:

- fit inside 45–60 minutes;
- require little or no participant setup;
- produce a small artifact, scorecard, card, sound, map, or reflection;
- connect back to tools and practices used in youth STEAM programming;
- feel polished enough for a corporate partner while staying handmade, generous, and alive.

## Labs included

1. **Signal Postcards** — data storytelling from the room.
2. **FPV Flight School** — simulator stick skills and calm recovery.
3. **Sound Logo Sprint** — Foley and tiny audio identity.
4. **Robot Mood Machines** — behavior design with LEGO Spike.
5. **Dimension Token** — rapid STL creation, exact dimensions, and a live print conversation.
6. **Tiny Code Creatures** — micro:bit interaction prototype.
7. **AI Workflow Arcade** — novel AI toolchains, source discipline, generated assets, structured output, and verification.

## Folder map

```text
SPINE/      Shared framing, facilitator rhythm, partner pitch, safety, materials matrix.
LABS/       One folder per Lunch Lab, each with its own doc pile.
TEMPLATES/  Reusable cards, signage, forms, and run sheets.
DATA/       CSV planning tables for quick import into Airtable, Sheets, or a project tracker.
ASSETS/     Printable starter prompts and lightweight event artifacts.
```

## How to use this v0.2

Start with `SPINE/SERIES_OVERVIEW.md`, then choose one lab folder and read its `README.md` and `FACILITATOR_GUIDE.md`.

For a first Target pilot, this package still recommends:

1. `LABS/01_signal_postcards`
2. `LABS/02_fpv_flight_school`
3. `LABS/03_sound_logo_sprint`

Together, those three offer data + space, simulation + control, and brand/sound + creativity.

For a higher-tech sponsor or innovation audience, pair one of those with:

- `LABS/07_ai_workflow_arcade`

That lab is intentionally no longer a gentle AI introduction. It treats AI as an inspectable toolchain made from sources, models, generated assets, structured outputs, and human approval gates.
