# Materials Checklist: Dimension Token

## Core CAD + print stack

- Chromebooks or laptops, 1 per participant pair
- Tinkercad accounts or preloaded classroom/shared access path
- Optional OpenSCAD or BlocksCAD for exact-dimension demo
- Cura, PrusaSlicer, MakerBot Digital Factory, Bambu Studio, or equivalent slicer
- 1–3 FDM printers, pretested
- PLA filament, ideally a visible color
- scraper/removal tool handled by facilitator only
- power strips and extension cords
- USB drive, shared folder, or QR upload form for STL collection

## Print prep

- printers leveled/trammed and preheated before participants arrive
- one pre-sliced emergency demo token
- one pre-vetted STL ready to print
- one failed token example
- one clean finished token example
- optional four-up batch plate prepared in slicer

## Table materials

- Dimension Cards
- Print Queue Cards
- pens / Sharpies
- calipers
- ruler with millimeters
- small sample bin of previous prints
- table sign
- QR code for follow-up / file gallery

## Nice-to-have

- document camera or webcam on printer
- projector showing slicer preview
- small part cooling fan already tuned
- 0.6 mm nozzle printer for faster robust prints
- small labeled bags/envelopes for later pickup

## Avoid for lunch version

- supports
- multicolor filament swaps
- resin printing
- adhesives
- tiny loose hardware
- account creation during the event if it can be avoided
