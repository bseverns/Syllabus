# Lunch Lab: Dimension Token
## Rapid STL Sprint + Live Print Conversation

## Defined objective

Participants create a tiny, dimension-controlled 3D model, export an STL, and watch one or more pieces print live while the facilitator leads a short conversation about constraints, iteration, and how youth learn manufacturing thinking.

## Participant output

A small 3D file for a **Dimension Token** plus a Dimension Card documenting the exact measurements, intended use, and one printability decision.

## The object: Dimension Token

Default challenge object:

- Base footprint: **30 mm × 18 mm**
- Base thickness: **3 mm**
- Raised mark/text height: **0.8–1.0 mm**
- Minimum readable text height: **5 mm**
- Optional hole: **4 mm diameter**, centered **5 mm** from one short edge
- No supports
- Flat back
- One-color, draft-friendly FDM print

The token can become a keychain tag, small desk marker, cart label, prototype badge, product-fit reference, or tiny “constraint chip.”

## Takeaway

Participants leave with at least one of the following:

- Their exported STL file
- A printed sample if the queue allows
- A pickup/send-later card if their print is queued for later
- A Dimension Card showing the object specs and design decision

## Technologies and materials

- Tinkercad, Onshape, or OpenSCAD/BlocksCAD path
- Chromebooks or laptops
- Cura, PrusaSlicer, [MakerBot Digital Factory](../../../PRIMARY/3D-Printing-Course-3-5/docs/migration-note.md), or equivalent slicer
- 1–3 small FDM printers, ideally preheated and tested
- PLA filament
- calipers
- printed dimension cards
- USB drive, cloud folder, or QR upload form for STL collection
- pre-printed example tokens and failure samples

## Corporate/workplace relevance

Connects to product prototyping, packaging, merchandising fixtures, labels, store operations, dimensional communication, QA, manufacturing constraints, and the gap between a digital idea and a physical object.

## Best 45-minute version

Participants make a 30 × 18 × 3 mm token from a prepared Tinkercad template, export the STL, and watch one facilitator-selected file print while the group discusses printability.

## Best 60-minute version

Participants make/export tokens, the facilitator starts a live batch print, and the group compares digital model → slicer preview → first printed layer → finished sample.

## Good audience size

- Ideal: 8–16 participants.
- Manageable: 20–30 participants in pairs.
- Large-room option: run as a demo table with two design stations and one live printer.

## Important print-time note

One tiny token can often print in roughly 6–12 minutes on draft FDM settings, but a whole room of unique tokens will not reliably finish inside one lunch break unless multiple printers are running. The recommended pattern is:

1. everyone creates and exports a file;
2. one or more files print live as evidence;
3. remaining files are queued, batched, and picked up or delivered later.

## Facilitation stance

Make the file quickly. Name the dimensions out loud. Treat the printer as a visible clock. While plastic is becoming an object, talk about constraints, failure, tolerance, and why young people benefit from seeing the whole pipeline.
