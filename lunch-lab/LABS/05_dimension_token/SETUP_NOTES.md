# Setup Notes: Dimension Token

## Room layout

Set up three zones:

1. **CAD zone** — laptops/Chromebooks with template open.
2. **Print zone** — printer visible but not crowd-blocked; facilitator controls removal.
3. **Artifact zone** — Dimension Cards, sample parts, calipers, and queue slips.

## Pre-event setup checklist

- Test the exact participant workflow from blank/open template to exported STL.
- Preheat printer 10–15 minutes before start.
- Load PLA and run a first-layer test.
- Keep one emergency pre-sliced file ready.
- Create a shared upload location or USB handoff process.
- Decide the live-print rule: selected file, lottery, earliest clean file, or pre-vetted demo file.
- Put printed dimensions on the table sign: **30 × 18 × 3 mm**.

## File naming convention

Use this simple format:

`dimension-token_firstname_team_initials.stl`

For corporate/privacy contexts, avoid full names unless the host explicitly wants them.

## Common failure points

| Issue | Fix |
|---|---|
| Participants make object too large | Keep the base locked or use a template. |
| Text too small | Minimum text height: 5 mm; raised height: 0.8–1.0 mm. |
| Hole too close to edge | Place 4 mm hole center 5 mm from edge. |
| Export takes too long | Use one facilitator machine as file collector/slicer station. |
| Printer cannot finish many parts | Print one live sample and queue the rest. |
| Tinkercad login slows the room | Use pre-staged accounts, shared devices, or OpenSCAD demo path. |

## Safety notes

- Participants do not touch nozzle, bed, or moving printer.
- Facilitator removes prints.
- Keep the printer where people can see but not bump it.
- Announce that failed prints are normal evidence, not embarrassment.
