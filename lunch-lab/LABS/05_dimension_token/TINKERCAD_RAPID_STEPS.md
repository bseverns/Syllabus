# Tinkercad Rapid Steps: Dimension Token

## Goal

Make a 30 × 18 × 3 mm token with one raised mark in under 12 minutes.

## Steps

1. Open the prepared Tinkercad template or start a new design.
2. Drag a **Box** onto the workplane.
3. Set the box dimensions to:
   - width: **30 mm**
   - depth: **18 mm**
   - height: **3 mm**
4. Add a **Text** shape or simple icon.
5. Set the raised detail height to **0.8–1.0 mm**.
6. Place it on top of the base.
7. Keep text short: initials, 1–3 letters, number, arrow, star, or simple mark.
8. Optional key/tag hole:
   - drag a **Cylinder**
   - set it as a **Hole**
   - diameter: **4 mm**
   - place center **5 mm** from one short edge
   - align vertically through the base
9. Select all shapes and **Group**.
10. Export as `.STL`.
11. Name the file using the event convention.

## Design rules

- No supports.
- No tiny text.
- No floating geometry.
- No features thinner than ~1 mm.
- Flat back stays flat on the print bed.

## Fast test question

Could someone understand this token from across a table? If not, simplify it.
