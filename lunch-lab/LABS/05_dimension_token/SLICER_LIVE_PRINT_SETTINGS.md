# Slicer Live Print Settings

These are starting points. Tune for your actual printer and filament.

## Draft live-print profile

- Material: PLA
- Nozzle: 0.4 mm or 0.6 mm
- Layer height: 0.24–0.28 mm for 0.4 nozzle; 0.3 mm for 0.6 nozzle
- Walls/perimeters: 2
- Top/bottom layers: 3
- Infill: 10–15%
- Supports: off
- Brim: optional, usually off for a small flat token
- Bed temp: according to PLA/printer profile
- Speed: draft/fast but not reckless

## Live talking points in slicer

Show participants:

- model orientation
- estimated print time
- layer preview
- first layer path
- where raised text appears
- why supports are off
- what changing layer height does to time/detail

## Batch strategy

For a group, consider:

- one file printed live as a demonstration;
- 2–4 tokens printed as a small batch if the printer is fast;
- remaining files queued for later pickup;
- preprinted examples distributed if time is tight.

## Risk note

A slicer time estimate is a forecast, not a promise. Build the lunch flow around observation, not guaranteed completion for every participant.
