# Discussion During Print

Use this while the Dimension Token is printing. The printer becomes the campfire.

## Minute 1: First layer

Ask:

- What does the first layer tell us?
- Why is the bottom of the object the first design decision?
- What would happen if the bed were not level or the first layer did not stick?

## Minute 2–4: Digital file vs. machine path

Ask:

- What changed when the design moved from CAD to slicer?
- What information did the slicer add?
- What information did the CAD view hide?

## Minute 4–7: Constraints

Ask:

- Why did we limit the object to 30 × 18 × 3 mm?
- What did that limit make easier?
- What did that limit make harder?

## Minute 7–10: Tolerance and scale

Ask:

- What would matter if this had to fit on a key ring, shelf, package, cart, or fixture?
- What changes when we print 100 instead of 1?
- What would quality control look like for this tiny object?

## Closing reflection

Ask participants to complete this sentence:

> The printer taught us that `__________________________________`.
