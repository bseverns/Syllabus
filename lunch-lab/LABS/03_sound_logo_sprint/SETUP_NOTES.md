# Setup Notes: Sound Logo Sprint

## Room setup

Use one main Foley table and one editing/listening table.

### Foley table

Place five labeled bins left to right:

1. Impact
2. Texture
3. Motion
4. Human / gesture
5. Tone / electronic

Add a sign:

> Foley = sound design made with ordinary objects.

Put only 5–8 objects in each bin. Too many choices slows the lunch-break format.

### Editing / listening table

Place devices, headphones, cue sheets, and prompt cards here. Keep liquids away from devices.

## Suggested table map

```text
[Entry]
   |
   |  Finished example + facilitator
   v
[Prompt Cards] -> [Foley Bins] -> [Recording Area] -> [Editing/Listening] -> [Share/QR]
```

## Noise management

The room can get chaotic if everyone records at once. Use short recording windows:

- "Impact sounds: record now. 60 seconds."
- "Texture sounds: record now. 60 seconds."
- "Motion sounds: record now. 60 seconds."

Then move everyone into listening/arranging.

## Best object quantity

For 12–16 people:

- 1 set of 5 bins is enough.
- Provide 25–35 total objects.
- Duplicate keys, paper, boxes, fabric, and containers if possible.

For 20–30 people:

- Make 2 identical Foley bin sets.
- Use pairs or trios.
- Have one facilitator float for recording issues.

## Failure recovery

If the audio software fails:

1. Keep the Foley table active.
2. Have teams complete the cue sheet with objects and timing.
3. Facilitator records 2–3 team recipes live using a phone.
4. Share by playing the quick phone recordings.

## Low-tech fallback

Participants build a sound logo score without recording:

- choose objects;
- write the timing;
- perform the sequence live once;
- complete the cue sheet.

The artifact becomes the cue sheet and a short live performance.

## Safety and cleanliness

- Avoid glass if the event is crowded.
- Avoid liquids, powders, sticky items, or food.
- Seal rice, lentils, beads, and stones in containers.
- Do not use sharp metal.
- Do not encourage loud shouting or startling sounds.
- Wipe shared objects before and after the session.

## Documentation

Photograph cue sheets and objects separately from participant faces unless consent is gathered.
