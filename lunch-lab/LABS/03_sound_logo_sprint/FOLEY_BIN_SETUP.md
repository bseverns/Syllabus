# Foley Bin Setup
## No-Imagination-Required Table Plan

## Goal

Make the Foley table understandable in 10 seconds.

Participants should be able to look at the table and know:

1. what Foley means;
2. which bin to start with;
3. which objects are required;
4. what each object might become as a sound.

## Required signage

Print and place this at the table:

> Foley = sound design made with ordinary objects.

Print one label for each bin:

1. Impact: clicks, taps, arrivals, endings
2. Texture: paper, fabric, shimmer, surface
3. Motion: sliding, rolling, zipping, whooshing
4. Human / Gesture: clap, snap, breath, step
5. Tone / Electronic: bell, beep, synth, chime

## Physical setup

Use shallow bins, trays, or baskets. Put a small label on each object or place an object card next to it.

Recommended arrangement:

```text
[Prompt Cards] [Cue Sheets]
      |
      v
[Impact] [Texture] [Motion] [Human/Gesture] [Tone/Electronic]
      |
      v
[Recording Area] -> [Editing/Listening] -> [Share/Export]
```

## Exact bin inventory for one table

### Impact bin

- cardboard box
- wooden block or cutting board
- plastic container with lid
- metal spoon
- ceramic mug
- binder clips
- keys
- mint tin

### Texture bin

- tissue paper
- brown paper bag
- aluminum foil
- felt square
- denim/canvas scrap
- microfiber cloth
- sealed rice/lentil container
- paintbrush

### Motion bin

- zipper pouch
- Velcro strip
- tape measure
- toy car
- cardboard tube
- plastic ruler
- deck of cards
- reusable shopping bag

### Human / gesture bin

This bin can be a card rather than a physical bin:

- clap
- snap
- table tap
- footstep on cardboard
- soft breath
- quiet word
- pencil tap
- sleeve swish

### Tone / electronic bin

- desk bell
- bicycle bell, optional
- kalimba, optional
- toy keyboard, optional
- littleBits/Korg synth, optional
- micro:bit tone, optional

## Object cards

Each card should use this format:

```text
OBJECT: Keys
TRY: Small jingle close to the microphone
CAN BECOME: search, access, cart, arrival
```

## Setup time

- Small kit: 15 minutes
- Full kit: 30 minutes
- With technology test: 45 minutes

## Reset between groups

- Put objects back in correct bins.
- Remove duplicate recordings from shared devices if privacy requires.
- Wipe handled objects.
- Replace damaged paper or foil.
- Check that headphones still work.
