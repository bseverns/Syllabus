# Materials Checklist: Sound Logo Sprint

## Core technology

- [ ] 1 facilitator laptop with audio output.
- [ ] 2–6 participant Chromebooks, tablets, or phones.
- [ ] BandLab, Soundtrap, GarageBand, Audacity, or a simple recorder tested before the event.
- [ ] 2–6 pairs of headphones.
- [ ] 1 small speaker for share-out.
- [ ] QR code for upload / follow-up, if using a shared gallery.

## Required Foley bins

Prepare five labeled bins. The first three are required. The last two are optional but useful.

### Bin 1: Impact sounds

Short, clear sounds that mark a beginning, ending, button press, arrival, or decision.

- [ ] cardboard box, small
- [ ] wooden block or small cutting board
- [ ] plastic container with lid
- [ ] metal spoon
- [ ] ceramic mug
- [ ] binder clips
- [ ] keys on keyring
- [ ] stapler, used only as a sound object; no staples needed
- [ ] empty mint tin or small metal tin
- [ ] small rubber ball

### Bin 2: Texture sounds

Continuous or surface sounds that create mood.

- [ ] tissue paper
- [ ] brown paper bag
- [ ] bubble wrap, optional; avoid popping if noise is disruptive
- [ ] aluminum foil
- [ ] felt square
- [ ] scrap denim or canvas
- [ ] microfiber cloth
- [ ] dry rice or lentils in sealed container
- [ ] beads in sealed container
- [ ] small brush or clean paintbrush

### Bin 3: Motion sounds

Sounds that suggest movement, transition, travel, scanning, sliding, or speed.

- [ ] zipper pouch
- [ ] Velcro strip
- [ ] retractable tape measure
- [ ] small toy car
- [ ] cardboard tube
- [ ] plastic ruler
- [ ] deck of cards
- [ ] reusable shopping bag
- [ ] smooth stones in sealed container
- [ ] small chain or bead necklace

### Bin 4: Human / gesture sounds

Body-made sounds. Use lightly and respectfully.

- [ ] hand clap
- [ ] finger snap
- [ ] knuckle tap on table
- [ ] shoe step on cardboard
- [ ] soft breath
- [ ] quiet "hmm"
- [ ] quiet spoken word such as "found," "ready," or "go"
- [ ] pencil tap
- [ ] palm rub
- [ ] sleeve swish

### Bin 5: Tone / electronic sounds

Optional layer for polish or contrast.

- [ ] small desk bell
- [ ] bicycle bell, if available
- [ ] kalimba or small thumb piano, if available
- [ ] toy keyboard, if available
- [ ] littleBits/Korg synth kit, if available
- [ ] phone tone recorded from facilitator device, if policy allows
- [ ] browser tone generator, preloaded
- [ ] micro:bit tone demo, optional

## Print materials

- [ ] Participant cards.
- [ ] Sound logo cue sheets.
- [ ] Prompt cards.
- [ ] Foley table labels.
- [ ] Bin labels.
- [ ] "Foley = sound design made with ordinary objects" sign.
- [ ] Mission bridge card.
- [ ] QR follow-up sign.

## Table materials

- [ ] Sharpies.
- [ ] Painter's tape.
- [ ] Index cards.
- [ ] Small baskets or trays.
- [ ] Cleaning wipes.
- [ ] Zip bags for small parts.
- [ ] Extension cord and power strip.
- [ ] Optional tablecloth to reduce table noise.

## Pre-event prep

- [ ] Test recording on the device you will actually use.
- [ ] Make one finished 5-second example.
- [ ] Label every Foley bin in plain language.
- [ ] Put 5–8 objects in each bin; do not overfill.
- [ ] Remove fragile, sharp, messy, wet, sticky, or food-allergen items.
- [ ] Decide whether participants can export audio or will only complete cue sheets.
- [ ] Prepare low-tech fallback: facilitator records one group recipe live.

## Pack-out

- [ ] Photograph cue sheets.
- [ ] Save/export digital files when possible.
- [ ] Count completed cue sheets.
- [ ] Note which objects got used most.
- [ ] Note which objects caused confusion.
