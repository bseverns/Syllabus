# Foley Object Guide
## Exact Object List and What Each Object Can Become

**Foley** means sound design made with everyday objects. The facilitator should not assume participants or decision-makers know this word.

Use this guide to pack the kit, label the table, and explain what participants are hearing.

## Required bins

### Bin 1: Impact

Impact sounds are short. They are good for starts, stops, arrivals, confirmations, clicks, decisions, and endings.

| Object | Action | Sounds like / useful for |
|---|---|---|
| Cardboard box | tap with fingers | package arrival, soft drum, door knock |
| Wooden block / cutting board | single knock | decision point, sturdy confirmation |
| Plastic container with lid | close lid | snap, sealed package, completion |
| Metal spoon | tap mug or tin | bright click, tiny bell, attention |
| Ceramic mug | finger tap | warm confirmation, checkout counter |
| Binder clip | open/close once | mechanical click, approval, lock |
| Keys on keyring | small jingle | search, access, cart, movement |
| Stapler, no staples | press gently | office click, system action |
| Mint tin | tap or close | small metal box, compact product |
| Rubber ball | drop lightly on cardboard | bounce, playful arrival |

### Bin 2: Texture

Texture sounds create surface, mood, and atmosphere. They can sit behind the main sound.

| Object | Action | Sounds like / useful for |
|---|---|---|
| Tissue paper | crinkle softly | light packaging, delicate reveal |
| Brown paper bag | crumple or unfold | shopping bag, browsing, fire-like crackle |
| Aluminum foil | fold slowly | shimmer, tech texture, tension |
| Felt square | rub with fingers | softness, calm, fabric, care |
| Denim or canvas scrap | rub or flap | durable fabric, movement, workwear |
| Microfiber cloth | sweep across table | clean, smooth, calm transition |
| Rice/lentils in sealed container | slow shake | tiny parts, movement, supply flow |
| Beads in sealed container | tilt gently | bright movement, small product pieces |
| Paintbrush | brush cardboard | air, sweep, gentle motion |
| Bubble wrap | press without popping if possible | packaging texture, fragile item |

### Bin 3: Motion

Motion sounds suggest movement through space, transition, speed, travel, scanning, delivery, or change.

| Object | Action | Sounds like / useful for |
|---|---|---|
| Zipper pouch | zip open/closed | reveal, bag, transition |
| Velcro strip | pull apart lightly | attachment, rough texture, fast reveal |
| Tape measure | extend/retract | precision, measuring, quick movement |
| Toy car | roll on table/cardboard | cart, delivery, vehicle, movement |
| Cardboard tube | whoosh through air | air movement, tunnel, sweep |
| Plastic ruler | slide across table | scan, swipe, clean movement |
| Deck of cards | riffle or slide | sequence, sorting, options |
| Reusable shopping bag | swish or shake | store, movement, everyday carrying |
| Stones in sealed container | tilt slowly | weight, movement, material |
| Small chain / bead necklace | drag lightly | mechanism, conveyor, tiny machinery |

### Bin 4: Human / Gesture

Human sounds add warmth and presence. Use quietly and intentionally.

| Sound | Action | Sounds like / useful for |
|---|---|---|
| Hand clap | one soft clap | arrival, attention, punctuation |
| Finger snap | one snap | quick idea, notification, decision |
| Knuckle tap | tap table | knock, small drum, waiting |
| Footstep | step on cardboard | person approaching, store aisle |
| Soft breath | one breath | relief, calm, human presence |
| Quiet "hmm" | short vocal tone | thinking, friendliness |
| Quiet word | "found," "ready," "go" | human service, confirmation |
| Pencil tap | tap pencil | office rhythm, decision |
| Palm rub | rub hands | anticipation, texture |
| Sleeve swish | move arm past mic | motion, gesture, fabric |

### Bin 5: Tone / Electronic

Tone sounds add polish, melody, app-like identity, or contrast. These are optional.

| Object / tool | Action | Sounds like / useful for |
|---|---|---|
| Desk bell | tap lightly | service, arrival, completion |
| Bicycle bell | ring once softly | friendly alert, motion |
| Kalimba | pluck one tine | warm brand tone, gentle melody |
| Toy keyboard | play one note | app sound, synthetic layer |
| littleBits/Korg synth | one short tone | electronic identity, future feel |
| Micro:bit tone | simple beep | classroom tech connection, notification |
| Browser tone generator | one sine tone | clean digital cue |
| Phone tone | use only if allowed | familiar notification reference |

## Object combinations that work immediately

### Calm checkout

- microfiber cloth sweep
- card slide or ruler slide
- mug tap
- soft breath or quiet "ready"

### Package arrival

- tape measure retract
- cardboard box tap
- key jingle
- binder clip click

### Helpful app notification

- finger snap
- soft desk bell
- tissue paper brush
- silence

### Product discovery

- paper bag crinkle
- zipper open
- keys jingle
- bell tap

### Fast team problem-solving

- pencil tap rhythm
- binder clip click
- ruler slide
- hand clap

## Objects to avoid

Avoid these in corporate lunch settings:

- liquids;
- powders;
- glass jars;
- sharp metal;
- food with allergens;
- sticky tape as a sound object;
- messy materials;
- loud poppers;
- anything that looks like trash unless it is intentionally clean and labeled.

## Facilitator phrase bank

- "What did this object become after you recorded it?"
- "Does the sound feel calm, fast, reliable, playful, or premium?"
- "Where should silence go?"
- "What should happen at the exact moment of success?"
- "What sound would make this feel more human?"
