# Lunch Lab: Signal Postcards
## Dispatches from the Room

## Defined objective

Participants collect one simple environmental or behavioral signal from the room, convert it into a postcard-sized data visualization, and send one evidence-based recommendation to a future user of the space.

## Participant output

4×6 postcard with front-side data artwork and back-side addressed message.

## Takeaway

A stamped 4×6 Signal Postcard plus an optional Signal Dispatch Receipt.

## Technologies and materials

- micro:bit v2
- MakeCode
- Chromebooks
- printed floor maps
- stickers / markers
- Signal Mailbox
- rubber stamp

## Corporate/workplace relevance

Connects to workplace design, store layout, guest experience, data storytelling, and observation as a design practice.

## Best 45-minute version

Measure sound or light at 3–5 points and turn the readings into a dot map.

## Best 60-minute version

Add a message to a specific recipient, photograph the postcard, and place it in a shared gallery.

## Good audience size

- Ideal: 8–16 participants.
- Manageable: 20–30 participants if run in pairs or stations.
- Large-room option: run as a table with timed rotations.

## Facilitation stance

Start with the artifact. Keep explanation short. Let adults touch the tool quickly. End by naming how the same pattern becomes a deeper youth learning pathway.
