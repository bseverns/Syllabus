# Setup Notes: FPV Flight School

## Room setup

- Place the finished example where participants can see it immediately.
- Keep the tool area uncluttered.
- Use pairs if gear is limited.
- Leave space for observers and late arrivals.

## Failure recovery

If the main technology fails:

1. Use the printed participant card.
2. Shift to the analog version of the concept.
3. Keep the same output.
4. Name the failure as part of prototyping.

## Low-tech fallback

Every lab should still be possible as a discussion-and-card exercise.

For this lab, the fallback is:

> Participants use the same prompt and artifact card, but the facilitator demonstrates the tool rather than each participant using it directly.

## Documentation

Photograph artifacts separately from faces unless consent is explicitly gathered.
