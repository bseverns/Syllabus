# Lunch Lab: FPV Flight School
## Simulator Stick Skills for Calm Hands

## Defined objective

Participants learn the basic control logic of FPV flight through simulator drills and record one skill goal for future practice.

## Participant output

Pilot Card documenting the first controlled flight attempt.

## Takeaway

A Pilot Card with hover, gate, reset, and personal-best notes.

## Technologies and materials

- FPV simulator
- USB radio controllers
- laptops or gaming-capable machines
- large display
- pilot cards

## Corporate/workplace relevance

Connects to simulation, training systems, risk reduction, embodied practice, and calm recovery after failure.

## Best 45-minute version

Complete hover, reset, and one clean gate.

## Best 60-minute version

Add a three-gate route and optional team relay.

## Good audience size

- Ideal: 8–16 participants.
- Manageable: 20–30 participants if run in pairs or stations.
- Large-room option: run as a table with timed rotations.

## Facilitation stance

Start with the artifact. Keep explanation short. Let adults touch the tool quickly. End by naming how the same pattern becomes a deeper youth learning pathway.
