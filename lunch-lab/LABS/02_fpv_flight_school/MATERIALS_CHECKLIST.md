# Materials Checklist: FPV Flight School

## Core materials

- [ ] FPV simulator
- [ ] USB radio controllers
- [ ] laptops or gaming-capable machines
- [ ] large display
- [ ] pilot cards

## Shared table materials

- [ ] Table sign.
- [ ] Printed participant cards.
- [ ] Sharpies.
- [ ] Painter's tape.
- [ ] QR code to follow-up form.
- [ ] Small sign: “What would you do with one more hour?”
- [ ] Artifact documentation station.

## Pre-event prep

- [ ] Test all technology.
- [ ] Create one finished example.
- [ ] Print 20–30 participant cards.
- [ ] Prepare a low-tech fallback.
- [ ] Prepare mission bridge card.
- [ ] Confirm power and table layout.

## Pack-out

- [ ] Photograph artifacts.
- [ ] Save/export digital files.
- [ ] Count completed cards.
- [ ] Note equipment failures.
- [ ] Record participant questions.
