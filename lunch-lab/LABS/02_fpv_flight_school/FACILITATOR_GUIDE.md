# Facilitator Guide: FPV Flight School

## Lab purpose

Participants learn the basic control logic of FPV flight through simulator drills and record one skill goal for future practice.

## Facilitator links

Pick one simulator, install it before the event, and calibrate every USB radio in that same simulator. Do not make participants choose software or remap controls during the lunch block.

- [VelociDrone](https://www.velocidrone.com/) — default classroom simulator already used elsewhere in this repository.
- [FPV Freerider](https://fpv-freerider.itch.io/fpv-freerider) — lightweight alternate path.
- [Existing radio-to-USB setup and drill notes](../../../SECONDARY/Robotics-to-FPV-Course/sim/Setup.md) — use for calibration and the hover/gate practice sequence.

Keep the simulator-only boundary: no live aircraft, radio configuration changes, or flight-hardware setup during this lab.

## 45-minute run

| Time | Segment | Action |
|---:|---|---|
| 0:00–0:05 | Show the artifact | Display a finished example and name the output. |
| 0:05–0:10 | Orient to the tool | Name the tool, the input/output, and the constraint. |
| 0:10–0:30 | Main sprint | Participants complete the core challenge: Complete hover, reset, and one clean gate. |
| 0:30–0:37 | Finish and label | Participants title, save, stamp, score, or label their artifact. |
| 0:37–0:43 | Share | Invite 2–3 lightning shares. Ask: “What changed after the first try?” |
| 0:43–0:45 | Bridge | Connect the lab to createMPLS youth pathways. |

## 60-minute run

| Time | Segment | Action |
|---:|---|---|
| 0:00–0:05 | Show the artifact | Display a finished example and name the output. |
| 0:05–0:12 | Orient to the tool | Name 3–5 key terms and the safety note. |
| 0:12–0:40 | Main sprint | Participants complete the core challenge, then revise. |
| 0:40–0:50 | Finish and document | Photograph, export, stamp, save, or score the output. |
| 0:50–0:56 | Share | Ask participants to name one design decision. |
| 0:56–1:00 | Bridge | Connect to youth learning, volunteer pathways, and follow-up. |

## Opening script

> Welcome to FPV Flight School. In this Lunch Lab, you will make one small artifact using a tool that also appears in youth STEAM programming. The goal is not mastery. The goal is to make, test, notice, and leave with a clearer question.

## Key vocabulary

- System
- Prototype
- Input
- Output
- Constraint
- Iteration
- Evidence

## Closing prompt

> What would you build, measure, test, or remix if we had one more hour?
