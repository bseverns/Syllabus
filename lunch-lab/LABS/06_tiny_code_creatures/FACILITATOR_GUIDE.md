# Facilitator Guide: Tiny Code Creatures

## Lab purpose

Participants create a simple micro:bit creature that responds to buttons, shake, or tilt.

## Facilitator links

Build and download one starter project before the event. It should expose every option on the participant card without adding hardware beyond the micro:bit.

- [MakeCode editor](https://makecode.microbit.org/).
- Inputs: [button press](https://makecode.microbit.org/reference/input/on-button-pressed) and [gesture](https://makecode.microbit.org/reference/input/on-gesture) for Button A/B, shake, and tilt.
- Outputs: [show LEDs](https://makecode.microbit.org/reference/basic/show-leds), [show text or number](https://makecode.microbit.org/reference/basic/show-string), and [play tone](https://makecode.microbit.org/reference/music/play-tone).

Test each input on the actual board, then print the companion [`CREATURE_CARD.md`](CREATURE_CARD.md). If a download fails during the lab, use the same starter project on the facilitator board for a quick live test rather than changing the activity.

## 45-minute run

| Time | Segment | Action |
|---:|---|---|
| 0:00–0:05 | Show the artifact | Display a finished example and name the output. |
| 0:05–0:10 | Orient to the tool | Name the tool, the input/output, and the constraint. |
| 0:10–0:30 | Main sprint | Participants complete the core challenge: Button A and Button B show two different moods. |
| 0:30–0:37 | Finish and label | Participants title, save, stamp, score, or label their artifact. |
| 0:37–0:43 | Share | Invite 2–3 lightning shares. Ask: “What changed after the first try?” |
| 0:43–0:45 | Bridge | Connect the lab to createMPLS youth pathways. |

## 60-minute run

| Time | Segment | Action |
|---:|---|---|
| 0:00–0:05 | Show the artifact | Display a finished example and name the output. |
| 0:05–0:12 | Orient to the tool | Name 3–5 key terms and the safety note. |
| 0:12–0:40 | Main sprint | Participants complete the core challenge, then revise. |
| 0:40–0:50 | Finish and document | Photograph, export, stamp, save, or score the output. |
| 0:50–0:56 | Share | Ask participants to name one design decision. |
| 0:56–1:00 | Bridge | Connect to youth learning, volunteer pathways, and follow-up. |

## Opening script

> Welcome to Tiny Code Creatures. In this Lunch Lab, you will make one small artifact using a tool that also appears in youth STEAM programming. The goal is not mastery. The goal is to make, test, notice, and leave with a clearer question.

## Key vocabulary

- System
- Prototype
- Input
- Output
- Constraint
- Iteration
- Evidence

## Closing prompt

> What would you build, measure, test, or remix if we had one more hour?
