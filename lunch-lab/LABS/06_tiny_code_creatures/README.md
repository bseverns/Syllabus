# Lunch Lab: Tiny Code Creatures
## Prototype a Pocket Interaction

## Defined objective

Participants create a simple micro:bit creature that responds to buttons, shake, or tilt.

## Participant output

Interactive micro:bit creature with named input/output mapping.

## Takeaway

An interactive micro:bit creature plus a Creature Card.

## Technologies and materials

- micro:bit
- MakeCode
- Chromebooks
- cardstock
- badge sleeves
- tape
- starter code cards

## Corporate/workplace relevance

Connects to prototyping, interaction design, accessibility, input/output logic, and playful product thinking.

## Best 45-minute version

Button A and Button B show two different moods.

## Best 60-minute version

Add shake or tilt behavior and a simple physical shell.

## Good audience size

- Ideal: 8–16 participants.
- Manageable: 20–30 participants if run in pairs or stations.
- Large-room option: run as a table with timed rotations.

## Facilitation stance

Start with the artifact. Keep explanation short. Let adults touch the tool quickly. End by naming how the same pattern becomes a deeper youth learning pathway.
