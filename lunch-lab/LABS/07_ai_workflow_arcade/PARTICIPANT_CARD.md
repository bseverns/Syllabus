# Start Here: AI Workflow Arcade

## Make this

Use the tool to make one thing from the source on your table. Tell it what to make, what it must include, and what it must not do. Then check the result.

## Before you run a tool

Use only the sample paper or notes on your table. Do **not** enter private Target information, names, customer information, money information, plans that are not public, or personal information.

## Step 1 — Choose a brief

Pick one:

- Rewrite this messy program note into a clear event invite.
- Turn these workshop facts into a 5-bullet decision memo.
- Generate three visual directions for a community tech event.
- Convert a short transcript into action items.
- Build a table comparing three workshop options.
- Draft a youth-friendly activity title, then critique it for tone.

## Step 2 — Choose a path

Circle one:

- Source packet → chat model → verified answer
- Messy notes → structured table → human decision
- Prompt → generated image/concept → critique
- Audio/transcript → summary → action checklist
- Local model → hosted model comparison → boundary note

## Step 3 — Tell the tool the rules

Complete this sentence before you run the tool:

> The output must be useful for ______, must include ______, and must avoid ______.

## Step 4 — Check the result

Mark the output:

- Keep: ________________________________
- Check: _______________________________
- Reject: ______________________________

## Step 5 — Decide what a person still needs to do

Finish:

> I would use AI for this part: ________________________________
>
> I would keep a human responsible for: ________________________
>
> I would not enter this kind of information: ___________________

## If you are stuck

Choose **Source packet → chat model → verified answer**, use only the facts you were given, and mark any unsupported claim as **Check** or **Reject**.
