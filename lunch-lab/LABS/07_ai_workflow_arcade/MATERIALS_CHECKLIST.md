# Materials Checklist — AI Workflow Arcade

## Required

- facilitator laptop
- projector or large display
- 6–12 participant laptops/Chromebooks or table stations
- printed AI Workflow Cards
- printed Verification Cards
- printed Source Packet Examples
- sample briefs, notes, transcripts, and image prompts
- timer
- pens / markers
- QR code to follow-up form

## Preferred

- one approved hosted AI interface
- one local-model demo machine
- one prepared retrieval/source packet demo
- one image-generation or visual-ideation demo, if allowed
- one speech-to-text or transcript summarization demo, if allowed
- prepared Google Docs / Slides / Sheets templates

## Optional spectacle items

- small sign: TOOLCHAIN, NOT MAGIC
- "human approval gate" stamp
- printed output labels: KEEP / CHECK / REJECT
- side-by-side comparison cards for hosted vs local vs source-aware workflows

## Prep burden

Medium. The lab is easy to facilitate once staged, but it must be pre-approved and pre-tested.

## Pre-event host questions

- Which AI tools are allowed on the host network?
- Are participants allowed to use personal AI accounts?
- Is image generation allowed?
- Is audio recording allowed?
- Should all examples avoid Target-specific operational content?
- Can we show a local model running on facilitator hardware?
