# Setup Notes — AI Workflow Arcade

## IT and policy setup

This lab should be staged with host approval. The facilitator should not assume access to any specific web service, AI provider, or account system.

Before the event, confirm:

- network access,
- browser restrictions,
- account restrictions,
- data/privacy expectations,
- whether generated images are allowed,
- whether audio recording/transcription is allowed,
- whether local model demos can run on facilitator hardware.

## Recommended staging

### Table 1 — Source-Aware Answer

Participants use a small printed source packet and ask the model to answer only from those facts.

### Table 2 — Structured Output

Participants turn messy notes into a table, checklist, JSON-like structure, or decision matrix.

### Table 3 — Generated Concept

Participants create a title set, visual direction, short storyboard, or image prompt, then critique it.

### Table 4 — Verification Desk

Participants label outputs: KEEP / CHECK / REJECT.

## Failure recovery

If no AI tools are accessible:

- Run the facilitator demo from pre-generated outputs.
- Use printed outputs for the verification exercise.
- Have participants write improved prompts and workflow cards without running tools live.
- Compare "bad output" and "better output" examples on paper.

The lab still works because the core skill is workflow design and verification, not button-clicking.

## Privacy posture

Use synthetic examples. Do not ask participants to enter real employee data, customer data, financial data, internal strategy, unreleased product plans, or personally sensitive information.
