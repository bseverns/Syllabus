# Lunch Lab: AI Workflow Arcade
## Novel AI Toolchains for Practical Human Judgment

## Defined objective

Participants will build and critique a tiny AI-assisted workflow, moving from a messy brief to a sourced output, a generated or structured artifact, and a human verification decision.

This is not an introduction to AI. It assumes participants have seen chatbots. The lab asks a better question:

> What happens when AI becomes a workflow made of tools, sources, constraints, and human decisions?

## Participant output

Each participant or pair leaves with an **AI Workflow Card** documenting:

1. the brief they chose,
2. the toolchain they used,
3. the source material or constraints supplied,
4. the model output or generated artifact,
5. what they verified,
6. what they would not trust,
7. the human decision they made at the end.

## Takeaway

A compact, adult-facing understanding of AI as a chain of decisions, not a magic answer box.

Participants should leave able to say:

- I can separate prompt quality from source quality.
- I can tell when the tool is inventing vs transforming.
- I can ask for structured output that a human can inspect.
- I can pair novel tools with ordinary classroom/computer-lab tools.
- I can name one boundary I would keep in a professional or educational setting.

## Technologies and materials

### Everyday / classroom-adjacent tools

- Chromebooks or laptops
- Google Docs / Slides / Sheets
- sample text packets
- QR codes
- printed workflow cards
- plain-language verification checklist

### Novel / emerging tools to feature

Use only tools approved for the host environment. The exact products can change; the categories matter.

- hosted chat model or approved enterprise AI interface
- local model demo through Ollama, LM Studio, or a comparable local runtime
- retrieval-augmented generation demo using a small curated source packet
- image generation or visual ideation demo, if allowed
- speech-to-text / summarization demo, if audio capture is approved
- structured-output demo: JSON, table, checklist, rubric, or project plan
- lightweight agent/workflow demo, if appropriate and pre-staged

## Corporate/workplace relevance

Connects to practical AI adoption, workflow design, source discipline, creative ideation, verification, privacy boundaries, and the difference between automation and judgment.

## Best 45-minute version

Run the lab as a three-station arcade with short rotations:

1. **Source-Aware Answer** — model must answer from a tiny source packet.
2. **Generated Asset With Constraints** — model creates a visual, title set, outline, or table under explicit constraints.
3. **Verification Desk** — participants inspect the output and decide what survives.

## Best 60-minute version

Use the same three stations, then add a short share-out where each pair presents one workflow decision:

- What did the tool do well?
- Where did the human need to step in?
- What would be unsafe, unfair, off-brand, or unverifiable if used as-is?

## Good audience size

- Ideal: 8–18 participants.
- Manageable: 20–30 participants in pairs.
- Large-room option: run one station as a projected facilitator-led demo and two stations as paper/workflow activities.

## Facilitation stance

Assume participants are already AI-aware. Do not spend the lunch break explaining that AI exists.

Instead, frame the lab around tool literacy:

> Today we are not asking whether AI is impressive. We are asking how to make a workflow that remains legible, useful, and accountable.
