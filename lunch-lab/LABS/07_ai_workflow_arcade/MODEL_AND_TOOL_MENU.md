# Model and Tool Menu — Pre-Event Planning

This file lists categories rather than requiring specific products. Confirm current availability, pricing, host approval, and data/privacy terms before each event.

## Category 1 — Approved hosted AI interface

Use for quick participant interaction if the host already permits it.

**Good for:** writing, summarizing, structured output, ideation.

**Risks:** data handling, account access, overconfidence, unknown retention policies.

## Category 2 — Local model runtime

Examples to evaluate before the event: Ollama, LM Studio, or comparable local model runners.

**Good for:** showing model weights, runtime, privacy posture, offline/edge thinking.

**Risks:** slower output, setup time, model quality variation, hardware limits.

## Category 3 — Retrieval / source-aware workflow

Use a small curated packet rather than live internal documents.

**Good for:** showing why sources matter.

**Risks:** participants may mistake source-aware for automatically true.

## Category 4 — Image or visual generation

Use only if approved and safe for the host context.

**Good for:** concept variation, moodboards, communication design.

**Risks:** brand resemblance, copyright uncertainty, biased imagery, inappropriate outputs.

## Category 5 — Audio / transcript workflow

Use pre-recorded sample audio unless recording is explicitly approved.

**Good for:** meeting summaries, accessibility, action-item extraction.

**Risks:** consent, privacy, false summaries, missing nuance.

## Category 6 — Agent / automation demo

Keep it pre-staged and bounded.

**Good for:** showing tool-calling, workflow automation, human approval gates.

**Risks:** runaway actions, unclear responsibility, accidental data exposure.

## Recommended default for Target lunch pilot

Use:

- one approved hosted interface or facilitator-only demo,
- one local-model demo machine,
- one printed source packet,
- one structured-output card,
- one verification station.

Avoid:

- live internal data,
- personal employee information,
- customer data,
- financial/strategy materials,
- uncontrolled image generation projected to a room.
