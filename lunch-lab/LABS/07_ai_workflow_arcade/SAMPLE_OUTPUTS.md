# Sample Outputs — AI Workflow Arcade

## Example 1 — Source-Aware Answer

### Brief

Create a five-bullet invitation for a creative technology lunch activity using only the facts in the source packet.

### Source facts

- The session is 45 minutes.
- Participants will use microcontrollers and paper maps.
- The activity turns room data into a postcard.
- No prior coding experience is needed.
- The session connects to youth STEAM programming.

### Useful output

- 45-minute hands-on lunch activity.
- Use simple sensors and paper maps.
- Make a postcard-sized data story from the room.
- No prior coding required.
- See how the same tools support youth STEAM learning.

### Verification notes

Keep: duration, activity, no prior coding.
Check: whether the host wants the word "coding" included.
Reject: any claim about official certification, Target endorsement, or guaranteed learning outcomes.

## Example 3 — Generated Concept Asset

### Prompt

Generate three visual directions for a 45-minute corporate lunch lab about mapping invisible signals in a room. Avoid childish language. Use a civic-design, creative-technology tone.

### Possible output directions

1. **Field Notes from the Room** — maps, stamps, sensor marks, observational tone.
2. **Signal Cartography** — clean grids, colored dots, subtle data layers.
3. **Dispatch Desk** — postcards, mail, archive boxes, report-like fragments.

### Verification notes

Keep: names and design directions.
Check: whether the tone fits the host.
Reject: any generated image that includes fake logos, copyrighted characters, or misleading brand resemblance.
