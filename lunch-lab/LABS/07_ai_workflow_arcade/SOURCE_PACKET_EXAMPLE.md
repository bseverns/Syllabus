# Source Packet Example — Signal Postcards

Use this as a tiny retrieval/source discipline exercise.

## Source facts

1. Signal Postcards is a 45–60 minute lunch lab.
2. Participants collect one simple signal from a room, such as sound or light.
3. Participants turn the signal into a postcard-sized visual map or chart.
4. The postcard includes one finding and one recommendation.
5. The activity can use micro:bit v2, MakeCode, Chromebooks, printed maps, stickers, and markers.
6. The lab connects sensors, data storytelling, design thinking, and youth STEAM programming.
7. Participants should not collect personal information about individuals.

## Bad prompt

Write a paragraph about Signal Postcards.

## Better prompt

Using only the source facts above, write a 75-word invitation for Target team members to attend Signal Postcards during lunch. Do not claim that participants need prior coding experience. Do not mention tools that are not listed. End with one sentence about why it connects to youth STEAM programming.

## Verification questions

- Did the output stay within the source packet?
- Did it invent a location, partner, date, or outcome?
- Did it overpromise what participants will learn?
- Did it preserve the privacy boundary?
