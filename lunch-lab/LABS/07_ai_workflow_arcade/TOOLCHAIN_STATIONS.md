# Toolchain Stations — AI Workflow Arcade

Use three stations for a 45-minute lunch version. Use four or five for a 60-minute version or open-house setting.

## Station A — Source-Aware Answer

**Question:** Can the model answer only from supplied evidence?

**Tools:** approved chat model, printed source packet, Google Doc.

**Participant action:** Ask for a short answer using only the source packet. Then mark unsupported claims.

**Everyday analogue:** research notes, source cards, citation discipline.

**Novel tool angle:** retrieval-augmented generation / grounded answering.

**Output:** a short answer with keep/check/reject marks.

---

## Station B — Structured Output Machine

**Question:** Can AI turn mess into a usable structure?

**Tools:** chat model, Google Sheets, table template, optional JSON example.

**Participant action:** Convert messy notes into a table, checklist, rubric, run sheet, or decision matrix.

**Everyday analogue:** spreadsheets, project planning, meeting notes.

**Novel tool angle:** structured prompting, schema-like outputs, machine-readable formats.

**Output:** a table or checklist that a human can edit.

---

## Station C — Concept Generator With Constraints

**Question:** Can generative tools produce useful creative directions when constrained by tone, audience, and ethics?

**Tools:** text model, image generator if approved, moodboard slides.

**Participant action:** Generate three concept directions for a lunch lab, youth workshop, volunteer campaign, or community event. Critique for tone and risk.

**Everyday analogue:** brainstorming, moodboards, thumbnails, naming exercises.

**Novel tool angle:** image generation, multimodal prompting, rapid concept variation.

**Output:** three concept names or images plus one selected direction.

---

## Station D — Local vs Hosted Model

**Question:** What changes when the model runs locally?

**Tools:** facilitator laptop running a local model through Ollama, LM Studio, or similar; approved hosted model for comparison.

**Participant action:** Compare responses to the same small prompt. Note speed, privacy posture, quality, and use case.

**Everyday analogue:** local files vs cloud services.

**Novel tool angle:** model weights, runtime, interface, offline/private-adjacent workflows.

**Output:** boundary note: "I would use local for... / hosted for... / neither for..."

---

## Station E — Transcript to Action

**Question:** Can AI make an audio or meeting transcript useful without erasing nuance?

**Tools:** pre-recorded sample audio or transcript, speech-to-text if approved, summarizer.

**Participant action:** Turn a short transcript into action items, then check for missing decisions or invented tasks.

**Everyday analogue:** meeting notes, documentation, follow-up emails.

**Novel tool angle:** speech-to-text, summarization, action extraction.

**Output:** action list with confidence notes.

---

## Station F — Agent / Automation Sketch

**Question:** Where should automation stop?

**Tools:** printed workflow canvas, optional pre-staged agent demo.

**Participant action:** Sketch a tool that takes one input, performs 2–3 steps, and stops for human approval.

**Everyday analogue:** checklists, routing forms, approval workflows.

**Novel tool angle:** agents, tool calling, workflow automation, human-in-the-loop design.

**Output:** a human-approved automation sketch.
