# Start Here: Robot Mood Machines

## Make this

Change the prebuilt SPIKE robot so a partner can guess its mood. Record what you changed on your [`BEHAVIOR_CARD.md`](BEHAVIOR_CARD.md).

## Do this in order

1. **Choose a mood:** curious, helpful, efficient, shy, premium, playful, chaotic, or your own.
2. **Change one setting** first: speed, pause, turn, light, or sound.
3. **Run the robot in the marked test area.** Watch what an observer would actually see and hear.
4. **Change one more setting** only if a partner cannot guess the mood. Keep the rest of the program working.
5. **Write the Behavior Card:** circle the choices you used and explain what makes the robot feel that way.
6. **Show the before/after behavior** to another pair. Ask them to guess the mood before you reveal it.

## If you are stuck

- Mood feels unclear? Make speed or pause more obvious before adding features.
- Robot behaves unexpectedly? Return to the last working version and ask before changing hardware.
- Waiting for the robot? Complete the Behavior Card and predict how each control will change the mood.
