# Lunch Lab: Robot Mood Machines
## Design Behavior, Not Just Motion

## Defined objective

Participants remix a prebuilt LEGO Spike robot behavior to express a chosen mood, service style, or personality.

## Participant output

Robot behavior performance plus Behavior Card.

## Takeaway

A tiny robot performance and a Behavior Card.

## Technologies and materials

- LEGO Spike Prime kits
- prebuilt driving bases
- Spike app
- mood cards
- test mat

## Corporate/workplace relevance

Connects to UX, service design, automation, interaction design, and the emotional layer of technology.

## Best 45-minute version

Choose a mood and adjust speed, pause, turn, light, or sound.

## Best 60-minute version

Add one sensor-triggered behavior and a short demonstration.

## Good audience size

- Ideal: 8–16 participants.
- Manageable: 20–30 participants if run in pairs or stations.
- Large-room option: run as a table with timed rotations.

## Facilitation stance

Start with the artifact. Keep explanation short. Let adults touch the tool quickly. End by naming how the same pattern becomes a deeper youth learning pathway.
