# Sample Outputs: Robot Mood Machines

## Example 1

**Title:** First useful version  
**What happened:** A participant completed the core challenge.  
**Design note:** The result does not need to be polished; it needs to show a decision.

## Example 2

**Title:** Revised after testing  
**What happened:** A participant changed one parameter, behavior, sound, reading, or prompt after a first attempt.  
**Design note:** The revision is the learning.

## Example 3

**Title:** Workplace connection  
**What happened:** A participant connected the lab to observation, design, training, communication, or responsible use.  
**Design note:** Keep this connection optional but visible.

## Prompt bank

- What did the system do that surprised you?
- What did you change?
- What did the tool make easier?
- What still required human judgment?
- What would a longer youth version of this lab teach?
