# Session 01: Welcome & Image Scavenger Hunt

Mission: Introduce digital images as made objects and begin practicing composition through a scavenger hunt.
Lesson slug (for course.yaml): s01-welcome-image-scavenger-hunt
Slug rule: start with s01- and use lowercase letters, numbers, and dashes only.

Teacher prep
- Open the [Session 1–2 visual pack](../assets/session01-02/README.md).
- Confirm camera and saving workflow.
- Set boundaries for the scavenger hunt.

Materials
- Cameras or phones
- Shared save location or computers
- Projector

Agenda
- 0-20 min: welcome, framing, and norms
- 20-35 min: mini-lesson on composition
- 35-70 min: image scavenger hunt
- 70-85 min: import and quick share
- 85-90 min: exit reflection

Checkpoints
- Students capture several scavenger hunt images.
- Students name one composition idea they used or noticed.

Common stuck points + fixes
- Students take random snapshots only -> require one image for each specific prompt.
- Files get lost -> model saving before sharing.

Extensions
- Compare two images and choose the stronger composition.
- Add one caption about what the image is doing.

# Session 02: Cameras, Light & Composition

Mission: Strengthen intentional photography through light, framing, and viewpoint choices.
Lesson slug (for course.yaml): s02-cameras-light-composition
Slug rule: start with s02- and use lowercase letters, numbers, and dashes only.

Teacher prep
- Open the [Session 1–2 visual pack](../assets/session01-02/README.md).
- Check camera access and room movement plan.

Materials
- Cameras or phones
- Sample images
- Reflection notes

Agenda
- 0-15 min: image review and warm-up
- 15-35 min: mini-lesson on light and framing
- 35-75 min: guided shooting session
- 75-90 min: share and reflect

Checkpoints
- Students intentionally vary light or viewpoint.
- Students can explain one framing choice.

Common stuck points + fixes
- Students stay at eye level for every image -> require high, low, and close options.
- Images are too dark or flat -> change light direction or move the subject.

Extensions
- Try a mini photo series instead of one image.
- Shoot one subject three different ways.

# Session 03: Pixels & Resolution

Mission: Help students understand image size, resolution, and pixelation through a self-portrait study.
Lesson slug (for course.yaml): s03-pixels-and-resolution
Slug rule: start with s03- and use lowercase letters, numbers, and dashes only.

Teacher prep
- Prepare examples of high and low resolution.
- Set up the pixel self-portrait prompt.

Materials
- Computers
- Image editor
- Self-portrait source images or drawing tools

Agenda
- 0-15 min: discussion of pixels and file quality
- 15-35 min: mini-lesson on resizing and formats
- 35-80 min: pixel self-portrait work time
- 80-90 min: reflection

Checkpoints
- Students can describe what happens when images are resized poorly.
- Students begin a pixel self-portrait or equivalent study.

Common stuck points + fixes
- Students confuse pixel style with accidental low quality -> compare intentional and unintentional pixelation.
- File exports are inconsistent -> set one save format for class.

Extensions
- Compare JPG and PNG exports.
- Create a deliberately pixelated version and a smoother version.

# Session 04: Editing Basics: Tone & Color

Mission: Use basic tonal and color adjustments to change image readability and mood.
Lesson slug (for course.yaml): s04-editing-basics-tone-color
Slug rule: start with s04- and use lowercase letters, numbers, and dashes only.

Teacher prep
- Prepare one before/after editing demo.
- Check editor access and sample files.

Materials
- Computers
- Layer-based editor
- Student source images

Agenda
- 0-15 min: warm-up with before/after examples
- 15-35 min: mini-lesson on crop, exposure, levels, and color balance
- 35-80 min: guided edit and studio work
- 80-90 min: short share

Checkpoints
- Students complete one useful edit.
- Students explain what the edit changed.

Common stuck points + fixes
- Students over-edit immediately -> compare with the original and step back.
- Students adjust everything blindly -> focus on one tonal problem first.

Extensions
- Build two different moods from one image.
- Compare warm vs cool grading.

# Session 05: Layers, Masks & Collage

Mission: Introduce layers and masks through collage and composite image building.
Lesson slug (for course.yaml): s05-layers-masks-collage
Slug rule: start with s05- and use lowercase letters, numbers, and dashes only.

Teacher prep
- Prepare a simple mask demo.
- Gather image sources with clear usage expectations.

Materials
- Computers
- Layer-based editor
- Source images

Agenda
- 0-15 min: warm-up and compositing examples
- 15-35 min: mini-lesson on layers, selections, and masks
- 35-80 min: collage/composite work time
- 80-90 min: reflection

Checkpoints
- Students use more than one layer.
- Students use masking or selection to combine images.

Common stuck points + fixes
- Students erase destructively -> duplicate the layer and use masks instead.
- Composite edges look rough -> feather or refine selection edges.

Extensions
- Build a surreal self-portrait variation.
- Add hand-drawn elements to the collage.

Agenda

Checkpoints

Extensions

- Add a photo-driven and a graphic-driven version.

# Session 08: Retouching, Restoration & Ethics

Mission: Teach basic repair tools while discussing when image alteration becomes misleading or harmful.
Lesson slug (for course.yaml): s08-retouching-restoration-ethics
Slug rule: start with s08- and use lowercase letters, numbers, and dashes only.

Teacher prep
- Prepare one restoration demo and one ethics discussion image.

Materials
- Computers
- Image editor
- `resources/image-rights-and-ethics.md`

Agenda
- 0-20 min: ethics and restoration discussion
- 20-35 min: mini-lesson on clone/heal tools
- 35-80 min: guided retouching work
- 80-90 min: reflection

Checkpoints
- Students use one repair tool appropriately.
- Students can name a case where editing crosses into misrepresentation.

Common stuck points + fixes
- Students over-retouch skin or faces -> redirect toward restoration rather than perfection.
- Students cannot tell whether an edit is ethical -> discuss purpose, consent, and context.

Extensions
- Restore an old or damaged image.
- Annotate an image with “acceptable repair” vs “misleading change.”

# Session 09: Glitch & Experimental Imaging

Mission: Use glitch and image disruption as a creative strategy rather than an accidental error.
Lesson slug (for course.yaml): s09-glitch-and-experimental-imaging
Slug rule: start with s09- and use lowercase letters, numbers, and dashes only.

Teacher prep
- Prepare examples of glitch methods appropriate to available tools.

Materials
- Computers
- Image editor
- Source images

Agenda
- 0-15 min: glitch examples and discussion
- 15-35 min: mini-lesson on one or two safe glitch methods
- 35-80 min: experimental image making
- 80-90 min: reflection

Checkpoints
- Students create one experimental image.
- Students can explain the effect they were trying to create.

Common stuck points + fixes
- Students rely on randomness only -> ask what visual change they want, then choose a method.
- Files get corrupted beyond use -> duplicate before each new experiment.

Extensions
- Create a small glitch series.
- Combine glitch with collage or poster elements.

# Session 10: Generative Images with Code

Mission: Introduce images as something that can be transformed or generated algorithmically.
Lesson slug (for course.yaml): s10-generative-images-with-code
Slug rule: start with s10- and use lowercase letters, numbers, and dashes only.

Teacher prep
- Prepare a very small p5.js or similar demo.
- Confirm browser access and fallback plan.

Materials
- Computers
- Browser-based coding environment
- Sample images

Agenda
- 0-15 min: discussion of code-based image change
- 15-35 min: mini-lesson and shared sketch
- 35-80 min: guided modification and experimentation
- 80-90 min: share

Checkpoints
- Students modify or run a simple generative image sketch.
- Students connect one code change to one visual result.

Common stuck points + fixes
- Students freeze at code syntax -> focus on changing small values and observing results.
- Browser setup fails -> switch to teacher demo plus paper predictions or screenshots.

Extensions
- Save multiple outputs from one sketch.
- Combine code output with prior edited images.

Mission: Share finished work, practice critique, and reflect on growth in image-making and image-reading.

Slug rule: start with s12- and use lowercase letters, numbers, and dashes only.

Materials

Agenda
- 0-20 min: final setup

Checkpoints
- Students present final work.

- Turn reflection text into a public-facing artist note.
