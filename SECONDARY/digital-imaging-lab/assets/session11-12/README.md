# Session 11–12 visual pack

Use [`series-exhibition.svg`](series-exhibition.svg) twice:

- **Session 11:** ask students what repeats and changes across the three-image example, then apply that question to their own series.
- **Session 12:** use the export, title, order, and reflection checklist before quiet viewing begins.
