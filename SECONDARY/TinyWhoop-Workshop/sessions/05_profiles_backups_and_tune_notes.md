# Week 5 - Profiles, Backups & Tune Notes

**Theme:** Keep your setup legible enough to recover it.
**Tuesday focus:** Backup habits, filenames, screenshots, tune logs, and race setup notes
**Thursday focus:** Simulator race heats and documented real-lap practice
**Class length:** Two 90-minute meetings

---

## Goals

By the end of the week, students will:

- Save labeled backups after tuning changes.
- Record which profile they prefer and why.
- Build a simple tune log they can return to later.
- Connect simulator race results to profile and control choices.
- Fly short laps or repeated patterns on a documented setup.
- Explain why restore points matter before race preparation.

---

## Instructor Prep

- Prepare one example of a clear backup filename and one weak filename.
- Decide where students will store backups, screenshots, and tune notes.
- Prepare a tune-log template if your LMS or notebook system needs one.
- Confirm that students still have their Week 1 baseline backup.
- Prepare a simple VelociDrone heat format for Week 5: short races, clean-lap scoring, or best-improvement scoring.

---

## Materials

- Student quads and radios
- Laptops with Betaflight Configurator
- Shared folder, LMS space, or notebooks
- VelociDrone stations if available
- Indoor flight area
- Pre-flight checklist

## Tuesday Class - Backups, Tune Logs & Race Setup Notes

### 0:00-0:10 - Why Documentation Matters

- Explain common ways beginners lose progress:
  - no backup
  - unclear filenames
  - screenshots with no date
  - changing too many things at once
- Connect documentation to troubleshooting and race readiness.
- Connect documentation to simulator race improvement: students need to know what they flew when a lap suddenly improves.

### 0:10-0:30 - Naming Conventions

Show examples:

- Good: `studentname-whoop1-profileA-2026-04-04.json`
- Weak: `backup.json`
- Weak: `final-final-new.json`

Students create a naming pattern they will use for the rest of the course.

### 0:30-1:00 - Save and Label

Students:

1. Connect their quad.
2. Confirm the active rate profile.
3. Save a new backup with a meaningful filename.
4. Store it in the agreed location.
5. Record where it lives.

If students cannot connect, they document a partner's backup process and list what they would do when their quad is available.

### 1:00-1:20 - Build a Tune Log

Students create a short record with:

- date
- quad or team name
- active profile
- main rate choice
- simulator course or challenge name
- best clean-lap result so far
- OSD notes
- what felt better or worse last week
- next change, if any

### 1:20-1:30 - Simulator Seed Time or Exit Ticket

If time and stations allow, students run one seed lap for Thursday's simulator heats. Otherwise, they answer:

- My current restore point is...
- The setting or profile I most need to remember is...
- My simulator race goal is...

## Thursday Class - Simulator Race Heats & Documented Practice

### 0:00-0:15 - Race Brief and Documentation Check

Students:

- Use the pre-flight checklist.
- Confirm which backup represents their current setup.
- Confirm the profile they will fly.
- State one thing they are not changing today.
- Review simulator heat rules: clean laps, calm resets, and sportsmanship matter.

### 0:15-0:55 - VelociDrone Race Heats

Run short simulator heats or time trials.

Suggested formats:

- best clean lap
- three-lap consistency challenge
- fewest resets in a timed run
- best improvement from Week 4

Students record:

- profile/settings used
- result
- crash/reset count
- one control habit that helped

### 0:55-1:15 - Controlled Real Laps on a Known Setup

Students fly short laps or repeated patterns on the setup they documented.

Focus on:

- same takeoff ritual
- same profile
- same course segment
- same landing routine
- consistency over experimentation

If a student changes anything, they must record the change before flying again.

If real-flight readiness is limited, use this time for additional sim heats or bench troubleshooting.

### 1:15-1:23 - Debrief: Stable or Not?

Ask students:

- Did the quad behave the way the notes predicted?
- Did the profile still feel right?
- Did simulator competition reveal a control habit to practice?
- What should stay locked for now?
- What might need work before race day?

### 1:23-1:30 - Exit Ticket

Students answer:

- What profile would I put on the line tomorrow?
- What evidence tells me that?
- What simulator race habit should transfer to real flight?

---

## Evidence of Learning

- Student creates a labeled backup.
- Student completes a tune log entry.
- Student participates in a simulator heat or time trial.
- Student flies or supports a practice run using a documented setup.

---

## Notes & Variations

- If you already use a class notebook or LMS, keep all tune notes there.
- If time is short, prioritize backups before flights.
- If hardware is unstable, use the day to document symptoms and make a repair plan.
