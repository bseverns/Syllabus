# Betaflight Tiny Whoop Demo Worksheet Pack

Markdown worksheet pack for a beginner-friendly Drone Course using tiny whoops and Betaflight.

## Files

- `01_student_worksheet.md` — main student-facing Betaflight setup worksheet.
- `02_teacher_guide.md` — instructor notes, key settings, and recommended boundaries.
- `03_quick_safety_checklist.md` — short pre-config and pre-flight checklist.
- `04_rates_tuning_lab.md` — student-friendly rates/expo/throttle feel activity.
- `05_config_record_sheet.md` — simple sheet for recording each drone's settings.

## Course Framing

The first goal is not maximum performance. The first goal is a whoop that is:

- safe
- recoverable
- readable
- personally flyable

Students should learn to verify the machine's truth before they start changing its personality.
