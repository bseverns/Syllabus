# Session 01: What is Sound? + Critical Listening

Mission: Build shared sound vocabulary and listening habits by comparing tone, timbre, and envelope.
Lesson slug (for course.yaml): s01-what-is-sound-critical-listening
Slug rule: start with s01- and use lowercase letters, numbers, and dashes only.

Teacher prep
- Test playback levels and headphones.
- Prepare short examples of sine-like, noisy, and complex sounds.
- Post the day’s file-naming expectations.

Materials
- Chromebooks or phones with BandLab or a spectrum app
- Headphones
- Projector or speakers

Agenda
- 0-5 min: hook with contrasting sounds
- 5-15 min: mini-lesson on frequency, amplitude, timbre, and ADSR
- 15-30 min: guided listening and spectrogram observations
- 30-55 min: station work and vocabulary application
- 55-60 min: exit ticket

Checkpoints
- Students can use at least three vocabulary terms correctly.
- Students can describe one sound difference they heard.

Common stuck points + fixes
- Students describe sounds only as “good” or “bad” -> prompt for timbre, pitch, loudness, or shape.
- Students rush through listening -> require one written observation before moving on.

Extensions
- Compare a voice recording to a synth tone.
- Sketch a waveform shape and predict how it will sound.

# Session 02: Phone Recording 101

Mission: Capture cleaner voice and object recordings using mic placement, room tone, and basic gain awareness.
Lesson slug (for course.yaml): s02-phone-recording-101
Slug rule: start with s02- and use lowercase letters, numbers, and dashes only.

Teacher prep
- Test a bad-vs-good recording example.
- Prepare a simple sonic ID demo.
- Mark quiet and noisy recording zones in the room.

Materials
- Phones
- Windscreens or simple phone stands
- Headphones

Agenda
- 0-5 min: A/B bad and good phone recordings
- 5-15 min: mini-lesson on mic distance, off-axis placement, and room tone
- 15-30 min: guided sonic ID recording
- 30-55 min: students record three takes and choose the best one
- 55-60 min: correctly named upload

Checkpoints
- Students upload a correctly named file.
- Students can explain one thing they changed to improve the recording.

Common stuck points + fixes
- Handling noise is too loud -> rest the phone or use a stand.
- Recording clips are distorted -> move farther away or reduce input level.

Extensions
- Record the same object from two different distances.
- Try one recording that feels intentionally close and one intentionally distant.
