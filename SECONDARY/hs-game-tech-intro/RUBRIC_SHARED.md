# Shared Rubric – Scratch & micro:bit Intro Courses

Use this rubric for most assignments in both courses.

- **10-point build/code assignments** (Weeks 1–5)
- **20-point final projects** (by doubling or using two passes)
- **5-point questions/exit tickets** (using only the Vocabulary & Reflection row)

## 3-Column Rubric

| **Criteria**                | **Full credit**                                                                                                     | **Partial credit**                                                                                       | **Limited / no credit**                                                                                      |
|-----------------------------|---------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------|
| **Participation & Process** | Student is on task for most of the work time, actively trying ideas, asking questions when stuck, and using class resources appropriately. | Student is on task some of the time but is easily distracted, needs reminders to re-engage, or only tries a small number of changes. | Student is mostly off task, frequently stops working, or does not attempt to engage with the activity.      |
| **Completion & Quality**    | Required parts of the assignment are completed; the project runs; changes are clearly visible and match the instructions (e.g., keys changed, variable added, housing built). | Some parts of the assignment are completed, but instructions are only partly followed, or the project has noticeable problems (e.g., doesn’t always run as described). | Little or no work is completed, or the project is non-functional with no serious attempt to fix it.         |
| **Vocabulary & Reflection** | Student uses at least one target vocabulary word correctly in their written or verbal work (e.g., event, condition, variable, input, output, sensor, algorithm, bug, debugging) and explains changes or design choices in clear, concrete language. | Student attempts to use vocabulary but uses it vaguely or with minor mistakes, or gives a very short/basic explanation of changes. | Student does not use course vocabulary or reflection is missing, off-topic, or only one or two unclear words. |

## Suggested Point Mapping

For a **10-point assignment**:

- Participation & Process: 0–3 points  
- Completion & Quality: 0–4 points  
- Vocabulary & Reflection: 0–3 points  
- **Total:** up to 10 points

For a **20-point final project**:

- Either double the above (e.g., 6 + 8 + 6 = 20), or  
- Score once with the rubric, then add a second pass focusing on improvement since earlier weeks.

For a **5-point question / exit ticket**:

- Use only the **Vocabulary & Reflection** row:
  - Full credit answer → **5 pts**
  - Partial credit → **3 pts**
  - Limited / no credit → **1–0 pts**
