# Facilitator Prep — HS Game & Tech Intro

Use this before publishing the existing Google Classroom posts. The posts are the student-facing delivery surface; this file makes their starter-project and device choices real.

## 9th Grade — Scratch

1. Open [Scratch](https://scratch.mit.edu/) and build one working mini-game starter using the existing [10-minute build checklist](../../PRIMARY/Scratch-Game-Design-Animation_Grades3-5/05_Starter-Project_Build-Recipe/Build_Checklist_10min.md).
2. Test that the starter has movement, a visible change students can make, a collision/goal condition, and a score/lives/timer path. These are the six-course changes named in the 9th-grade syllabus.
3. Share the starter in the school-approved Scratch account and test that a student can remix or save a copy.
4. Paste that tested URL into the one marked line in [`9th-scratch/GOOGLE_CLASSROOM_9TH_SCRATCH.md`](9th-scratch/GOOGLE_CLASSROOM_9TH_SCRATCH.md) **before** publishing the Week 1 assignment.
5. Keep student projects private until the student chooses to share and the teacher approves the content.

## 10th Grade — micro:bit

1. Open the [MakeCode micro:bit editor](https://makecode.microbit.org/) on a student device.
2. Build and download the `MoodFace` example: start icon, Button A face, Button B face.
3. Build and download `GestureTester`: shake plus left/right tilt responses.
4. Check each micro:bit, cable, browser permission, and download path. Use the local-board comparison note in [`10th-microbit/SYLLABUS_10TH_MICROBIT.md`](10th-microbit/SYLLABUS_10TH_MICROBIT.md) rather than assuming every board revision is identical.
5. Stage cardboard, tape, and the cutting boundary before the physical-housing session.

## Both tracks

- Publish the matching Google Classroom posts only after the links and device path are tested.
- Create the private turn-in location before Session 1: project link or file, one screenshot/photo, and the short reflection named in the relevant grading file.
- If a platform fails, keep the lesson moving with the teacher demo and a paper code/logic trace; do not ask students to create accounts or change platforms during class.
