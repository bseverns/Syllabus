# HS Game & Tech Intro – Scratch + micro:bit

This repo holds materials for two related but independent high school tech-credit courses:

- **9th Grade – Intro to Games & Code with Scratch**
- **10th Grade – Intro to Physical Computing with micro:bit**

Both courses are:

- **6 class meetings**, ~60 minutes each, during the school day.
- Aimed at students with **little or no programming experience**.
- Focused on **reading and tweaking** existing projects and learning the **vocabulary** of computing.

## Philosophy

These are **gentle introductions**:

- 9th grade focuses on **how games work**: sprites, events, conditions, variables, feedback.
- 10th grade focuses on **how small computers work**: inputs, outputs, sensors, algorithms, bugs, debugging.

The emphasis is on:

- Changing existing code and noticing what happens.
- Naming what students see with accurate but accessible vocabulary.
- Light, low-stakes assessment based on effort, completion, and use of terms.

You can hook these into Google Classroom using the content in the `GOOGLE_CLASSROOM_*.md` files.

## Before teaching

Use [`FACILITATOR_PREP.md`](FACILITATOR_PREP.md) to stage the Scratch starter/remix URL, test the MakeCode download path, and publish the existing student-facing Google Classroom posts only after both tracks work on student devices.
