# Contributing Guidelines

This repo is designed as a teaching artifact for high school tech-credit courses built around Scratch (9th grade) and the BBC micro:bit (10th grade).

If you are adapting this for your own classroom or institution, feel free to:

- Fork the repo and rename it to match your context.
- Edit the syllabi to match your schedule (more/less weeks, longer periods, etc.).
- Swap out tools (e.g., different block languages or hardware) while keeping the same structure:
  - Mini-lesson
  - Guided practice on a starter project
  - Short reflection using vocabulary

## Making Changes

When you make changes, try to:

1. Keep student-facing language clear and concrete.
2. Preserve or adapt the vocabulary emphasis in each week.
3. Note local changes (e.g., different grading scale, different hardware) in the appropriate syllabus or grading file.

If you’re working with others:

- Use branches or pull requests to propose changes.
- Include a short note in the PR describing which course (9th/10th) and which week you’re modifying.
