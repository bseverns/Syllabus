# Glossary (Quick)

- **CAD** — Computer‑Aided Design, where you model geometry.
- **CAM** — Computer‑Aided Manufacturing, where you create toolpaths.
- **Slicer** — Converts 3D models into printer instructions (G‑code).
- **G‑code** — The motion/control language machines follow.
- **WCS** — Work Coordinate System (your X/Y/Z zero point).
- **DOC** — Depth of Cut (how deep each pass goes).
- **Kerf** — Width of material removed by a tool or laser.
