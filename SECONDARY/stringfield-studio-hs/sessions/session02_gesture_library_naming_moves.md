# Session 02 – Gesture Library: Naming the Moves

## At a glance

- **Length:** 90 minutes  
- **Mode:** Hands-on + documentation  
- **Goals:**
  - Build a shared, named library of string gestures.
  - Record short audio examples of each gesture.
- **Deliverables:**
  - Labeled audio clips for 6–10 core gestures.

## Before class (instructor)

- Prepare a simple recording setup (DAW or portable recorder).
- Create a naming convention, e.g.: `gesture_short_pluck_01.wav`.

## In-class plan

### 0–15 min — Review & warm-up

- Revisit gesture categories from Session 01.
- Quick demo of a few favorites.

### 15–30 min — Decide on core gesture set

- As a class, pick 6–10 “core gestures” to document.
  - e.g., short pluck, long slide, scratch, palm mute, tap, harmonic.

### 30–70 min — Record the gesture library

- In small groups:
  - Each group is responsible for 2–3 gestures.
  - Record 2–3 takes of each gesture (2–5 seconds).
  - Name files using the agreed convention.
- Rotate groups through the instrument(s) as needed.

### 70–85 min — Listen & tag

- Quickly audition a few recordings.
- Confirm that file names make sense and are consistent.

### 85–90 min — Exit ticket

- “Which gesture from the library sounds least like you expected?”

## After class / Homework

- Instructor organizes clips into a shared folder.
