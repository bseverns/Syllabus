# Classroom Setup Checklist

Use this before Session 1 so the course runs like a studio instead of a scramble.

## Instruments and audio

- Confirm how many string rigs or alternate instruments are available.
- Test each rig for stable sound output.
- Set a starting volume that is audible but not aggressive.
- Check cables, interfaces, batteries, and power supplies.
- Decide where each station lives in the room.

## Recording workflow

- Choose your main recording method:
  - laptop DAW
  - handheld recorder
  - phone or tablet recorder
- Test one complete path from recording to saved file.
- Create a shared folder structure before students arrive.
- Decide who is allowed to rename, move, or delete files.

## Drawing and documentation

- Prepare paper, index cards, or sketchbook pages for gesture maps.
- Prepare markers, pencils, tape, and clipboards if students move around.
- Decide whether you will photograph or scan gesture maps after Session 3.

## Projection and playback

- Test projector or display if you plan to show visuals.
- Test classroom speakers for playback of student work.
- Have headphones available for quieter review.

## Safety and room culture

- Decide on a clear rule for maximum volume.
- Decide how students move between stations.
- Plan where students can wait, draw, or reflect when it is not their turn.
- Identify any sensory or access concerns before the first sound check.

## Staffing and rotation

- Decide whether students work solo, in pairs, or in small groups.
- Set a rotation plan for classes larger than the number of rigs.
- Identify which moments require direct instructor supervision:
  - first exploration
  - first recordings
  - final playback and showing

## Low-tech fallback plan

- Have one backup instrument or sound source ready.
- Have a paper-only version of the gesture-map exercise ready.
- If recording fails, be ready to run a listening, drawing, and live-performance day instead of stopping the course.
