# Recording and File Management

This course gets messy fast if students cannot find their own work. Use one clear system and stick to it.

## Recommended folder structure

```text
stringfield-studio/
  class_gesture_library/
  student_work/
    lastname_firstname/
      gesture_maps/
      raw_recordings/
      drafts/
      final/
```

If students use school drives, mirror the same structure in the LMS or cloud folder.

## File naming rules

Use plain, searchable names with no spaces.

Recommended patterns:

- `lastname_firstname_gesture_shortpluck_take01.wav`
- `lastname_firstname_gesturemap01.jpg`
- `lastname_firstname_soundsketch01_take02.wav`
- `lastname_firstname_finalpiece_v03.wav`
- `lastname_firstname_artiststatement.md`

## Minimum student habits

Students should be able to answer:

- Where is my current folder?
- Which file is the newest version?
- Which file is the final export?
- Which drawing matches this recording?

Build two minutes of saving and labeling into every session. Do not leave it for the end.

## Suggested daily closeout

Before students leave:

1. Save the current file.
2. Export or back up the newest version if needed.
3. Rename it using the class convention.
4. Put it in the right folder.
5. Write one sentence describing what changed today.

## Recording tips

- Record a short level-check before each round.
- Keep raw takes even if students think they are bad.
- If the room is noisy, note the noise rather than pretending it is not there.
- Photograph or scan gesture maps on the same day they are created.
- Keep one class archive folder that only the instructor edits.

## If you only have one recording station

- Assign waiting students to drawing, listening, or reflection work.
- Use pairs so one student performs while the other runs the recorder and labels files.
- Record fewer takes, but label them well.

## If students record at home

- Keep accepted formats simple: `wav`, `mp3`, or `m4a`.
- Require the same naming convention as class recordings.
- Ask for one sentence about where and how the sound was made.
