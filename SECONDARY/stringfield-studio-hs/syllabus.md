# StringField Studio Syllabus

## Overview

StringField Studio is an 8-session high school studio course where students investigate how gesture becomes sound and how sound can be planned, drawn, recorded, layered, and shared. The course treats a string instrument or StringField-style rig as both an instrument and a mark-making system.

Students do not need prior music or coding experience. What they do need is patience, curiosity, and a willingness to listen closely.

## Course snapshot

- **Audience:** Grades 9-12
- **Length:** 8 sessions x 90 minutes
- **Format:** studio / lab with demos, hands-on exploration, recording, and reflection
- **Core tools:** one or more StringField-style rigs or alternate string instruments, recording setup, headphones, paper and markers
- **Optional tools:** p5.js or Processing for basic visuals

## Essential questions

- How does a gesture become a sound?
- How can a drawing act like a score or performance plan?
- What changes when a gesture is recorded, layered, or looped?
- How much control do I actually have over an instrument, a room, or a recording?

## Learning outcomes

By the end of the course, students should be able to:

- describe and demonstrate several distinct string gestures
- document sounds with clear labels and file names
- translate audio ideas into visual marks and visual marks into performance
- build a short composition using contrast, layering, and pacing
- present work using specific language about gesture, texture, and structure
- reflect on what felt intentional, accidental, controllable, and surprising

## Student artifacts

Students should leave the course with:

- a shared class gesture library
- at least one gesture map drawing
- one recorded sound sketch
- one layered or looped draft
- one final 60-120 second piece
- one short artist statement or reflection

## Session arc

### Session 1 - Meet the String
- Explore the instrument and establish safety.
- Start a shared vocabulary of gestures.

### Session 2 - Gesture Library
- Name, record, and organize 6-10 core gestures.
- Practice documentation and file naming.

### Session 3 - Sound Drawing
- Draw marks for known sounds.
- Build a gesture map that can be performed.

### Session 4 - Recording Sound Sketches
- Perform gesture maps and record short takes.
- Match recordings to drawings and titles.

### Session 5 - Layers and Loops
- Thicken recordings through layering and repetition.
- Notice contrast in density, volume, and pacing.

### Session 6 - Optional Visuals or Extra Audio Studio
- Build simple reactive visuals, or use the time for more audio refinement.

### Session 7 - Compose a Short Piece
- Shape material into a clear arc with a beginning, middle, and end.
- Use peer feedback to revise.

### Session 8 - Studio Showing and Reflection
- Share finished work.
- Reflect on gesture, sound, and process.

## Materials and setup

- 1 or more StringField rigs, monochords, or alternate string instruments
- recording device or DAW
- headphones
- paper, markers, pencils
- projector and speakers
- storage plan for audio files and images of student drawings

Use `resources/classroom_setup_checklist.md` before launch and `resources/recording_and_file_management.md` to keep the archive usable.

## Assessment approach

Assessment should stay studio-oriented. Reward listening, experimentation, documentation, and revision rather than technical polish alone.

Suggested weighting:

- **30% Process and participation**
- **30% Documentation and artifact care**
- **40% Final piece and presentation**

Use `rubrics/final_piece_rubric.md` as the main scoring tool for the culminating presentation.

## Participation expectations

Students are expected to:

- handle instruments and recording gear carefully
- respect volume limits and listening needs
- save files with usable names
- contribute to peer feedback
- try multiple gestures before settling on one idea
- reflect on what they changed and why

## Adaptation notes

This course still works if you do not have a formal StringField rig.

Possible substitutes:

- a monochord or single amplified string
- a classroom instrument with a limited set of strings
- an electric guitar or bass used in a highly restricted way
- contact-mic experiments on a stringed object

If setup is limited, reduce the number of simultaneous stations and lean harder on rotation, drawing, and listening while students wait their turn.
