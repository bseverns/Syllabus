# Microsoft Learn Implementation Notes

## Recommended stance
Use Microsoft Learn as a structured backbone, not as the only learning experience.

## Best use in this course
- assign short Learn segments on distance-learning days
- capture notes in the study log
- bring Learn vocabulary back into practicum work
- use Week 6 for mock review and next-step planning

## Before launch, verify
- current AI fundamentals certification title
- current exam code and page
- current module collection
- whether learners need accounts, school email addresses, or vouchers
- whether any labs require Azure resources you do not want students provisioning

## Practical caution
For this age group and course goal, do not let cloud setup complexity swallow the class. Prefer concept modules, knowledge checks, glossary work, and teacher-curated application tasks.
