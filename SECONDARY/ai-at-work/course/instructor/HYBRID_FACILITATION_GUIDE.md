# Hybrid Facilitation Guide

## Default weekly rhythm
- Day 1 in-person: launch and model
- Day 2 distance-learning: Learn module + notes + short artifact
- Day 3 in-person: studio task and correction
- Day 4 distance-learning: quiz + portfolio update + bridge note

## What continuity looks like in practice
- Every remote day begins with a checklist students recognize
- Every remote day ends with an uploaded artifact and bridge note
- Every in-person day starts from that evidence rather than starting over

## Distance-learning options

### Async-light model
- LMS post with checklist
- Microsoft Learn module(s)
- one notes page
- one uploaded artifact
- one bridge note

### Sync-light model
- 15 minute live kickoff
- independent Learn work and artifact creation
- end-of-session check-in or office hour

## What to avoid
- remote tasks that are only passive consumption
- changing tool locations every week
- unclear due dates
- remote work that does not feed directly into the next in-person session
