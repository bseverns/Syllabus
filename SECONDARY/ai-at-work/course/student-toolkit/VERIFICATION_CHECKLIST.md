# Verification Checklist

Before using AI output in real work, check:

- Did I compare this to the source material?
- Did I look for missing details?
- Did I look for made-up facts, names, dates, or links?
- Did I rewrite anything that sounds robotic or unclear?
- Is the tone right for the audience?
- Did I remove anything private, sensitive, or inappropriate?
- Would I be comfortable putting my name on this?
- Does a human need to review this before it is used?
- Can I explain which AI concept this task actually used?
