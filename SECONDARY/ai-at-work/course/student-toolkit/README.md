# Student Toolkit

These files are meant to be copied for each student so they leave the course with a real, reusable professional toolkit.

Recommended first-day move:
- make a folder called `ai-at-work-toolkit`
- duplicate each template into that folder
- rename files with the student's name or initials
- keep versions rather than overwriting everything
- add Microsoft Learn evidence in the same system so study and practice stay connected

## Core reference docs

These two files are not templates. They are the course's stable reference layer for AI concepts and systems thinking:

- `AI_SYSTEMS_FLOW_REFERENCE.md`
- `AI_DEEPER_DIVES_AND_REFERENCES.md`

Suggested use:
- use `AI_SYSTEMS_FLOW_REFERENCE.md` during weeks 1-3 when learning search, software, machine learning, generative AI, privacy, and verification
- use `AI_DEEPER_DIVES_AND_REFERENCES.md` when students want a trustworthy place to read further without falling into hype, random blogs, or isolated social posts

## Working rule

Keep the templates and the reference docs in the same folder system. The goal is for students to leave with both:
- reusable workplace tools
- a stable concept map they can return to later
