# Session 14: Distance Study: Vision / NLP / Generative AI Review

## Mode
**Distance-learning**

## Week
Week 4

## Session focus
Students revisit Microsoft Learn-aligned concept areas that now connect to the communication tasks they are actually doing.

## Learning targets
- Complete assigned Learn segment
- Update progress tracker
- Link one concept to this week's practicum artifact

## Microsoft alignment
Vision, NLP, and generative AI review

## Materials
- device and internet access
- shared docs or LMS
- notebook or reflection sheet
- Microsoft Learn access or teacher-posted module links
- course toolkit templates

## Session flow (2 hours)
### 1. Launch checklist (10 min)
- open the progress tracker and study log
- review the task list
- gather the files you need from the last in-person session
### 2. Microsoft Learn / assigned study work (40 min)
- complete the selected module or segment
- take notes on new vocabulary
- record any knowledge check results
### 3. Applied artifact (25 min)
- make one small product that uses the concept
- connect at least one idea back to real workplace practice
### 4. Reflection and upload (25 min)
- update the study log or vocabulary file
- upload the artifact
- complete the bridge note
### 5. Exit check (10 min)
- confirm everything is saved in the correct folder
- note one question to bring back in-person

## Suggested artifact
- progress tracker update + concept connection note
- one reflection note or bridge note
- one saved versioned file

## Continuity note
This session should visibly connect to the previous one and feed the next one. Do not let the artifact disappear after completion; it should travel into the student's toolkit or review folder.

## Facilitator notes
- keep the pace steady
- make quality visible
- reward revision
- call attention to hidden workplace rules when they appear
- name where the Microsoft concept is useful in real work rather than as isolated trivia
