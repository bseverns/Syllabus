# Assessment Rubric

## Assessment model
Competency-based, portfolio-driven, practical, and hybrid-aware.

## Categories

### 1. Systems understanding
**Emerging**
- Can repeat vocabulary but struggles to explain what tools do

**Developing**
- Can explain basic differences between search, chat, machine learning, and generation

**Proficient**
- Clearly explains how AI tools function at a practical level and where they are limited

**Strong**
- Applies this understanding when choosing tools and workflows

### 2. Prompting skill
**Emerging**
- Prompts are vague, short, or missing context

**Developing**
- Prompts include some task and audience information

**Proficient**
- Prompts use role, task, audience, format, and constraints well

**Strong**
- Prompts are efficient, reusable, and tuned for workflow quality

### 3. Verification and revision
**Emerging**
- Accepts outputs too quickly

**Developing**
- Notices some errors but misses important issues

**Proficient**
- Checks sources, improves drafts, and identifies uncertainty

**Strong**
- Uses a repeatable process for testing, revising, and documenting changes

### 4. Professional communication
**Emerging**
- Work is understandable but inconsistent in tone or structure

**Developing**
- Produces mostly clear communication with support

**Proficient**
- Produces clear, audience-aware, workplace-appropriate communication

**Strong**
- Adapts voice and structure across contexts while maintaining clarity

### 5. Workflow independence
**Emerging**
- Needs frequent support to move between steps

**Developing**
- Can complete a sequence with prompts and reminders

**Proficient**
- Can complete a repeatable workflow with moderate independence

**Strong**
- Can explain, improve, and transfer a workflow to new situations

### 6. Credential-readiness habits
**Emerging**
- Rarely completes Microsoft Learn notes or remote checkpoints

**Developing**
- Completes some study tasks but inconsistently tracks understanding

**Proficient**
- Completes Microsoft Learn tasks, tracks vocabulary, and uses review tools productively

**Strong**
- Connects Microsoft Learn concepts back to workplace practice and can explain why they matter

## Evidence sources
- folder checks
- prompt notebook
- revision artifacts
- scenario outputs
- reflection notes
- Microsoft Learn progress tracker
- study / vocabulary log
- final capstone and presentation
