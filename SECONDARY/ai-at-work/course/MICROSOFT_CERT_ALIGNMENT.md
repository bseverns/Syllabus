# Microsoft Certification Alignment

## Primary recommendation

This course is best aligned to a **Microsoft AI fundamentals study spine** for all students.

For cohorts launching **before June 30, 2026**, **Microsoft Azure AI Fundamentals (AI-900)** is still a workable exam target.

For cohorts launching **after June 30, 2026**, staff should plan around the current replacement fundamentals offering on Microsoft Learn rather than hard-coding AI-900 into the course pitch.

Why a Microsoft AI fundamentals spine is the right fit here:
- it is introductory rather than deeply technical
- it rewards concept understanding and vocabulary building
- it can sit beside workplace practice instead of replacing it
- it gives students a recognizable credential target without requiring them to become cloud engineers

## How the course uses Microsoft Learn

Microsoft Learn is used here in a supporting role:
- to provide structured concept modules
- to reinforce vocabulary with knowledge checks
- to give students a recognizable external learning environment
- to build confidence with self-directed professional study

## Recommended credential model

### Tier 1 — Core for all students
- Microsoft Learn account setup
- selected AI fundamentals modules
- vocabulary / glossary logging
- weekly knowledge checks
- mock exam-style review in Week 6

### Tier 2 — Optional for students ready to go farther
- sit the current Microsoft AI fundamentals exam if the partner can support scheduling / vouchers
- continue into additional Microsoft Learn AI, data, or productivity pathways after the course
- build a stronger LinkedIn / resume narrative around the capstone and Learn progress

## AI fundamentals concept domains this course is designed to support

The sequence broadly supports these idea clusters:
1. AI workloads and responsible AI considerations
2. Machine learning fundamentals
3. Computer vision concepts
4. Natural language processing concepts
5. Generative AI concepts and practical use

## Important implementation note

This repo does **not** assume that every student must sit the certification exam during the 6-week course. For many cohorts, the better pattern is:
- finish the course
- complete the capstone
- identify students who want to continue
- schedule exam preparation or exam sitting as a follow-on support track

## Live verification note

Microsoft's live materials currently show that **Exam AI-900 retires on June 30, 2026** and that Microsoft is introducing successor AI credentials in 2026. Before launch, staff should verify:
- current credential name(s)
- exam availability and age requirements
- whether the cohort should use AI-900 or its successor
- Microsoft Learn collection links
- whether the Learn materials now use Microsoft Foundry terminology
- voucher options, if any
- any updated domain wording or weighting
