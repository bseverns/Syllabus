# Hybrid Continuity Model

## The problem this solves

Hybrid courses break when distance-learning feels like a disconnected side room. This model keeps all four days of each week tied together so that students feel one sequence, not four separate classes.

## Weekly continuity spine

### Day 1 — In-person launch
Students receive:
- the week's question
- the core concept model
- a first guided artifact
- the exact checklist for Day 2

### Day 2 — Distance-learning build
Students complete:
- a Microsoft Learn module or assigned segment
- guided notes in the vocabulary / study log
- one small evidence artifact
- a bridge note naming what they understood and where they are stuck

### Day 3 — In-person studio
Facilitator begins by using Day 2 evidence:
- sort common misunderstandings
- repair weak spots
- move into the week's main practicum task
- ask students to reuse what they learned remotely

### Day 4 — Distance-learning consolidation
Students complete:
- a short quiz or retrieval task
- portfolio or toolkit update
- revision of one artifact from the week
- a bridge note that prepares the opening of the next week

## Stable routines to keep every week feeling legible

Use these same items every week:
- launch checklist
- Microsoft Learn progress tracker
- study / vocabulary log
- bridge note
- saved artifact in the same folder structure

## Facilitator continuity moves

- open every in-person day by projecting 2-3 anonymous examples from the remote day
- keep naming conventions identical every week
- require one uploaded artifact on every distance-learning day
- never assign a remote task that is only passive watching or reading
- make the remote task visibly useful for the next in-person session

## Suggested grading split

- 50% in-person studio artifacts
- 20% distance-learning evidence completion
- 15% Microsoft Learn study log / progress
- 15% capstone and presentation
