# Session 01: Welcome to AI at Work + Microsoft Pathway

Mission: Launch the course, map where AI appears in work and daily life, and set up the course toolkit and folder structure.
Lesson slug (for course.yaml): s01-welcome-to-ai-at-work
Slug rule: start with s01- and use lowercase letters, numbers, and dashes only.

Teacher prep
- Confirm access to shared docs or LMS.
- Prepare one strong and one weak AI example.
- Duplicate toolkit templates students will start using.

Materials
- Device and internet access
- Shared docs or LMS
- Reflection sheet or notebook
- Microsoft Learn access or staff-posted links
- Course toolkit templates

Agenda
- 0-15 min: opening and workplace framing
- 15-35 min: mini-lesson and examples
- 35-55 min: guided practice
- 55-100 min: studio artifact build
- 100-120 min: debrief and bridge setup

Checkpoints
- Students explain the course question in plain language.
- Students set up a first-pass folder structure.
- Students save an initial artifact or reflection.

Common stuck points + fixes
- Students treat AI as only hype or only cheating -> anchor in real workplace tasks.
- File organization is weak from the start -> model naming and folder rules explicitly.

Extensions
- Add first glossary entries.
- Start a prompt notebook immediately.
