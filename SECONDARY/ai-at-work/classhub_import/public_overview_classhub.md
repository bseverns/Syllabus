# AI at Work with Microsoft Learn

Course slug: ai_at_work
Grade level: 9th-12th
Session length: 120 minutes
Total sessions: 24
UI Level: secondary

## Course overview

This hybrid workforce course helps high school students use AI tools in professional settings without giving up judgment, privacy, or responsibility. Students learn the foundations of digital work systems, prompting, verification, privacy, bias, and professional communication, then apply those skills in workplace-style simulations and repeatable document workflows.

The course also includes a Microsoft Learn-aligned study thread so students build familiarity with current AI fundamentals concepts while creating practical artifacts they can actually reuse.

## Learning goals

By the end of the course, students will be able to:

- explain major AI concepts in plain language
- distinguish between search, chat, generation, automation, and machine learning workloads
- write stronger prompts using context and audience awareness
- verify and revise AI-generated drafts against source material
- identify privacy and professional-risk concerns
- build a reusable toolkit of templates, prompts, and checklists
- demonstrate one complete AI-supported workplace workflow

## What students make

Students build:

- a digital folder structure
- a prompt notebook
- verification and workflow checklists
- workplace-style templates
- Microsoft Learn study evidence
- a capstone workflow demonstration

## Course format

Each week follows a repeatable hybrid pattern:

1. in-person launch and model
2. distance-learning Microsoft Learn and evidence task
3. in-person studio and coaching
4. distance-learning reflection, quiz, or toolkit update

## Tools and materials

- browser and internet access
- shared docs or LMS
- word processing and presentation tools
- selected AI tools approved by staff
- Microsoft Learn modules chosen by staff
- student toolkit templates

## Assessment

Assessment emphasizes:

- systems understanding
- prompt quality
- verification habits
- workplace communication
- workflow independence
- portfolio evidence

## Final showcase

Students present a personal AI-at-work toolkit and one end-to-end professional workflow that shows where AI helped, where judgment mattered, and what they would carry into future work or certification study.
