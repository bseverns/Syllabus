# Live Media Lab: Sound, Projection & Generative Performance

A four-session high-school pilot where learners make a timed visual-and-sound study, test it in a real room, and leave another person a usable run sheet.

> **PILOT READY:** A lead facilitator can run the single-screen/projector pathway as written. It needs a real delivery review before public promotion.

## Run this

1. Read [`SYLLABUS.md`](SYLLABUS.md) and choose the screen-only or one-projector pathway.
2. Pre-test a single browser-based visual tool, playback device, speaker, and cable route.
3. Keep cable paths taped down, volume bounded, and a screen-only fallback ready.
4. Record room constraints, software friction, and reset time after Session 4.
