# Syllabus — Live Media Lab

## Course snapshot

- **Promise:** learners make a timed visual-and-sound system, test it under real room conditions, and document how it can run again.
- **Group / staffing:** 10–16 learners; one lead plus an assistant recommended for projection, sound, and cable management.
- **Final share:** a short live/semi-live study and a run sheet.
- **Agreement:** *The room is part of the system.*

## Materials for 12 learners

Six or more laptops with a single approved browser-based visual tool; headphones; one projector or shared display; one speaker; audio files or approved recordings; power strips; gaffer/painter's tape; adapters; extension leads; paper storyboards; and run-sheet templates.

**Preflight:** test the exact device, browser, projection resolution, speaker volume, cables, and playback route. Tape cable paths or keep them outside circulation. Set a safe volume. Confirm any blackout/low-light space access. Prepare a screen-only, silent, or paper-score fallback.

## 90-minute session rhythm

10-minute encounter; 15-minute demonstration; 30-minute studio round; 8-minute reset; 17-minute test/revision; 10-minute documentation/cleanup.

## Four-session sequence

### Session 1 — Make time visible

**Target:** make a loop, cue, or visual change that relates to a sound or timer.

**Prompt:** *What should the audience notice first, and when?*

**Build/play:** learners storyboard three moments, then make a 10–20 second visual loop or cue sequence.

**Evidence:** annotated storyboard and first test clip/screen capture.

### Session 2 — Build a rule, not just an effect

**Target:** change a visual system through one clear rule: repetition, drift, amplitude, cue, or input.

**Prompt:** *What repeats, and what changes?*

**Build/play:** pairs make one generative or responsive study with a predictable control.

**Evidence:** plain-language rule plus a before/after test.

### Session 3 — Test the room

**Target:** revise for scale, brightness, sound, audience angle, and cable reality.

**Prompt:** *What survives when this leaves the laptop?*

**Build/play:** teams run brief projector/screen rehearsals, log what was unreadable or unreliable, and change one consequential element.

**Evidence:** room-test note and revised setup/signal-flow sketch.

### Session 4 — Run, witness, hand off

**Target:** present a bounded piece another person could set up safely.

**Prompt:** *What does the next operator need to know?*

**Build/play:** groups present a short piece, assign run roles, and leave a run sheet covering files, cue, cable path, volume, and reset.

**Evidence:** performance/install test and completed run sheet.

## Safety, access, and recovery

Keep students away from ceiling mounts, high-voltage fixtures, and unsecured trip hazards. Roles include visual maker, sound listener, cue caller, setup mapper, and witness. If projection or software fails, present the work as a timed laptop/screen study or paper cue score; the learning target is a legible relationship among image, sound, time, and room.

## Assessment and partner description

Observe: makes a clear time-based rule; tests a media system in actual conditions; recognizes a room constraint; revises from evidence; documents safe rerun conditions.

**Partner description:** A live-media studio where learners build audiovisual systems for actual rooms, audiences, and reruns—not just for a laptop screen.
