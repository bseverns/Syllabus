# Robotics with LEGO Spike Prime (High School)
This repository contains a 12-session robotics course using LEGO SPIKE Prime kits.

## Start here

### Facilitators

1. Read the [`syllabus`](syllabus/Robotics_Syllabus.md), then stage every kit with [`Materials and Setup`](instructor_notes/Materials_and_Setup.md).
2. Complete the device, kit, room, and safety checks in the [`Facilitator Runbook`](instructor_notes/FACILITATOR_RUNBOOK.md).
3. Open the [SPIKE App download](https://education.lego.com/en-us/downloads/spike-app/software/) and [official building instructions](https://education.lego.com/en-us/product-resources/spike-prime/downloads/building-instructions/) on one student device before Session 1.
4. Use the relevant `session_plans/` file with the shared timing and session launch map in the runbook. Keep [`Troubleshooting`](instructor_notes/Troubleshooting.md) open during build, coding, and arena work.

### Students

1. Build and inspect the Driving Base with [`Build Instructions`](student_handouts/Build_Instructions.md).
2. Follow [`Coding Tutorials`](student_handouts/Coding_Tutorials.md) for the current session target.
3. Use [`Challenge Cards`](student_handouts/Challenge_Cards.md) for maze and SuGo runs, then complete the assigned [`Reflection Prompts`](student_handouts/Reflection_Prompts.md).
