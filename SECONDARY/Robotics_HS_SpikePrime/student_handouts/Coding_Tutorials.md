# Start Here: Code, Test, Record

1. Open the SPIKE App and connect only to your team's hub.
2. Name and save your project before changing code.
3. Make one small change, run it in the clear lane, then write what happened before the next change.
4. Stop the program before touching the robot or moving it back to the start.

## Current session target

| Sessions | Build this behavior | Show your team before moving on |
| --- | --- | --- |
| 2–3 | Straight movement, 90° turns, a square, then a figure-eight | The robot repeats the route with a loop. |
| 4–5 | Read a color/distance sensor and react | The robot stops at a red line or avoids an obstacle. |
| 6–7 | Follow a maze strategy and improve a threshold/turn | One full maze test plus one revision. |
| 8–11 | Detect the ring edge/opponent and refine strategy | A safe practice run and a note on the last change. |

Use movement blocks first, loops for repeated actions, and `wait until` blocks for sensor-based motion. If the robot drifts, pauses, or cannot see a sensor, record the problem and use the instructor's troubleshooting path instead of guessing.
