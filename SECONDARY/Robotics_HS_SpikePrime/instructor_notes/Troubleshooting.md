# Troubleshooting Guide
| Issue | Likely Cause | Fix |
|--------|---------------|------|
| Robot not moving | Low battery | Recharge hub |
| Sensor not detected | Loose cable | Check ports and re-seat connections |
| Drifts off path | Uncalibrated gyro | Recalibrate in software |
| Delay in response | Code loop too long | Add wait blocks or condition checks |
