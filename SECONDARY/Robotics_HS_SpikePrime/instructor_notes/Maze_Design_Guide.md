# Maze Design Guide

Project or print the [maze run loop](../assets/maze-run-loop.svg) so every team works through predict → test → notice → revise rather than repeated unrecorded runs.

- Use masking tape or foam walls on the floor or large board.
- Start with simple 90° turns, then add dead ends.
- Ensure at least two valid solutions for testing variations.
- Provide consistent wall height (5–7 cm) for reliable distance sensor detection.
