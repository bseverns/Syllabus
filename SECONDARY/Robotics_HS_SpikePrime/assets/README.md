# Original course visuals

These are original, editable SVG teaching diagrams created for this curriculum repository.

| Asset | Use | Alt text | Limits |
| --- | --- | --- | --- |
| `maze-run-loop.svg` | Keep the maze challenge focused on a repeatable prediction, test, observation, and revision loop. | Four cards show the robot-maze workflow: predict a route, test after an instructor signal, notice the result, and revise one thing. | This is a learning-process aid, not a build diagram, code template, or replacement for the instructor's room and robot readiness checks. |

The SVG has a `<title>`, `<desc>`, and `role="img"`. The course's MIT license governs reuse unless a downstream use requires a more specific notice.
