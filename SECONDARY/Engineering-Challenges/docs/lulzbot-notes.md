# LulzBot Mini 2 / Mini 3 — Tuning Notes (Cura LulzBot Edition)

Conservative, reliability‑first starting points for 0.5 mm nozzles and PEI beds.

- **First layer:** 0.32–0.36 mm with slower outer walls for strong adhesion.
- **Retraction (direct drive):** PLA 0.8–1.2 mm @ 25–35 mm/s; PETG 0.6–1.0 mm @ 20–30 mm/s.
- **Cooling:** PLA 100% after layer 2; PETG 30–50%; ASA minimal (enclosed per policy).
- **PEI + PETG:** use **glue stick as a release agent** to protect the sheet.
- **Leveling:** If firmware supports on‑print mesh (**G29**), use the G29 start variant. If you saved a mesh, enable with **M420 S1**.
