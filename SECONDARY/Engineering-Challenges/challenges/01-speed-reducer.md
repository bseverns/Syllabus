# Challenge 01 — Speed Reducer

**Goal:** Build a gearbox that reduces input RPM by ≥ 4:1 and drives the indexing dial **repeatably** (±1 mark).  
**Constraints:** PLA only; no oil; printed gears only; footprint ≤ 120×120 mm.

**Evidence:** calculated ratio, measured output RPM, dial repeatability (hits mark N times).  
**Tips:** mind shaft/bore fits and support bearing surfaces; avoid tooth under-extrusion.
