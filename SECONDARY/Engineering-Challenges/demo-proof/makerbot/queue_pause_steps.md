# MakerBot SKETCH — Pause/Color Swap

1. Import `../assets/MECH-demo-token_40x3.stl` and choose Draft/Balanced.
2. Confirm **layer height** (e.g., 0.25 mm). Pause height ≈ 1.25 mm → Layer ~5.
3. In the MakerBot UI, schedule a **pause** near Layer 5 (or 1.25 mm).
4. Print; at pause, swap filament, purge a little off-part, resume.
5. Name & log using the dual-fleet schema (see `docs/dual-fleet-pipeline.md`).
