# Rubric — Mechanism Lab (100 pts)
- **Design Intent (20):** Clear goal; parameters justified.
- **Printability (20):** Orientation, supports, tolerances handled well.
- **Function (30):** Mechanism moves as intended; test criteria met.
- **Measurement (20):** Rig use, logs complete, calculations sensible.
- **Reflection (10):** Specific next steps; connects failure to cause.
