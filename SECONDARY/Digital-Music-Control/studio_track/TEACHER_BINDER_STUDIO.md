# Teacher Binder — Studio Track (upper/advanced)

- Keep lecture ≤ 20 minutes; reserve time for lab and critique.
- Safety: power off before rewiring; ESD care around USB/host.
- Pair programming; rotate roles.
- Debug discipline: MRE (Minimal Reproducible Example), serial logs, hypotheses.
- Exit tickets: one insight + one blocker.

## Timing pattern (per session, 2h)
- 0:00–0:15  Check‑in + demo reference
- 0:15–0:25  Micro‑lecture (one concept)
- 0:25–1:25  Guided lab
- 1:25–1:50  Share/crit + fixes
- 1:50–2:00  Notes + next steps
