# Assessment Rubric — Level 3

| Criterion | 4 | 3 | 2 | 1 |
|---|---|---|---|---|
| Process | Clear diagrams, logs, and change notes | Some diagrams/logs | Sparse notes | Minimal |
| Network & Sync | Stable timing; tolerant to loss | Minor drift | Frequent drift | Unstable |
| Map & Motion | Repeatable paths; bounded error | Mostly repeatable | Intermittent | Unreliable |
| Cues & Expression | Intentional, readable storytelling | Mostly coherent | Patchy | Unclear |
| Documentation | Video + README + BT/scene graph | Video + README | One artifact | None |
