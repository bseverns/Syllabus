# Robotics & Vibe Coding — Level 3 (Swarms & Scenes)

**Duration:** 8 sessions × 2 hours • **Audience:** Level 2 grads / equivalent • **Max builds:** 12 robots

Level 3 treats robots as a **networked ensemble**: multi‑agent coordination, map‑aware motion, and **performative integration** with lights/sound. Students select a **dialect** (LEGO Spike / Arduino / MicroPython), skewing toward Python/C on boards that support reliable comms.

## Learning Goals
- Architect a rehearsal‑ready network: addressing, timebase, **sync beacons**.
- Implement **localization & map awareness** (fiducials, line tracks, or dead‑reckoning with correction).
- Compose **behaviors as scenes** (state machines or behavior trees) with transitions.
- Integrate **lighting/sound cues** (DMX/MIDI/OSC) via a conductor console or base‑station laptop.
- Perform a safe, intentional demo; document design trade‑offs and test evidence.
