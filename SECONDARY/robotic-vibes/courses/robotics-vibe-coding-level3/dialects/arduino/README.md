# Arduino / ESP32 — Level 3

- **ESP32** recommended (ESP‑NOW/Wi‑Fi). Otherwise nRF24 for classic Arduino.
- Behavior Trees with lightweight libs **or** structured states; logging over serial.
- DMX: via MAX485 + DMX library **or** route OSC→DMX on laptop.
- Milestones: time sync → reliable messages → mapped cues → show.
