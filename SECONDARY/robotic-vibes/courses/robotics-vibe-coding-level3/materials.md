# Materials & Budget Tiers — Level 3

**Add‑ons beyond Level 2**

## Lean
- Optical **tempo beacon** (LED strip + metronome box)
- High‑contrast floor markers or line track tape
- Small audio interface or powered speaker
- USB‑DMX adapter **or** PC‑MIDI interface (for cue control)

## Standard
- Radio modules (ESP32 for ESP‑NOW/Wi‑Fi **or** nRF24) per robot (policy‑dependent)
- IMU + ToF per robot; fiducial marker set (printable)
- I2C OLED per robot for debug
- Conductor laptop with USB‑DMX and/or OSC/MIDI routing

## Enhanced
- Overhead camera (UVC) + fiducial board; OpenCV laptop
- Small DMX fixtures (2–4 pars) or LED bars; safe stands
- Network switch, long USB, and gaffer for clean runs
