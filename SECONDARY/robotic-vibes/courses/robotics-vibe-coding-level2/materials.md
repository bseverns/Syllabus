# Materials & Budget Tiers — Level 2

**Add-ons beyond Level 1**

## Lean
- Line sensor or simple encoder per robot
- Small IMU (e.g., MPU-6050/MPU-6886) shared pool
- IR LED/receiver pairs **or** simple radio pairs (where feasible)
- Breadboards/jumpers; spare motor drivers

## Standard
- Encoders for all drive wheels **or** line sensor + IMU per team
- I2C OLED (0.96") for on-robot debugging
- Extra battery capacity + fuses; charge/test station

## Enhanced
- ToF distance sensors (VL53L0X) for crisp ranging
- Better motor drivers; servo pan/tilt for sensor gimbals
- Radio modules (nRF24/ESP-now) where policy allows
