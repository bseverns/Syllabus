# Teacher Guide

- **Framing**: robotics as instrument + studio practice; normalize iteration.
- **Class Flow**: tight Block A demos; generous Block B coaching.
- **Safety**: model teardown rituals; battery discipline.
- **Differentiation**: steer beginners to LEGO Spike; tinkerers to Arduino/MicroPython.
- **Assessment**: check notebooks weekly; short stand‑ups; rubric at S7.
- **Showcase**: plan S8 audience; record short videos for reflection.
