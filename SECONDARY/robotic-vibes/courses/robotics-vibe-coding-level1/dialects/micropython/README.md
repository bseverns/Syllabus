# MicroPython / CircuitPython Path (Raspberry Pi Pico)

## Setup
- Thonny (MicroPython) or CircuitPython with `code.py` on the device.
- Project the [Raspberry Pi Pico orientation reference](../../../../assets/hardware-references/raspberry-pi-pico-top-bottom.jpg) before the first build to identify the USB connector, BOOTSEL button, and board edges—not to substitute for a local pinout. Its [CC BY-SA 4.0 attribution](../../../../assets/hardware-references/README.md) is maintained with the asset.

## Milestones
- M1: Read pin/ADC; map to LED.
- M2: Timer-based rhythm; button toggles mode.
- M3: Simple avoidance with HC‑SR04 or IR sensor.
