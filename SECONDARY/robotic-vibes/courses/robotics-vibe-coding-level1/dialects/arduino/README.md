# Arduino Path (C/C++)

## Setup
- Arduino IDE or PlatformIO. Target: common “open MCU” (e.g., Nano/Uno) + motor driver (L298N/DRV8833).
- Project the [Arduino Uno orientation reference](../../../../assets/hardware-references/arduino-uno.jpg) before the first build to name board regions—not to copy wiring. Its [CC BY 2.0 attribution](../../../../assets/hardware-references/README.md) is maintained with the asset.

## Milestones
- M1: Read analog sensor; print serial; map to LED PWM.
- M2: Non‑blocking timer (millis); step a rhythm pattern.
- M3: Bump switch triggers state change; motor avoidance.
