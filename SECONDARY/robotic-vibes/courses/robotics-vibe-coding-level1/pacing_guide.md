# Pacing Guide (8 × 2h)

Each session: **Block A (50–60 min)** concept + code‑along; **Block B (50–60 min)** studio build + coaching; **Transitions (10–20 min)** resets, charging, notes.

- **S1**: Safety, power, I/O; first drive + blink; sensor readout.
- **S2**: Map sensor → LED/sound; smoothing; thresholds; first “vibe” loop.
- **S3**: Timers and rhythms; non‑blocking loops; parameter tweak UI.
- **S4**: State machines; mode buttons; expressive presets.
- **S5**: Bump + range sensing; avoidance; graceful stops.
- **S6**: Duets; sync tactics; shared tempo.
- **S7**: Dress rehearsal; fix lists; doc capture.
- **S8**: Performance; reflection; teardown & inventory.
