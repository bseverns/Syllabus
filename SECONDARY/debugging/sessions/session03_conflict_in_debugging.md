# Session 3 — Conflict in Debugging

## At a glance

- length: 60 to 90 minutes
- focus: different debugging goals can conflict
- artifact: debugging goals reflection

## Core framing

When students get stuck, the class may pursue different goals:

1. solve the problem now
2. prevent the same problem from happening again
3. build skill for future unfamiliar problems

## In-class plan

1. Present the three goals above.
2. Give students one debugging scenario and ask which goal they would prioritize.
3. Compare how teacher or peer support changes depending on the goal.
4. Students complete `handouts/debugging_goals_reflection.md`.
