# Session 6 — Debugging With Other People

## At a glance

- length: 60 to 90 minutes
- focus: bug reports, peer coaching, and debugging talk
- artifact: bug report + peer coaching script

## Before class

- print `handouts/bug_report_template.md`
- print `handouts/peer_coaching_moves.md`

## In-class plan

1. Model bad peer help versus good peer coaching.
2. Students practice describing a bug without solving it immediately.
3. In pairs, one student is the debugger and one is the coach.
4. Swap roles.
5. End with written bug reports.

## Instructor notes

- watch for takeover behavior
- reinforce that helping someone think is different from doing the work for them
