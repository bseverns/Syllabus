# Debugging Studio

This folder now functions as a secondary-level course packet built from the earlier debugging workshop materials in this directory.

The course treats debugging as more than error correction. Students learn that debugging involves:

- technical reasoning
- design decisions
- communication
- emotional regulation
- reflection on what "better" actually means

## What this packet is for

This version is designed for secondary students, but it is intentionally written so it can be translated one level lower or one level higher without changing the core ideas.

Use this folder if you want a course on:

- how students get stuck
- how they recover
- how debugging choices reflect different goals
- how class culture shapes who feels capable of solving problems

## What is inside

- `FACILITATOR_LAUNCH_GUIDE.md`: preflight, materials, timing, novice supports, and recovery paths
- `STUDENT_START_HERE.md`: plain-language learner orientation and four-move debugging routine
- `COURSE_DESCRIPTION.md`: overview and learning outcomes
- `COURSE_ONEPAGER.md`: concise school-facing overview
- `SYLLABUS.md`: 8-session sequence
- `INSTRUCTOR_GUIDE.md`: pacing, facilitation, and classroom norms
- `ADAPTATION_GUIDE.md`: how to scale the course up or down
- `ASSESSMENT_RUBRIC.md`: growth-focused rubric
- `sessions/`: full session plans
- `handouts/`: student-facing tools

## Launch in three steps

1. Choose one shared system and complete the preflight in `FACILITATOR_LAUNCH_GUIDE.md`.
2. Give students `STUDENT_START_HERE.md`, then use the matching file in `sessions/` for each meeting.
3. Keep the named evidence from each session and assess the final portfolio with `ASSESSMENT_RUBRIC.md`.

The existing PDFs, slide decks, and workshop materials remain in this folder as source material. The new course package translates those ideas into a classroom-ready sequence for students.
