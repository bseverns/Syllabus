# Repair Studio: Devices, Diagnostics & Reuse

A four-session high-school pilot where learners diagnose low-voltage devices, document evidence, and decide whether a device should be repaired, reused, or salvaged.

> **PILOT READY:** A lead facilitator can run this bounded low-voltage version as written. It needs a real delivery review before public promotion.

## Run this

1. Read [`SYLLABUS.md`](SYLLABUS.md) and choose only the listed safe device families.
2. Build the device tote and pre-sort one device per pair.
3. Keep every mains-powered item, swollen battery, and unknown hazardous item out of the learner workspace.
4. Record timing, repair outcomes, and sourcing friction after Session 4.
