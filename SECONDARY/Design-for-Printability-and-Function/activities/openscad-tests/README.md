# OpenSCAD Test Artifacts

Parametric SCAD files used to explore printability. Export to STL at classroom scale.
- `overhang_test.scad` — towers with increasing overhang angles.
- `bridge_test.scad` — bridge ladder with growing spans.
- `tolerance_gauge.scad` — pegs/holes at stepped clearances.
- `snapfit_test.scad` — cantilever hooks for cycle tests.
