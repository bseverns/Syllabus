# Contributing

- Fork for your class; keep local printer-specific settings in `slicer-profiles/local/`.
- Add new test artifacts under `activities/openscad-tests/` and include a preview PNG.
- When changing rubrics, keep version notes in the file header.
- Prefer open, student-friendly formats: `.md`, `.csv`, `.scad`.
- PRs welcome for bugfixes/typos; anonymize student data before sharing.

## Pull request checklist
- [ ] Updated README or docs
- [ ] Included rationale for changes
- [ ] No personally identifying information (PII)
