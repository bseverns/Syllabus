# Gates from Gravity
**A window comparator as an instrument**  
AE Modular BRAEDBOARD • 2-session lab workshop

This workshop builds a **voltage window comparator** that turns continuous control voltage into **musical decisions**.
A gate goes HIGH only when the input voltage lives *between* two thresholds.

**IC count:** 2–3  
- MCP602 (dual op-amp as comparators)  
- CD40106 (Schmitt inverter / logic cleanup)

See `syllabus/2-session-block.md`.
