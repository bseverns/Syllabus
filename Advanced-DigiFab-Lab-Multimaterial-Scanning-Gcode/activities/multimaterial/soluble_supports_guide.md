# Soluble Supports — Quick Guide

- Use **dense interface layers** (≥ 3) for clean undersides.
- Dry PVA (or BVOH) before use; store in sealed bins with desiccant.
- Reduce support Z‑distance; lower fan if layers don't bond.
- Dissolve in room‑temp water with agitation; change water when cloudy.
- Dispose per local rules; never pour slurry into sinks with filters/pumps.
