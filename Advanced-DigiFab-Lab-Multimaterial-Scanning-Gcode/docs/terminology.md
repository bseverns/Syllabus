# Key Terms
- **MMU/AMS:** Multi‑material hardware systems for automatic filament changes.
- **Wipe/Prime Tower:** Purge structure to swap materials cleanly.
- **M600/M0/M25:** G‑code commands used to change filament or pause prints.
- **Photogrammetry:** Reconstructing 3D from photos.
- **KPI:** Key performance indicator (uptime, success rate, reprint rate).
