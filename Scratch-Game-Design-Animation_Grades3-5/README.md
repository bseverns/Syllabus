# Scratch Game Design + Cutscenes Lab (Grades 3–5)

A 12-week, 1-hour/week Scratch (MIT) course for grades 3–5 focused on **video game design with levels** and **cut-scene animations**.

This folder is designed to drop into a syllabus repository as a self-contained course packet:
- A **school-facing syllabus** (for administrators / families)
- A detailed **instructor play-by-play** (minute-by-minute session plans)
- **Handouts** for at least 6 sessions (printable Markdown)
- A **template plan** (project architecture + naming + broadcast map)

## Capstone requirement (what “done” means)
A published Scratch project that includes:
- **Start/Menu** (or a clear beginning)
- **At least two levels** (Level 1 + Level 2 minimum)
- **At least one cutscene** between levels
- A clear **win or ending** state (and ideally a game-over)

## Notes
- This curriculum is built for a large, energetic class (~18 students).  
  It uses consistent routines, short demos, timed build sprints, and frequent playtesting.
- You can run this course solo, but it’s much smoother with 1 assistant or a rotating student “help desk” role.
