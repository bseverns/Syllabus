# Classroom Setup Checklist

> **Local notes (edit for this implementation):**  
> - Who unlocks the room / lab and when:  
> - Shared drive or LMS location for saving student work:  
> - Backup plan if network or logins fail:  

## Before the course begins

- [ ] Confirm software installed or accessible (Photopea/GIMP/Photoshop).
- [ ] Test saving and opening files from student accounts.
- [ ] Set up a shared folder or cloud space for saving and collecting work.
- [ ] Decide where final exhibition will live (hallway, website, slideshow, etc.).

## Before each session

- [ ] Test projection/screen-sharing for demos.
- [ ] Prepare demo files (before/after images, sample projects).
- [ ] Charge cameras/ensure devices have battery.
- [ ] Check free disk space on lab machines.

## During class

- [ ] Have at least one “backup” activity that doesn’t require internet.
- [ ] Keep a visible timer for work sprints.
- [ ] Reserve 5–10 minutes at the end for saving and cleanup.

## After class

- [ ] Snapshot a few exemplary works-in-progress.
- [ ] Note any tech/logistical snags to fix before next session.
