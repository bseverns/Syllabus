# Session 08 – Studio Showing & Reflection

## At a glance

- **Length:** 90 minutes  
- **Mode:** Informal show + reflection  
- **Goals:**
  - Share finished or near-finished pieces.
  - Reflect on gesture, control, and surprise.
- **Deliverables:**
  - Final presentation.
  - Short written reflection.

## Before class (instructor)

- Arrange playback (speakers, projector if visuals).
- Decide on order for presentations.

## In-class plan

### 0–10 min — Setup & expectations

- Explain:
  - Each student (or group) gets a few minutes:
    - Show gesture map (and visuals, if any).
    - Play 45–60 seconds of their piece.
  - Peers give specific, kind feedback.

### 10–65 min — Presentations

- For each student:
  - Show gesture map and title.
  - Play audio (and visuals if present).
  - 1–2 peer comments:
    - “One gesture I heard was…”
    - “One moment that grabbed my attention was…”

### 65–80 min — Individual reflection

- Written prompts:
  - “Which gesture are you most proud of, and why?”
  - “What surprised you about how gesture turned into sound?”
  - “What would you try next with more time or more strings?”

### 80–90 min — Closing circle

- Quick go-round:
  - “One word for how this project felt.”

## After class / Homework

- Optional: document work (photos of maps, audio uploads) in a shared class archive.

## Local notes (edit before teaching)

- **Audience:** only class / invited guests?  
- **Recording policy:** can you record audio/video of the showing?  
- **Potential follow-up:** club, advanced course, or exhibition.
