TMS Workshop: Lookahead Limiter

Time • Matter • Space — keeping transients beautiful and mixes safe.

Use ← / → or space

What & Why

  • Prevent clipping beyond a ceiling (e.g., −1 dBFS)
  • Act *before* transients hit by delaying the audio path
  • Release smoothly to avoid pumping

Signal flow

Detector & Envelope

level   = max(abs(L), abs(R))
g_req   = clamp( ceiling / level, 0..1 )
env[n]  = min( g_req,  env[n−1] + α * (1 − env[n−1]) )
α       = 1 − exp( −1 / (τ * fs) ),  τ = release_ms/1000

Parameters

  • Ceiling: −6..−0.3 dBFS (shared headroom across devices)
  • Lookahead: 1–5 ms (more safety ⇢ more latency)
  • Release: 20–200 ms (short ⇢ chatter, long ⇢ pumping)

Pitfalls & Practice

  • HF “sneak-through”: consider oversampling detector
  • True peak vs. sample peak (DA reconstruction)
  • Clip guards in feedback paths (never > 0.98)

Live Code: core loop

float level = max(abs(xL), abs(xR));
float g_req = (level <= 1e-12f) ? 1.0f : min( ceiling / level, 1.0f );
env = min( g_req, env + alpha * (1.0f - env) );
yL = delayL.read(lookahead) * env;
yR = delayR.read(lookahead) * env;

Labs (pick 1–2)

  1. Add a hold stage before release
  2. Make RMS detector; compare
  3. Try mid/side detection
  4. Profile CPU and buffer sizes

Takeaways

  • Limiter = foresight + envelope grace
  • Design with shared headroom for interop
  • Measure, don’t guess
