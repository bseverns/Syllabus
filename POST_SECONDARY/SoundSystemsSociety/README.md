# Sound / Systems / Society

Speakers move people and politics; let's tune both.

This folder is a **course stack** for a college-level class that treats sound as infrastructure, listening as method, and small PA systems as tools for community, memory, and power.

## What's here

- `syllabus.md` – full course description and week-by-week outline.
- `assignments/`
  - `listening-log.md` – weekly listening practice.
  - `process-log.md` – project-focused process documentation.
  - `project1-sound-system-roots-case-study.md`
  - `project2-tiny-system-design-and-demo.md`
  - `project3-community-mix-and-gathering-documentation-final.md`
- `reading-media.md` – anchor texts, films, and suggested additions.
- `instructor-notes.md` – pacing notes, assessment mix, and access practices.

Drop this folder into the root of the `Syllabus` repo (alongside `CTMSoundDesign`, `ExplorationSoundDesign`, etc.) and wire it into `catalog/` however you like.
