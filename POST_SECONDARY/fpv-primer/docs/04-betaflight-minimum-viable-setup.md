# Betaflight: minimum viable setup (telemetry-first)

Goal: a stable configuration that produces usable telemetry without extra complexity.

Topics to cover:
- Firmware target + board orientation
- Receiver setup (channel map, endpoints)
- Failsafe behavior
- Rates/expo basics (keep conservative at first)
- Motor test (props off)
- OSD (optional)
- Logging (blackbox if available)

Output artifact:
- a saved diff / config export
- a screenshot set of key pages
