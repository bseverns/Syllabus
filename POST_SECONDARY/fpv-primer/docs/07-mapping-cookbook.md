# Mapping cookbook (telemetry → control)

Mappings are compositions. This cookbook should include:
- deadband (ignore jitter)
- smoothing (EMA)
- slew limiting (physicality)
- hysteresis (stability near thresholds)
- curves (exp/log/S)
- quantization (steps become rhythm)
- safety rails (min/max, limiter compensation)

Artifacts:
- example mappings in pseudocode
- a “mapping sheet” template (see /templates)
