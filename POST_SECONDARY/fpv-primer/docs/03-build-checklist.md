# Build checklist (pre-flight readiness)

A practical checklist you can run before first flight:
- mechanical (screws, props, frame integrity)
- electrical (shorts, solder, strain relief)
- firmware (FC target, correct orientation)
- radio (binding, channel map, failsafe)
- sensors (gyro calibration)
- OSD (if used)
- logging (blackbox / telemetry capture)

End with: “bench proves it first.”
