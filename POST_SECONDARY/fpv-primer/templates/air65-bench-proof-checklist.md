# Air65 bench-proof checklist

## Pre-power

- props removed
- frame and ducts inspected
- battery lead and connector look healthy
- VTX antenna path is intact
- workspace is clear

## Betaflight proof

- FC connects to configurator
- board orientation matches the craft
- receiver protocol is correct
- channels move in the expected directions
- arm switch is intentional
- mode configuration is documented

## ELRS / control-link proof

- correct radio model selected
- bind state confirmed
- link quality field observed
- signal-loss test performed on bench
- expected failsafe behavior observed

## Motor and output proof

- motor order verified
- motor direction verified
- no rough motor sound on test spin
- no unexpected output while disarmed

## Video / OSD proof

- analog feed appears when expected
- key OSD fields visible
- channel / power assumptions noted

## Artifact set

- screenshots saved
- config export or diff saved
- one note on what is proven
- one note on what still needs proof

## Instructor signoff

Launch cleared for:

- bench-only continuation
- indoor supervised hover work
- no launch; hold for troubleshooting
