# Local AI, Archives & Small Tools

A four-session post-secondary pilot where learners audit a permissioned document set, test a bounded retrieval/annotation workflow, and make provenance and limits visible.

> **PILOT READY:** A lead facilitator can run this paper-first or local/sandboxed tool pathway as written. It needs a real delivery review before public promotion.

## Run this

1. Read [`SYLLABUS.md`](SYLLABUS.md); choose one small document set with documented permission to use it in class.
2. Pick one approved tool path; a paper/simulated retrieval workflow is the default fallback.
3. Do not upload private, confidential, copyrighted, or student-record material to a hosted tool without explicit permission.
4. Record tool failure, hardware, provenance, and user-test findings after Session 4.
