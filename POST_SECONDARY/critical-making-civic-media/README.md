# Critical Making & Civic Media

Make media that can survive contact with real publics, real constraints, and real consequences.

This folder is a fully scaffolded **post-secondary studio-seminar** for teaching civic media as a making practice: diagnose a local system, test small interventions, work with actual stakeholders, stage a modest public action, and document the work so somebody else could repeat or challenge it.

Default shape:

- **Audience:** undergraduate studio-seminar
- **Length:** 12 weeks
- **Contact model:** 24 sessions x 110-115 minutes, or merged into one longer weekly block
- **Credit load:** 3 credits / about 45 contact hours
- **Materials bias:** low-cost, portable, remixable

## Folder map

- `COURSE_DESCRIPTION.md` - catalog-ready description, outcomes, prerequisites
- `SCHEDULE.md` - 12-week spine with phase logic and weekly artifacts
- `ASSIGNMENTS.md` - project set, grading weights, submission rules
- `ASSESSMENT_RUBRIC.md` - critique-ready criteria tied to evidence
- `INSTRUCTOR_NOTES.md` - pacing, partner management, risk, tech tiers, failure modes
- `READINGS.md` - weekly reading and viewing clusters with short rationale notes
- `PROJECT_BRIEF.md` - final civic media action brief and documentation bundle
- `PARTNER_ONBOARDING_CHECKLIST.md` - partner-facing alignment and boundary tool
- `templates/` - reusable logs, maps, briefs, run sheets, meeting notes
- `sessions/` - session-by-session teaching plans
- `catalog/course.json` - lightweight catalog entry for indexing systems

## Course spine

The sequence is intentionally narrow:

1. **Diagnosis** - identify a local issue, narrative, or bureaucratic friction point worth studying.
2. **Small intervention** - make something quickly in public language, not academic fog.
3. **Systems framing** - map stakeholders, leverage points, risks, and dependencies.
4. **Partner check** - test whether the project is actually useful, legible, and appropriately scoped.
5. **Prototype and field test** - run a modest version with consent and evidence discipline.
6. **Public action** - stage a civic media intervention that is smaller than the fantasy but sharper than the vague big idea.
7. **Replication and postmortem** - publish setup, decisions, failures, and next steps.

## Teaching stance

- Start from **observable conditions**, not abstract "awareness."
- Treat critique as an argument about evidence, audience, timing, and consequence.
- Keep projects **modest enough to finish** and public enough to matter.
- Require documentation as part of the civic act, not a cleanup task after the fact.
- Let students work across media forms:
  - no-code / low-code web tools
  - print, poster, zine, and signage systems
  - web pages, SMS flows, short videos, public screens
  - sensors, kiosks, installations, and lightweight public interfaces

## Adaptation notes

- If you have **no formal partner**, use a campus office, student org, block club, library table, or a clearly defined public on campus as the working constituency.
- If your class meets in a single weekly block, pair the session files as `A/B` halves and protect a real break.
- If the tech stack is thin, keep the strongest version of the course:
  - paper prototypes
  - posters
  - printed maps
  - SMS mockups
  - zines
  - low-fi kiosks built from cardboard and shared devices
- If a project starts expanding, use the course doctrine:
  - **smaller is better than vague**

## Local notes for future instructors

- Write down the actual partner landscape before the semester starts.
- Mark which permissions are easy, slow, or impossible on your campus or site.
- Decide early where students will store documentation artifacts so the archive survives turnover.
