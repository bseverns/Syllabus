# Documentation Checklist

Use this before final submission and before any partner handoff.

## Artifact files

- Final files exported in usable formats
- Working files named clearly
- Version/date noted

## Setup proof

- Wide photo of full setup
- Close photos of key details
- Diagram or flow of system
- Materials list

## Process proof

- Process log excerpt
- Notes showing at least one revision from feedback
- Meeting notes or partner check

## Public proof

- Audience or user feedback
- Observation notes
- Public framing statement

## Ethics / permissions

- Consent note if people are documented
- Permission note if site access was required
- Risk note if the work handles sensitive topics

## Postmortem

- What worked
- What failed
- What changed
- What to keep / cut / hand off
