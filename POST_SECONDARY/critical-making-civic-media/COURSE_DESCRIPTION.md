# Course Description

## Catalog description

**Critical Making & Civic Media** is a studio-seminar on building public-facing media artifacts that intervene in local civic life. Students study how narratives, interfaces, signs, bureaucracies, and technical systems shape public understanding, then prototype modest interventions that can clarify, redirect, or challenge those systems. The course combines critical reading, field observation, systems mapping, stakeholder analysis, tactical media experiments, and a final public action documented for reuse. Emphasis falls on accountability, not spectacle: students are expected to define audience, scope, permissions, risks, and evidence before scaling an intervention.

## Learning outcomes

By the end of the course, students should be able to:

- analyze a civic issue as both a media problem and a systems problem
- identify stakeholders, leverage points, constraints, and unintended consequences
- prototype tactical media artifacts that make a public claim legible
- select an appropriate medium for a specific audience and context
- work with a partner or constituency without promising more than a class can responsibly deliver
- document setup, decisions, failures, and changes so another person could replicate the work
- evaluate a public intervention using observation, feedback, and postmortem evidence rather than taste alone

## Typical outputs

Students usually leave with a visible bundle, not just a paper:

- a civic signal scan and issue framing dossier
- systems and stakeholder maps
- one early tactical media prototype
- partner meeting notes and an intervention brief
- an ethics / consent / unintended consequences review
- a tested prototype or modest public action
- a documentation bundle including photos, setup notes, permissions notes, run-of-show, and postmortem

## Prerequisites / recommended context

No single technical prerequisite is required. Helpful backgrounds include:

- introductory media studies
- design foundations
- web or print production
- community-engaged practice
- journalism, activism, public humanities, HCI, or social practice

Students should be ready to read critically, work in teams, talk to people outside their immediate friend group, and make public-facing artifacts under real constraints. Prior coding experience can help but is not required.

## Course character

This is not a "solve civics with an app" class and not a vibe-only activism seminar. It is a making course for students willing to define scope, test claims, and accept that public work has consequences.
