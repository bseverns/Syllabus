# Session 22 - Public action window B and debrief

> **Local notes (edit before teaching):**
> - Remaining action slots:
> - Debrief room:

## At-a-glance outcomes

- Teams complete the action window or run a second pass.
- Students document immediate lessons before memory smooths them out.

## Before-class prep

- Make space for a same-day debrief.
- Ask teams to bring all raw captures back into one place.

## In-class sequence

1. Final action or second pass.
2. Teardown and artifact collection.
3. Immediate debrief.
4. Sort evidence into what worked, failed, and needs explanation.
5. Assign archive and postmortem owners.

## Discussion prompts

- What is the strongest piece of evidence you have from the action?
- What part of the project still needs to be explained honestly in the postmortem?

## Required artifacts

- Raw capture set
- Immediate debrief notes

## Instructor notes

- Insist on same-day note capture.
- Watch for teams rewriting history too generously.

## Contingency / low-tech fallback

- If the action could not happen, run a documented staged pilot and write the failure honestly as part of the project record.
