# Session 02 - Issue walk and evidence capture

> **Local notes (edit before teaching):**
> - Observation zone:
> - Recording permissions:
> - Weather or mobility backup:

## At-a-glance outcomes

- Students practice documenting an issue with usable evidence.
- Students begin to separate broad concerns from specific civic friction points.

## Before-class prep

- Prepare a short evidence-capture checklist.
- Select 2-3 example issue statements, one too broad and one usable.

## In-class sequence

1. Warm-up: "bad issue statement / better issue statement."
2. Field documentation sprint.
3. Sort captures into patterns: access, confusion, delay, exclusion, narrative distortion.
4. Draft issue statements.
5. Share-out and instructor calibration.

## Discussion prompts

- What did you observe directly versus infer?
- Where is there a tractable communication or interface problem here?

## Required artifacts

- 5-8 captured observations
- Draft issue statement

## Instructor notes

- Ask for verbs and locations: who gets stuck, where, and when.
- Discourage "fix democracy" scale immediately.

## Contingency / low-tech fallback

- Use screenshots, phone photos from prior experience, and memory mapping if field access is limited.
