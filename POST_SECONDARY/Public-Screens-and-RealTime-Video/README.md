# Public Screens, Experimental Video & Real-Time Systems

A four-session post-secondary pilot where learners make a screen/projection work for a real site, test it with an audience, and leave a reliable operating guide.

> **PILOT READY:** A lead facilitator can run the single-screen or single-projector pathway as written. It needs a real delivery review before public promotion.

## Run this

1. Read [`SYLLABUS.md`](SYLLABUS.md) and secure one modest, approved presentation site.
2. Pre-test one display/projector, playback device, audio path, and cable plan in that site.
3. Do not promise installation access beyond the permission already granted; use the classroom screen fallback.
4. Record site permission, playback, maintenance, and audience-flow findings after Session 4.
