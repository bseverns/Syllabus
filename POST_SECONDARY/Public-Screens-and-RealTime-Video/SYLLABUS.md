# Syllabus — Public Screens, Experimental Video & Real-Time Systems

## Course snapshot

- **Promise:** learners treat moving image as an event in space, building a bounded public screen/projection work that can be run again.
- **Group / staffing:** 8–14 learners; one lead plus a technical assistant recommended for setup day.
- **Final share:** a screen work, site plan, operating guide, and postmortem.
- **Agreement:** *Playback, audience, and maintenance are part of the work.*

## Materials and preflight

Laptops; one tested display or projector; one playback device; audio playback where appropriate; adapters; extension leads; floor-safe cable tape; masking material; playback/maintenance templates; site-study sheets; and an approved, bounded site.

**Preflight:** secure site permission; test brightness, sightlines, power, audio, device sleep settings, file playback, and cable routes. Do not mount overhead, alter electrical systems, obstruct exits, record bystanders, or use a public screen without site approval. Prepare classroom-screen and silent-loop fallbacks.

## 110-minute session rhythm

15-minute encounter; 20-minute case/technical demonstration; 45-minute studio or site work; 10-minute reset; 15-minute critique; 5-minute evidence parking.

## Four-session sequence

### Session 1 — Screen as site

**Target:** name how a specific site changes attention, legibility, and audience behavior.

**Prompt:** *Who encounters this, from where, and for how long?*

**Build/play:** learners make a short site study and a 10–30 second screen/loop test.

**Evidence:** annotated site diagram and initial loop with stated viewing condition.

### Session 2 — Loop, rule, response

**Target:** develop a timed, looping, or responsive media behavior with a legible rule.

**Prompt:** *What stays stable, and what changes over time?*

**Build/play:** learners make one system test: authored loop, procedural change, or controlled input response.

**Evidence:** rule description, media test, and intended audience effect.

### Session 3 — Installation logic

**Target:** make technical conditions visible before public display.

**Prompt:** *What must happen for this to run reliably next week?*

**Build/play:** teams conduct a site/classroom rehearsal, test sightline/audio/cables/playback, and write a setup plan.

**Evidence:** signal/setup diagram and revised operating checklist.

### Session 4 — Public test and handoff

**Target:** stage a bounded viewing encounter and document its limits.

**Prompt:** *What did the audience actually encounter?*

**Build/play:** learners host a short test, collect non-identifying audience observations, revise their guide, and write a postmortem.

**Evidence:** final work, operating guide, and site/audience postmortem.

## Access, safety, and recovery

Learners may work as maker, site mapper, playback operator, audience observer, or documentarian. Provide captions/text alternatives where sound is used. If site access fails, run an in-room simulated site test; the learning goal is still spatial/operational media thinking, not a specific venue.

## Assessment and partner description

Observe: analyzes site conditions; makes a visible time-based rule; tests work beyond a laptop; anticipates operating constraints; documents a handoff another person can run.

**Partner description:** A media studio where learners build screen works for real rooms, actual audiences, and repeatable playback—not just for export.
