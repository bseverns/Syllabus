# Key Terms
- **Parametric:** Defined by variables; change inputs to change outcomes.
- **Extrude / Rotate Extrude:** Pull a 2D profile into 3D / revolve around an axis.
- **Heightmap:** Grayscale image mapped to elevation.
- **Vase Mode:** Continuous single wall; no top layers, spiralized path.
- **Critique:** Guided discussion to improve concept and craft.
