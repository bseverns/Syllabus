# Art, Sculpture & Parametric Patterning in 3D Print — Course Repo

**Grade band:** 8–11 • **Duration:** 8 weeks (A/B blocks per session) • **Prereqs:** Basic 3D printing & intro CAD

This course treats code and constraints as an **art material**. Students create sculptural works using **parametric tools** (OpenSCAD, optional p5.js → SVG), explore **tiling/patterning**, remix **3D scans**, and exploit printer behaviors (vase mode, variable infill, translucency) for visual effect. The repo includes week-by-week lessons with A/B blocks, teacher guides, student briefs, parametric starter files, critique rubrics, artist‑statement templates, and exhibit prep checklists.

## Quick start
- Read the **Course Outline** at [`/syllabus/course-outline.md`](syllabus/course-outline.md).
- Start with the **Parametric Starter Pack** in [`/activities/parametric-templates`](activities/parametric-templates).
- For code → print, see the **Pipelines** doc: [`/docs/pipelines.md`](docs/pipelines.md).
- Use **Vase/Translucency** slicer presets in [`/slicer-profiles`](slicer-profiles/).

## Course goals
- Treat parametric rules as artistic composition tools (repetition, transformation, constraint).
- Generate and iterate patterns procedurally; translate 2D sources (SVG/heightmaps) into 3D artifacts.
- Curate materials/light: wall thickness, infill, and orientation as deliberate visual choices.
- Produce a final **gallery-ready piece** with a concise artist statement and process log.
