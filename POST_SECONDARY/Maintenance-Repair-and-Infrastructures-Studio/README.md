# Maintenance, Repair & Infrastructures Studio

A four-session post-secondary pilot where learners observe an actual upkeep system, map hidden labor, test one small continuity intervention, and make a handoff legible.

> **PILOT READY:** A lead facilitator can run this observation-and-prototype version as written. It needs a real delivery review before public promotion.

## Run this

1. Read [`SYLLABUS.md`](SYLLABUS.md) and obtain permission for one bounded, low-risk site or process.
2. Prepare a classroom fallback case for sites where observation is unavailable.
3. Do not ask learners to repair or alter equipment they do not own or have authority to handle.
4. Record site access, labor/consent boundaries, and the usefulness of the intervention after Session 4.
