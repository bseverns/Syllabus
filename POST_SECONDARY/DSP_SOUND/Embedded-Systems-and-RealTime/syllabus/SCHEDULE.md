# 12-Week Schedule

1. Real-time thinking: latency, jitter, measuring your loop
2. Non-blocking loops: cooperative scheduling + cadence
3. Inputs I: debouncing + edge detection + event generation
4. Inputs II: ADC stability, smoothing, calibration, drift
5. Event routing: queues, priorities, loss policies
6. State machines: modes, transitions, “don’t get lost”
7. Output discipline: LEDs/displays without starving input
8. Persistence: config structs, versioning, safe defaults
9. Diagnostics: INFO, self-test, error codes, safe mode
10. Robustness: brownouts, watchdogs, recovery patterns
11. Integration: firmware architecture for a whole instrument
12. Showcase + documentation audit + release notes
