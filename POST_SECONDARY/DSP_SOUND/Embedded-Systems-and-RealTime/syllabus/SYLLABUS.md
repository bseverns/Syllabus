# Syllabus — Embedded Systems + Real-Time Instruments (12 weeks)

**Audience:** advanced high school / undergraduate  
**Mode:** lab studio + measurement + critique  
**Ethos:** an instrument is a promise under time pressure

We study embedded systems through the lens of instruments and controllers:
timing, state, memory, and survivability.

See `syllabus/SCHEDULE.md`.

## ClassHub Delivery Map

| Phase | Required private evidence | ClassHub materials |
| --- | --- | --- |
| Weeks 1–4 — timing/inputs | Loop latency/jitter, schedule design, event evidence, ADC stability/calibration, and code version | Timing checklist; private code/data uploads; reflection |
| Weeks 5–8 — routing/state/persistence | Queue/loss policy, state diagram, output-load test, versioned config, and safe defaults | Architecture checklist; private files/logs; midpoint rubric |
| Weeks 9–11 — diagnostics/recovery/integration | Self-test/error codes, brownout/watchdog/recovery evidence, and integrated instrument architecture | Recovery checklist; private code/video/data; reliability reflection |
| Week 12 — release | Final firmware/config, measurement evidence, documentation audit, release notes, and critique response | Final rubric; private portfolio upload; optional consent-cleared gallery demo |

ClassHub completion never replaces powered bench inspection. Keep device identifiers, credentials, memory dumps, and production configurations private.
