# Final Project — A Reliable Embedded Instrument

Build a controller or small instrument firmware that:
- runs without blocking delays
- samples inputs on a stable cadence
- routes events through a queue (or equivalent)
- uses an explicit state machine (modes)
- caps output event rates
- persists config safely (versioned; defaults)
- provides diagnostics (INFO + self-test) and safe mode on boot

Deliver:
- demo (video or live)
- docs (connect, controls, modes, config, recovery)
- bench checklist results
- report: `project/REPORT.md`
