# AGENTS.md — assistant rules for this capstone repo

## Safe work
- Improve docs clarity and create templates.
- Add checklists, bench procedures, and structured test plans.
- Add scripts for measurement, logging, and report generation.
- Refactor project scaffolds without changing behavior.

## Do not
- Change someone’s core project direction without explicit request.
- Invent hardware constraints—keep templates configurable.
- Add heavy dependencies.

## Evidence expectation
Any suggested improvement should include at least one:
- test, checklist item, or
- measurement artifact, or
- before/after documentation clarity upgrade.
