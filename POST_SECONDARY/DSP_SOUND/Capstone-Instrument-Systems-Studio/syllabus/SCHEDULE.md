# 12-week studio arc

1. Choose a user + write the promise (what this tool guarantees)
2. Architecture + contracts (timing, protocols, parameters, safety rails)
3. MVP build (smallest playable loop)
4. Measurement harness (what will prove it works?)
5. Reliability pass (safe mode, defaults, diagnostics, recovery)
6. UX pass (parameter feel, mode clarity, feedback)
7. Integration week (edge cases, overload, “what breaks first?”)
8. Documentation sprint (end-user docs + build/run)
9. Teaching sprint (optional): lesson plans + rubrics + demos
10. Beta release + user test (watch someone else use it)
11. Optimization + polish (CPU, latency, wiring/noise, packaging)
12. Final release + showcase + postmortem
