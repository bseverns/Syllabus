# Week 04 — Measurement harness

## Goals
- Create repeatable tests.
- Define golden references.
- Make evidence automatic where possible.

## Studio
Set up `tests/` and `bench/` so any change can be evaluated.

## Critique prompt
If your sound/behavior changes, how quickly will you know?

## Deliverables
- At least 3 tests (audio, timing, mapping)
- One plot or numeric report
- Test-run instructions

## Optional lane notes
- Instrument: latency/jitter logging.
- Plugin: render A/B audio and analyze peak/RMS/DC.
- Installation: event logs + replay script.
