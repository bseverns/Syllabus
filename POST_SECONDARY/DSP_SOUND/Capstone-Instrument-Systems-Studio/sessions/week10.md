# Week 10 — Beta release + user test

## Goals
- Ship a beta tag.
- Watch a user use it (without rescuing).
- Collect feedback as evidence.

## Studio
Cut a beta release, then conduct a 15–30 minute user test session.

## Critique prompt
What did the user do that you never predicted?

## Deliverables
- Beta release notes
- User test notes
- Top 10 fixes prioritized

## Optional lane notes
- Instrument: test on multiple computers/DAWs.
- Plugin: test preset recall + automation.
- Installation: test setup in a new space.
