# Week 08 — Documentation sprint: the manual that works

## Goals
- Write end-user docs with zero assumed context.
- Make setup reproducible.
- Add diagrams and ‘common failures’.

## Studio
Fill `docs/` templates: quick start, troubleshooting, controls, reset paths.

## Critique prompt
Where does the doc lie? Where does it assume too much?

## Deliverables
- Docs v1
- Quick start tested by a peer
- Screenshots/photos added

## Optional lane notes
- Instrument: wiring + enclosure notes.
- Plugin: install paths + DAW notes.
- Installation: site setup + teardown routine.
