# Week 03 — MVP build: smallest playable loop

## Goals
- Implement a playable loop end-to-end.
- Make it impossible to get ‘lost’ in modes.
- Demonstrate it live (even rough).

## Studio
Build the smallest version that proves the promise. Wire measurement hooks early (logs, meters).

## Critique prompt
What does the MVP *teach* the user about itself?

## Deliverables
- MVP demo (video or in-person)
- Known issues list
- Release plan draft

## Optional lane notes
- Instrument: one mode, 4–8 controls, stable MIDI output.
- Plugin: one block, stable gain staging.
- Installation: one sensor → mapping → output.
