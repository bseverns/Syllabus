# Week 01 — Choose a user + write the promise

## Goals
- Name a real user (even if it’s ‘future you under pressure’).
- Write a one-paragraph promise: what the tool guarantees.
- Define one failure mode you will prevent.

## Studio
Create `project/USER_STORY.md` and `project/PROMISE.md`. Draft a minimal control surface and a minimal output behavior.

## Critique prompt
If I hand this to a stranger, what is the first thing they’ll misunderstand?

## Deliverables
- User story + promise docs
- Control surface sketch (photo or diagram)
- Initial risk list (top 5 ways it fails)

## Optional lane notes
- Instrument: define physical controls + MIDI contract.
- Plugin: define parameters + automation behavior.
- Installation: define inputs/outputs + environment constraints.
