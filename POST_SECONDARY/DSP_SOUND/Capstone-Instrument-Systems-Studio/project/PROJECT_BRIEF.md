# Capstone Project Brief

Ship one instrument/system that satisfies your Week 1 promise.

Minimum requirements:
- explicit architecture + contracts
- measurement harness (at least 3 tests)
- recovery path (safe mode or equivalent)
- user-facing documentation (quick start + troubleshooting + controls)
- release notes (versioned, honest)

Recommended:
- a user test (Week 10)
- a “touring mode” profile (stable defaults, low CPU)
