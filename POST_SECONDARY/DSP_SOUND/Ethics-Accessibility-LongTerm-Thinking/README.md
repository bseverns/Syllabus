# #7 — Ethics, Accessibility, and Long‑Term Thinking (12 weeks)
**Design literacy for people who build systems.**  
Advanced high school / undergraduate • studio + critique + fieldwork

This course treats ethics as an engineering constraint and accessibility as a creative medium.
Students learn to build **responsible instruments and interactive systems** that:
- respect people (consent-forward design),
- respect bodies and brains (accessibility),
- respect materials (repairability + sustainability),
- respect communities (open-source ecosystems + documentation as care).

## What students ship
A **Responsibility Pack** for a real artifact (their own, a lab device, or a case-study device):
- transparency + data/consent statement
- accessibility audit + redesign plan (with a tested improvement)
- repairability + maintenance plan (parts, modularity, versioning)
- licensing + attribution plan
- documentation contribution (open tool OR internal doc upgrade)
- user test notes (including at least one accessibility-focused test)
