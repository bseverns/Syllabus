# Syllabus — Ethics, Accessibility, and Long‑Term Thinking

## Course promise
You will learn to make systems that can be used, repaired, understood, and trusted.

We treat ethics like a design spec:
- explicit assumptions
- clear contracts
- measurable commitments
- recoverable failure modes

## Studio loop (weekly)
1) inspect a system (what it does, what it hides)
2) name a harm or barrier (specific, not abstract)
3) design a mitigation (smallest useful improvement)
4) test it with a human or a protocol
5) document it so others can repeat it

## What you need
- notebook (paper welcome)
- basic ability to build or analyze a simple system (hardware or software)
- willingness to test with others respectfully
