# Bench checklist (Responsibility Pack)

## Transparency + consent
- [ ] consent/data statement complete
- [ ] opt-out/revocation behavior documented
- [ ] retention/storage addressed

## Accessibility
- [ ] baseline audit complete
- [ ] at least one improvement implemented
- [ ] improvement tested and documented

## Repairability + long-term
- [ ] repairability audit complete
- [ ] maintenance plan includes tools/spares/versions
- [ ] recovery demo documented (safe mode/reset/rollback)

## Documentation
- [ ] quick start tested by a peer
- [ ] troubleshooting includes 3+ failure cases
- [ ] diagram included

## Release hygiene
- [ ] changelog updated
- [ ] credits + third-party notices complete
- [ ] postmortem written
