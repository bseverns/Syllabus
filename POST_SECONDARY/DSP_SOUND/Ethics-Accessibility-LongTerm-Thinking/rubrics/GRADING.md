# Grading (0–4 per category)

1) **Clarity of promise**
- 0: no promise
- 2: promise exists but vague
- 4: promise measurable + reflected in design decisions

2) **Accessibility work**
- 0: no audit
- 2: audit done, changes minimal or untested
- 4: change implemented and tested; documentation updated

3) **Transparency + consent**
- 0: unclear data practices
- 2: disclosure drafted
- 4: disclosure + opt-out + retention plan + failure behavior documented

4) **Repairability + sustainability**
- 0: ignored
- 2: audited
- 4: improvement made + maintenance plan + lifecycle note with honesty

5) **Documentation quality**
- 0: incomplete
- 2: basic quick start
- 4: quick start tested + troubleshooting + diagrams + known unknowns

6) **Ecosystem contribution**
- 0: none
- 2: internal improvement only
- 4: meaningful contribution with community-aware process

7) **Evidence discipline**
- 0: claims only
- 2: some evidence
- 4: repeatable evidence and clear before/after comparisons
