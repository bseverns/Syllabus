# HW 08 — Documentation test

1. Complete `templates/QUICK_START.md` and `templates/TROUBLESHOOTING.md` for a first-time user/maintainer.
2. Ask a consenting peer to perform one safe task using only the documentation, or run a structured self-test with fresh-state screenshots if peer testing is unavailable.
3. Observe silently until a stop condition occurs. Record where the reader paused, guessed, recovered, or needed hidden knowledge.
4. Revise the documentation and preserve a before/after diff in `export/`.
5. Add `project/DOC_TEST_NOTES.md` with task, evidence, changes, access route, and known unknowns.

Do not test on live production systems, private accounts, or unsafe equipment.

Submit: see `assignments/SUBMISSION.md`.
