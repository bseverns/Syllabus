# Resourcing

## Space
- seminar classroom for critique + discussion
- lab access for redesign sprints (hardware or software work)
- quiet area for user tests when possible

## Materials
- depends on artifacts; course can run with minimal spend
- recommended: basic accessibility testing aids (label tape, tactile dots, spare knobs, contrast cards)

## Time structure
- 2× 90 min/week + open lab hour
- or 1× 3-hour studio/week + optional office hour
