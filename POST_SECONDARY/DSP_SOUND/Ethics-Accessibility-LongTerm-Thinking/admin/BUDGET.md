# Budget (planning ranges)

This course is intentionally low-cost because it focuses on audits, documentation,
and small but meaningful improvements.

## Per-student
- low: $0–$30 (mostly docs + software; small materials)
- mid: $40–$120 (tactile markers, replacement knobs, buttons, small enclosure parts)
- high: $150–$300 (significant redesign, new sensors/boards)

## Shared
- consumables: $100–$400
- printing/labels: $40–$150
