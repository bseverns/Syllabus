# Week 09 — Redesign sprint I (accessibility)

## Goals
- Implement one accessibility improvement.
- Test it against your plan.
- Document the change and its evidence.

## Studio plan
Build the smallest accessibility change that matters: contrast, labeling, tactile cues, mode feedback, control spacing, alternate input path, simplified language.

## Deliverables (this week)
- Accessibility change implemented (artifact evidence)
- `project/ACCESSIBILITY_CHANGELOG.md` (what changed + why)
- `export/` evidence (photo, plot, test results)

## Critique prompt
Did the change make the system calmer for more people?
