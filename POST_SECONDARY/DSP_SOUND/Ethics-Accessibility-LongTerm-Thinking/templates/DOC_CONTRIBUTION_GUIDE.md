# Documentation contribution guide (template)

## Choose a target
- a confusing README section
- missing setup steps
- unclear troubleshooting
- poor diagrams

## Make a minimal improvement
- one clarified paragraph
- one diagram
- one checklist

## Validate
- have a peer follow the instructions
- confirm steps work on a fresh machine if possible

## Submit
- keep changes small and reviewable
- explain the “why” in the PR/commit message
