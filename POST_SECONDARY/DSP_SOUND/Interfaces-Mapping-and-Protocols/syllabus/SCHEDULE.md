# 12-Week Schedule

1. Control is a signal (measure first) — Serial logging
2. Mapping curves — deadband, smoothing, hysteresis
3. MIDI as a language — CC/Note, 7-bit, discipline
4. OSC routing — address design and clarity
5. Timing — throttling, priority, meaningful change
6. Gestures — long-press, double-click, velocity
7. Feedback — LED language, mode legibility
8. Configuration — schema, validation, safe apply
9. Presets + persistence — versioning configs
10. Testing — golden logs, regressions, “don’t break the gig”
11. Build week — unify contract + behavior + docs
12. Showcase — release notes and critique
