# Syllabus — Interfaces, Mapping, and Protocols (12 weeks)

**Audience:** advanced high school / undergraduate  
**Mode:** studio lab + critique + shipping artifacts  
**Core loop:** measure → map → feel → document → repeat

Translate physical gestures into digital meaning: protocols, mapping, feedback, and configuration.

See `syllabus/SCHEDULE.md`.

## ClassHub Delivery Map

| Phase | Required private evidence | ClassHub materials |
| --- | --- | --- |
| Weeks 1–3 — measure/map/MIDI | Baseline logs, mapping curves, deadband/smoothing choices, MIDI contract, and versioned code | Measurement checklist; private code/data uploads; reflection |
| Weeks 4–7 — OSC/timing/gestures/feedback | Address map, rate policy, gesture tests, LED language, and mode-legibility evidence | Protocol checklist; private files/video; midpoint rubric |
| Weeks 8–10 — config/presets/tests | Validated schema, safe-apply behavior, versioned presets, golden logs, and regression evidence | Reliability checklist; private config/code uploads; test reflection |
| Weeks 11–12 — build/release | Unified contract/behavior, docs, release notes, demo, and critique response | Final rubric; private portfolio upload; optional consent-cleared gallery demo |

Keep endpoint addresses, identifiers, credentials, and production configurations private. Scope helper support to contracts, mappings, validation, and diagnostic tests—not interaction authorship.
