# HW 05 — Sensor thresholds and hysteresis

1. Measure the usable input range of the local sensor or potentiometer fallback.
2. Choose separate on/off thresholds from evidence and record why the gap is large enough.
3. Log a slow sweep through both thresholds and plot raw value plus state.
4. Define behavior for unplugged, saturated, or implausible input.

Submit inspected wiring, firmware, CSV/plot, threshold/state diagram, and `reflections/week05.md` naming the stability/responsiveness tradeoff.
