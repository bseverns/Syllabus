# HW 12 — Controller build and handoff

1. Freeze a pin map and power budget before integrating subsystems.
2. Prove four knobs, four buttons, three feedback states, two modes, debouncing, deadband, and non-blocking event output—or document an approved reduced-scope equivalent.
3. Run a repeatable bench test including startup, every control, mode change, unplug/reconnect, and one safe failure/recovery case.
4. Ask a peer to use the wiring/run documentation without hidden coaching and revise it.
5. Present a two-to-four-minute live or recorded demo plus one honest known unknown.

Submit source, board/version record, wiring/pin map, BOM, logs/plot, bench checklist, rebuild notes, report, and `reflections/week12.md`.
