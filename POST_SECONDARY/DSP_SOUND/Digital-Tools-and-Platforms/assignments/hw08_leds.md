# HW 08 — Feedback language

1. Define at least three device states with user meaning, required action, and failure consequence.
2. Implement the states with safely wired discrete LEDs or an approved alternative.
3. Add a non-color cue using position, label, pulse pattern, brightness, Serial text, or another accessible channel.
4. Run a silent interpretation test with a consenting peer and revise one ambiguous state.

Submit state table, inspected wiring, firmware, event/state log, test notes, and `reflections/week08.md`. NeoPixels are optional, not required.
