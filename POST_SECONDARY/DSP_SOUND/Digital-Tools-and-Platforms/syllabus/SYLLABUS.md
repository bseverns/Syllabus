# Syllabus — Digital Tools and Platforms (12 weeks)

**Audience:** advanced high school / undergraduate makers  
**Meetings:** 1× 2.5–3h lab per week (or 2× 75m)  
**Core loop:** wire → flash → observe → adjust → document

## Course description
We learn microcontrollers as creative tools: buttons become decisions, pots become parameters, LEDs become feedback.
Students will build durable habits for working with embedded systems: debouncing, non-blocking timing, calibration,
and clean documentation.

## Learning outcomes
Students can:
- build reliable input circuits (buttons, pots, sensors)
- write non-blocking firmware loops
- design state machines for interface modes
- stream data over Serial and interpret it
- (optional) send MIDI messages to a host

## Assessment (suggested)
- Weekly labs + check-ins: 40%
- Assignments/writeups: 25%
- Final build project: 25%
- Participation/critique: 10%
