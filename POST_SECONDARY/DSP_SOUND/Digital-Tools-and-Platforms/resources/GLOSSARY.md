# Glossary (starter)

- **Debounce**: filtering button noise so one press equals one event.
- **Deadband**: ignore tiny changes to prevent spammy output.
- **Hysteresis**: different thresholds for rising vs falling edges (prevents flicker).
- **Non-blocking loop**: code that keeps running without long delays.
- **State machine**: explicit modes and transitions.
- **Calibration**: mapping raw readings to meaningful values.
