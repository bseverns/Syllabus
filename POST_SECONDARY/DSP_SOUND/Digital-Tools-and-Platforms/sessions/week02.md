# Week 02 — Buttons + debounce (make a press mean one thing)

## Goals
- Wire a button safely using internal pullups.
- See mechanical bounce in data.
- Implement and tune a debounce algorithm.

## Session arc (timed)
1. Warm-up (10 min): press a cheap button and guess what the signal looks like
2. Mini-lecture (20–30 min): pullups, floating inputs, bounce as physics
3. Build + flash (40–60 min): flash Week02 sketch; view raw/debounced
4. Observe + log (20 min): log + plot; tune debounce ms
5. Share-out (15 min): what value felt best and why?
6. Close (10 min): introduce hysteresis as cousin concept

## Prep (instructor)
- Bring a few different button types if possible.
- Show one scope screenshot if you have it (optional).
