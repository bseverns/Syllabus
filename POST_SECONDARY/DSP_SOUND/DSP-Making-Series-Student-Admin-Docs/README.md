# Student + Admin Docs — DSP / Digital Making Series (8-part arc)

This repository is a **document stack** for a full learning series spanning:
1) Foundations of Signals & Systems
2) Digital Tools & Platforms
3) DSP Essentials
4) Instruments & Interfaces
5) Systems Thinking & Modularity
6) Creative Applications & Composition
7) Ethics, Accessibility, Long-Term Thinking
8) Capstone Projects

It’s written so:
- **students** can understand what they’re joining and how to succeed, and
- **administrators** can approve, staff, budget, and evaluate it.

## Repo map
- `docs/student/` — handbooks, FAQs, expectations, how to prepare, how you’re assessed
- `docs/admin/` — program brief, staffing, budget, facilities, risk/safety, evaluation plan
- `docs/shared/` — the program story, learning outcomes, rubrics, common templates
- `course_one_pagers/` — one page per module (8)
- `templates/` — reusable forms: equipment checkout, incident log, critique sheet, etc.
