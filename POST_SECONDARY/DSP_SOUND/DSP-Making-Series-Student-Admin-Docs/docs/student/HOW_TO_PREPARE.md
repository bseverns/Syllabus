# How to prepare (student)

## Before Module 1 (Signals)
- install Audacity (or use lab computers)
- install Python (or use hosted notebooks if provided)
- bring headphones

## Before Module 2 (Digital Tools)
- be ready to learn breadboards and basic wiring
- expect tiny failures (loose wires are teachers)

## Before Module 4 (Interfaces)
- start collecting references: controllers, instruments, accessibility examples

## Before Capstone
- decide what you want to *promise* to a user
- plan to test with at least one person who isn’t you
