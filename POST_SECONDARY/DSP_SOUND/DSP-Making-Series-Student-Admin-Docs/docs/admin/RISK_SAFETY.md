# Risk + safety

## Electronics
- soldering safety training
- battery handling (if used) and storage procedures
- no mains projects without qualified supervision

## Fabrication
- tool training requirements for laser/3D printing
- PPE and machine supervision policies

## Data + consent
- if projects capture audio/video/sensors about people, require disclosure and opt-out options
- document data handling in student projects

## Accessibility
- require at least one accessibility check in each interface project
- ensure lab space accommodates diverse bodies and sensory needs
