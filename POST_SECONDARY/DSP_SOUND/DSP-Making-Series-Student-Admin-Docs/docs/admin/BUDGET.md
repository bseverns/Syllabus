# Budget (planning ranges)

Budgets vary by lane emphasis (plugin vs embedded vs fabrication).
These are **order-of-magnitude** ranges for planning.

## Per-student (typical)
- low: $40–$75 (shared hardware, minimal fabrication)
- mid: $90–$180 (microcontroller + sensor pack + small interface parts)
- high: $250–$500+ (custom enclosures, higher-end boards, extra actuators)

## Shared lab costs (annual)
- consumables (solder, wire, heatshrink, tape): $200–$800
- tools maintenance (tips, bits, PPE): $150–$600
- replacement cables/adapters: $150–$500

## Notes
- Open-source tooling is prioritized.
- Licenses are optional; workflows exist without paid DAWs.
