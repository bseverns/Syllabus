# Evaluation plan (admin)

## What we evaluate
- student learning (outcomes + portfolios)
- program feasibility (costs, time, staffing load)
- inclusion/accessibility effectiveness
- artifact quality (documentation, reliability)

## Evidence to collect
- pre/post self-assessments (confidence + skills)
- rubric-scored artifacts (sample each module)
- participation metrics (attendance, lab usage)
- user-test notes (capstone)
- qualitative reflections (student + staff)

## Reporting cadence
- mid-module pulse report
- end-of-module report
- annual synthesis
