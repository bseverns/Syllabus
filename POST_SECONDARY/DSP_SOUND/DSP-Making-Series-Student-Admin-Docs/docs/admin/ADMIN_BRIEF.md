# Admin brief — DSP / Digital Making Series (8-part arc)

## Summary
This series develops students who can build and explain digital instruments and systems:
- technically rigorous (measurable, testable)
- creatively expressive (composition, performance)
- responsible (ethics, accessibility, repairability)

## Why this matters
Students gain:
- practical DSP and embedded skills applicable to audio, robotics, interaction design
- portfolio-ready artifacts and documentation
- systems thinking that transfers across disciplines

## Format options
- 8 modules × 6–12 weeks each (semester blocks)
- intensive summer institute (compressed)
- stackable certificates / badges
