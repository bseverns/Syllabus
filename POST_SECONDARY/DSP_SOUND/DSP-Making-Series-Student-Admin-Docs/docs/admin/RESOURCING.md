# Resourcing + staffing

## Staffing (recommended)
- Lead instructor (DSP + systems)
- Lab tech / TA (hardware, soldering, fabrication safety)
- Optional: accessibility consultant / UX mentor

## Space
- classroom with projector
- lab benches (electronics)
- access to fabrication (laser cutter / 3D printers) for interface weeks

## Time
- 2× 90 min sessions/week + open lab hour (ideal)
- or 1× 3-hour studio session/week (works if labs are supported)

## Materials management
- labeled kits per student/team
- checkout forms
- spares for wear items (jumpers, pots, buttons, USB cables)
