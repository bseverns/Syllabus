# Learning outcomes (program-level)

By the end of the full series, students can:

## Signals + DSP
- explain sampling, aliasing, frequency-domain thinking, filtering
- implement and test basic DSP blocks (filters, envelopes, delay, distortion, modulation)
- interpret plots and measurements (RMS/peak, spectra, step/impulse responses)

## Hardware + Real-time
- connect sensors/actuators to code (microcontrollers + embedded systems)
- understand real-time constraints, latency, and jitter as design materials
- build robust input systems (debounce, smoothing, calibration)

## Instruments + Systems
- design interfaces for playability and accessibility
- map sensor data to sound/control with intention and guardrails
- build modular systems with explicit contracts (state machines, protocols, versioning)

## Authorship + Responsibility
- compose/perform with their systems (automation, generativity, feedback)
- document work so others can reproduce and learn
- apply ethics: consent-forward design, right-to-repair, sustainability, inclusive UX
