# Series structure guide

## Stackable design
Each module can stand alone, but the full arc compounds power.

Recommended pairing:
- 1 + 2 as an intro year/semester
- 3 + 4 as an intermediate year/semester
- 5 + 6 as an advanced year/semester
- 7 + 8 as a capstone year/semester

## Optional lanes inside modules
- Plugin lane: DAW + WebAudio + JUCE
- Embedded lane: Arduino/Teensy/Daisy
- Fabrication lane: interface building
- Systems lane: networking + OSC + logging

The course should never punish students for choosing a lane.
Instead, require **contracts + evidence** in every lane.
