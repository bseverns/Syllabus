# Module 4: Building Instruments and Interfaces — one-pager

## What this module is
A focused loop of **build → measure → listen/observe → document → improve**.

## Key concepts
- Human-centered design
- MIDI and mapping
- Feedback loops

## Tools (flexible)
- MIDI controllers
- WebMIDI
- Fabrication tools
- Debounce/filtering

## Activities (examples)
- Design a controller for a DAW synth
- Build custom controller with LEDs
- Map for expression

## Learning goals
- Design for playability, responsiveness, and clarity under pressure.

## Evidence you’ll leave with
- one working artifact (code, patch, hardware, or system)
- one measurement or observation artifact (plot/log/A-B render)
- one page of documentation explaining how it works and how to run it
