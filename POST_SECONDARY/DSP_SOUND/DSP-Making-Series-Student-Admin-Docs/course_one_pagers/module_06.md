# Module 6: Creative Applications & Composition — one-pager

## What this module is
A focused loop of **build → measure → listen/observe → document → improve**.

## Key concepts
- Generativity and feedback
- Performance systems
- Automation as composition

## Tools (flexible)
- DAWs
- Sonic Pi/TidalCycles
- Generative tools

## Activities (examples)
- Compose with custom controller
- Perform with envelope followers
- Automate systems musically

## Learning goals
- Use technical knowledge for expressive ends; connect design to aesthetics.

## Evidence you’ll leave with
- one working artifact (code, patch, hardware, or system)
- one measurement or observation artifact (plot/log/A-B render)
- one page of documentation explaining how it works and how to run it
