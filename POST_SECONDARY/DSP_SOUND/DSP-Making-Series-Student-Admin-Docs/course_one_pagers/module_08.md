# Module 8: Capstone Projects — one-pager

## What this module is
A focused loop of **build → measure → listen/observe → document → improve**.

## Key concepts
- Iteration + integration
- User testing
- Shipping and documentation

## Tools (flexible)
- Any stack; lane-based

## Activities (examples)
- Adaptive MIDI controller
- Environmental sonification system
- FFT-explainer instrument

## Learning goals
- Deliver a shipped artifact with documentation, evidence, and user experience focus.

## Evidence you’ll leave with
- one working artifact (code, patch, hardware, or system)
- one measurement or observation artifact (plot/log/A-B render)
- one page of documentation explaining how it works and how to run it
