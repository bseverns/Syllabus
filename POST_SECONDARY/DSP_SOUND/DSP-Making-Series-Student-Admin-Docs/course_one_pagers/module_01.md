# Module 1: Foundations of Signals and Systems — one-pager

## What this module is
A focused loop of **build → measure → listen/observe → document → improve**.

## Key concepts
- Waveforms and sampling
- Time vs frequency domain
- Filters as tools, not mysteries

## Tools (flexible)
- Audacity
- Oscilloscope apps
- Python (NumPy/SciPy)

## Activities (examples)
- Record/visualize sounds
- Draw waveforms and hear the difference
- Simulate sampling + aliasing

## Learning goals
- Understand how analog signals become digital, and how to manipulate them responsibly.

## Evidence you’ll leave with
- one working artifact (code, patch, hardware, or system)
- one measurement or observation artifact (plot/log/A-B render)
- one page of documentation explaining how it works and how to run it
