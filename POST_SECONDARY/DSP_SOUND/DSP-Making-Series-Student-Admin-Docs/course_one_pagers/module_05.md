# Module 5: Systems Thinking & Modularity — one-pager

## What this module is
A focused loop of **build → measure → listen/observe → document → improve**.

## Key concepts
- Abstraction and state machines
- Protocols (I2C/SPI/OSC)
- Versioning + contracts

## Tools (flexible)
- Git
- JSON
- Modular firmware
- Simulation tools

## Activities (examples)
- Reverse-engineer a system
- Design reusable function blocks
- Define contracts + tests

## Learning goals
- Break complex problems into testable units; build maintainable systems.

## Evidence you’ll leave with
- one working artifact (code, patch, hardware, or system)
- one measurement or observation artifact (plot/log/A-B render)
- one page of documentation explaining how it works and how to run it
