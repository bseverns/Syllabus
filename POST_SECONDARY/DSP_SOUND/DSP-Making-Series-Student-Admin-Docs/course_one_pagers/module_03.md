# Module 3: Digital Signal Processing Essentials — one-pager

## What this module is
A focused loop of **build → measure → listen/observe → document → improve**.

## Key concepts
- Filtering and convolution
- FFT as a lens
- Envelopes and modulation

## Tools (flexible)
- Python notebooks
- Pure Data/Max
- WebAudio, Teensy Audio

## Activities (examples)
- Build a filter and visualize response
- Simple synth voice
- Compare MCU vs PC DSP

## Learning goals
- Translate math into sound transformations with evidence.

## Evidence you’ll leave with
- one working artifact (code, patch, hardware, or system)
- one measurement or observation artifact (plot/log/A-B render)
- one page of documentation explaining how it works and how to run it
