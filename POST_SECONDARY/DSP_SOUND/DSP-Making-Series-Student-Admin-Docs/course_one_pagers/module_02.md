# Module 2: Introduction to Digital Tools and Platforms — one-pager

## What this module is
A focused loop of **build → measure → listen/observe → document → improve**.

## Key concepts
- Microcontrollers and GPIO
- Sensors/actuators
- Real-time constraints

## Tools (flexible)
- Arduino / Teensy
- Raspberry Pi
- Breadboarding

## Activities (examples)
- LED reacts to microphone
- Touch-based MIDI trigger
- Debounce + smoothing

## Learning goals
- Connect code to physical behavior; learn timing and reliability basics.

## Evidence you’ll leave with
- one working artifact (code, patch, hardware, or system)
- one measurement or observation artifact (plot/log/A-B render)
- one page of documentation explaining how it works and how to run it
