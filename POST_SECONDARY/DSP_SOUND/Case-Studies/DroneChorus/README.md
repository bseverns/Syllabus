# Drone Chorus — Case Study (Telemetry → MIDI → VCV)

This case study is the “one sitting” walkthrough: a structured demo you can run
in ~10–15 minutes, then expand into a full workshop or performance rehearsal.

If you’re new to the repo, the canonical deep docs are still:
- `docs/CONTROL_STACK_PLAYBOOK.md`
- `docs/checklists/SAFETY.md`
- `docs/EXPERIENCE_PLAYBOOK.md`
- `docs/UX_MAP.md`
- `docs/LIVE_WORKFLOW.md`

This folder is the **bridge**: it turns those into a single, repeatable sequence.

## What you’ll do
- prove the pipeline with a sample MSP log (no props, no flight),
- show how `config/mapping.yaml` shapes “feel” (slew + curve),
- make the VCV patch respond in a legible way,
- scale to multi-drone channels,
- and keep the room safe (ears, audience, hardware).

Start here:
- `DEMO_EXERCISES.md` (the run-of-show)
- `VIDEO_COMPANION.md` (chapters + overlays)
- `MODULE_CROSSWALK_DSP_SOUND.md` (optional: where this maps into DSP_SOUND)
- `SUPPORTING_DOCS_NEEDED.md` (the FPV “deeper ocean” checklist)
