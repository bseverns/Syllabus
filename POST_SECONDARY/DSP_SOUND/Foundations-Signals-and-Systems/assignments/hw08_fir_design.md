# HW 08 — FIR filter design: sculpting frequency response

## Prompts
1. Design one FIR low-pass, high-pass, or band-pass filter for a stated signal problem. Record sample rate, cutoff/band edges, and tap count.
2. Plot impulse response and frequency response with labeled axes.
3. Test the filter on a signal containing wanted and unwanted components. Compare input/output in time and frequency views.
4. Change tap count while holding the target band fixed. Explain the cost and benefit using measured evidence.
