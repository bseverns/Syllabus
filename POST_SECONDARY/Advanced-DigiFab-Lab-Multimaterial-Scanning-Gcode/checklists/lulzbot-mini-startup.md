# LulzBot Mini — Startup Checklist
- [ ] Inspect nozzle tip; remove carbon; verify fan spins freely.
- [ ] Verify bed is clean; apply glue stick if printing PETG on PEI.
- [ ] Load filament; purge 30–50 mm until color is pure.
- [ ] Choose the correct **start G-code variant** (G29 vs. M420) in your slicer.
- [ ] Run first-layer test square; adjust Z-offset only if needed (log changes).
