# G‑code Hacks

Small, testable edits that improve ops or add capabilities.
- **Start/End Templates:** Purge line, bed‑wipe, safe park.
- **Pauses & Inserts:** `M0` (generic) / `M25` (SD pause) / `M600` (filament change) — depends on firmware.
- **Conditional Logic:** Some slicers allow simple variables/macros; keep comments and a rollback.
