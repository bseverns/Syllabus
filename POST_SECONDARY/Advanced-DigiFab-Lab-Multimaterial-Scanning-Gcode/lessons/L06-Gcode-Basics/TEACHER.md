# Teacher Guide — L06 Gcode Basics

## Block A — Concept & Demo
- Live demo with a **risk call‑out** (what can go wrong, how to bail).
- Emphasize **why** the technique matters for reliability or capability.

## Block B — Lab Shift
- Assign roles (operator, observer, documentarian, QC).
- Capture evidence (photos, settings, logs).

## Prep
- Pre‑slice a demo with annotated settings.
- Stage a recovery scenario (e.g., jam, resume‑after‑pause, support dissolution).

- Exit ticket prompt in `assessments/checkpoints` for this lesson.
