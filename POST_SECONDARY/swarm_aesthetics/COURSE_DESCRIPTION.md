# Swarm Aesthetics: Perceptual Drift Studio

## Course description

Swarm Aesthetics is a studio course about coordinated behavior, distributed systems, and the aesthetics of collective movement. Students approach swarms not as a single discipline, but as an encounter between systems thinking, performance design, interface design, and critical media practice.

The course uses the idea of perceptual drift as a core anchor: how small local rules, sensing assumptions, role assignments, and interface decisions can accumulate into a collective event that feels unstable, uncanny, legible, poetic, or political. Students read and redraw system diagrams, write drift recipes, build low-risk prototype swarms, and stage a modest showing supported by signage, scripts, and documentation.

The emphasis is on:

- systems literacy instead of gadget worship
- structured experimentation instead of improvising from hype
- clear roles and protocols instead of vague collaboration
- reflective documentation instead of "it worked in the room"

The course is intentionally adaptable. It can run as:

- simulation-only
- screen or tabletop swarm installation
- hybrid sensing / telemetry performance lab

## Learning outcomes

By the end of the course, students should be able to:

1. describe a swarm or distributed artwork as a system with layers, assumptions, and failure points
2. analyze how rules, mappings, feedback, and interfaces shape collective behavior
3. produce readable system maps, role cards, recipes, and rehearsal documents
4. build and critique a low-risk swarm prototype
5. stage and document a final drift event with clear audience framing

## Typical outputs

Students should leave with:

- one system map
- one annotated reading response
- one drift recipe
- one role-card set
- one prototype study
- one rehearsal packet
- one final showing and documentation bundle

## Prerequisites

No single technical prerequisite is required, but students should be prepared to:

- read critically
- diagram a system
- work in small groups
- test and revise an idea in public

## Recommended context

This course pairs well with adjacent work in this repo such as `fpv-primer`, `TinyWhoop-Workshop`, or `drone-chorus`, but it does not require live flight or advanced hardware. Those can remain optional extensions rather than hidden prerequisites.
