Swarm Aesthetics is a studio exploring swarms as technical systems and aesthetic events. Students read and redraw system diagrams (with *perceptual-drift* as a core anchor), write recipes and role cards for "drifts", build low-risk swarm-like prototypes, and stage a modest event or in-class run. The emphasis is on systems thinking, careful experimentation, and critical reflection rather than any particular tech stack.
