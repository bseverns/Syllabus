# Swarm Aesthetics: Reading & Viewing List

This file now points to actual sources rather than placeholder themes. The list is intentionally mixed:

- primary texts where possible
- official author, publisher, museum, or project pages
- a few book pages when a canonical source is important but not freely hosted

Access varies. Some entries are free online, while others are publisher or archive pages that help students locate the text responsibly.

## Selection principle

Choose readings that help students do one of the following in the same week:

- draw a better system map
- write a more executable recipe
- justify a mapping choice
- stage a clearer event
- document evidence more honestly

If a reading cannot support one of those actions, it is probably extra rather than essential.
