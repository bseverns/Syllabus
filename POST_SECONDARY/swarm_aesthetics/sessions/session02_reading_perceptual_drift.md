# Session 02 – Reading Perceptual Drift

## At a glance

- approximate length: 2 to 3 hours
- focus: close reading, diagram redraws, and extracting operative logic
- output: annotated reading response + revised system diagram

## Before class

- assign the course anchor text or project notes related to perceptual drift
- ask students to bring one marked passage that describes behavior, not just theme

## In-class plan

1. Start with a passage round: each student reads one marked line and explains why it matters.
2. Build a board list of recurring terms:
   - drift
   - signal
   - uncertainty
   - coordination
   - threshold
3. Ask students to redraw the text as a system using `templates/system-map-template.md`.
4. Compare redraws and note where interpretation changes the apparent system.
5. End with a short writing prompt on how diagrams clarify or distort a work.

## Artifacts

- annotated reading response
- revised system diagram tied to the reading

## Instructor notes

- do not let the session become pure interpretation
- keep asking what the text implies about rules, sensing, roles, and perception
