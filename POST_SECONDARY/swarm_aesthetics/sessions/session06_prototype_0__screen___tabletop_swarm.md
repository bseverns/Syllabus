# Session 06 – Prototype 0: Screen / Tabletop Swarm

## At a glance

- approximate length: 2 to 3 hours
- focus: build the smallest version that proves the core behavior
- output: prototype evidence + test notes

## Before class

- require groups to arrive with a recipe, roles, and one system map
- define the room layout and available materials clearly

## In-class plan

1. Open with the rule: prove the smallest viable version first.
2. Give groups build time to realize a screen-based or tabletop prototype.
3. Midway through class, stop for a proof check:
   - what rule is actually functioning?
   - what is still simulated by explanation?
4. Resume build and run at least one short documented test.
5. Close with a critique focused on legibility, not ambition.

## Artifacts

- video or photo evidence of Prototype 0
- short test notes describing what worked and what failed

## Instructor notes

- scope control matters here more than polish
- if a group cannot show behavior, cut features immediately
