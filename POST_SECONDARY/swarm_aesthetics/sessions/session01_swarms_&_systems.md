# Session 01 – Swarms & Systems

## At a glance

- approximate length: 2 to 3 hours
- focus: shared vocabulary for systems, swarms, and distributed behavior
- output: first-pass system map

## Before class

- assign one short systems reading and one visual swarm reference
- print or duplicate `templates/system-map-template.md`
- decide whether the course is running simulation-only, tabletop, or hybrid

## In-class plan

1. Open with course framing: what this class is and what it is not.
2. Ask students to list examples of coordinated behavior they have seen in art, code, animals, crowds, or games.
3. Introduce a simple systems stack:
   - inputs
   - rules
   - outputs
   - audience perception
4. Read one swarm example together and identify:
   - what is local
   - what is shared
   - what feedback exists
5. In pairs, draft a first system map for a chosen example.
6. Close with a short critique focused on clarity rather than originality.

## Artifacts

- one first-pass system map per student or pair
- one paragraph answering: "what makes this a system instead of just a group?"

## Instructor notes

- push students to describe mechanisms, not just moods
- if discussion gets abstract, ask what an observer would actually see
- keep the first artifact small and legible
