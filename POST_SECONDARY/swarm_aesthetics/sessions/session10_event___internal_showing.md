# Session 10 – Event / Internal Showing

## At a glance

- approximate length: 2 to 3 hours
- focus: install, run, observe, and capture evidence
- output: internal showing + raw documentation

## Before class

- duplicate `templates/documentation-checklist.md`
- confirm who is capturing photo, video, notes, and any live screen or signal output

## In-class plan

1. Set up the room with attention to audience flow and operator space.
2. Run a quick preflight using the group's run sheet.
3. Stage the internal showing.
4. Assign observers to note:
   - what was legible
   - where confusion appeared
   - where timing or behavior drifted
5. Archive raw materials before the class ends.

## Artifacts

- internal showing completed
- raw documentation capture collected and backed up
- observer notes

## Instructor notes

- protect time for documentation
- if a run fails, document the failure clearly rather than hiding it
