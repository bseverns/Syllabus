# Session 08 – Rehearsal Lab

## At a glance

- approximate length: 2 to 3 hours
- focus: cues, timing, operator handoff, and failure recovery
- output: rehearsal run sheet + revision log

## Before class

- duplicate `templates/rehearsal-run-of-show.md`
- require each group to arrive with a runnable version, even if rough

## In-class plan

1. Explain that rehearsal is not a soft preview. It is where event logic gets tested.
2. Groups draft or update a run sheet with:
   - setup
   - cueing
   - start and stop
   - fallback actions
3. Run one timed rehearsal per group.
4. Observe with a strict lens:
   - where did timing drift?
   - where did a cue fail?
   - where did audience framing disappear?
5. Log revisions immediately after the run.

## Artifacts

- completed rehearsal run sheet
- revision log after one rehearsal

## Instructor notes

- do not let groups skip run sheets because they think the piece is intuitive
- insist on named operator responsibilities
