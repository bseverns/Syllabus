# Session 03 – Recipes & Roles

## At a glance

- approximate length: 2 to 3 hours
- focus: translating swarm behavior into instructions and responsibilities
- output: first drift recipe + role-card draft

## Before class

- prepare examples of instruction-based art, scores, or protocols
- duplicate `templates/drift-recipe-template.md` and `templates/role-card-template.md`

## In-class plan

1. Discuss how instructions differ from explanations.
2. Analyze one score or protocol and identify:
   - what it makes possible
   - what it leaves open
   - what can fail
3. In groups, draft a drift recipe for a small swarm event.
4. Convert the recipe into roles:
   - operator
   - participant
   - observer
   - documentarian
5. Run a dry tabletop rehearsal using only the written materials.

## Artifacts

- one recipe draft
- one role-card set
- one note on what was unclear in rehearsal

## Instructor notes

- if the group cannot run the recipe from the page, the recipe is not finished
- push for explicit stop and reset conditions
