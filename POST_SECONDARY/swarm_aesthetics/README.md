# Swarm Aesthetics: Perceptual Drift Studio

Swarm Aesthetics is a post-secondary studio about swarms as both technical systems and aesthetic events. The course is deliberately low-risk and modular: it can run as screen-based simulation, tabletop installation, or a bridge into more complex telemetry and performance systems.

This version is structured as a runnable teaching package rather than a placeholder.

## Course spine

- `COURSE_DESCRIPTION.md`: catalog-style overview, outcomes, and framing
- `SCHEDULE.md`: 12-session arc with weekly goals and artifacts
- `ASSIGNMENTS.md`: grading model and deliverable expectations
- `ASSESSMENT_RUBRIC.md`: criteria for critique, process, systems thinking, and final presentation
- `INSTRUCTOR_NOTES.md`: setup, pacing, risk tiers, and facilitation guidance
- `READINGS.md`: week-by-week reading and viewing clusters
- `PROJECT_BRIEF.md`: final drift event and documentation bundle

The `sessions/` folder now contains session-by-session plans with:

- in-class sequence
- required artifacts
- instructor notes

## Teaching stance

This course borrows the strongest pattern from the more mature primers in this repo:

- artifact-first learning
- explicit systems language
- low-risk prototyping before spectacle
- critique tied to evidence instead of vibes alone

Students should leave with a small but serious portfolio: system maps, recipes, role cards, prototype evidence, rehearsal documents, and a documented final showing.
