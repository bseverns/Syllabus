# Session 03 – Chopping & Slicing

## At a glance

- **Length:** 90 minutes  
- **Mode:** Lab  
- **Goals:**
  - Introduce slicing a longer recording into smaller fragments.
  - Practice organizing slices on a grid or in a sampler.
  - Build a new loop from chopped material.
- **Deliverables:**
  - One “chopped loop” version of a recording.

## Before class (instructor)

- Prepare a demo recording with clear transient events (claps, steps, speech).
- Test slicing tools in the DAW / sampler you’re using.

## In-class plan

### 0–10 min — Warm-up listen

- Play one student loop from last time.
- Ask:
  - “If we chopped this into 8 pieces, which moments would you keep?”

### 10–30 min — Demo: Slice a Longer Recording

- Show:
  - Selecting a longer clip (10–30 seconds).
  - Manually placing slice markers at interesting points.
  - Mapping slices to pads or notes.

### 30–70 min — Student slicing lab

- Students:
  - Choose one longer recording (or teacher-provided sample).
  - Create **at least 4 slices** (up to 8).
  - Rearrange slices into a new pattern/loop.
- Encourage:
  - Repetition of “weird” slices.
  - Silences between slices for rhythm.

### 70–85 min — A/B comparison

- Let a few students play:
  - Original loop from Session 02
  - New chopped version
- Discuss:
  - “Which feels more interesting? Why?”

### 85–90 min — Exit ticket

- “One slice I’m proud of is…” (brief description).

## After class / Homework

- Optional: export both original and chopped versions for later use.
