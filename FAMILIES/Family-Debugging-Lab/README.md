# Fix It Together: Family Debugging Lab

A mixed-age family `PILOT` using deliberately faulty instructions, mechanisms, Scratch projects, or LEGO Education SPIKE systems. The goal is not fastest repair: it is a repeatable evidence-based next test.

- **Audience:** family teams with participating caregiver; adaptable from age 6+
- **Format:** one 90-minute workshop or bounded station rotation
- **Screen load:** `S0` minimum; `S2` for digital/SPIKE cases
- **Equipment:** `E0` minimum; `E3` for SPIKE stations
- **Readiness:** `PILOT`

This adaptation draws from the repository's [Debugging course](../../SECONDARY/debugging/) while adding mixed-age roles, prepared cases, and reset controls.
