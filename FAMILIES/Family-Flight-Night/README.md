# Family Flight Night

A simulator-first FPV `PILOT` for an older child or teen paired with an adult. Pairs learn multirotor controls, calm recovery, coaching, and basic aircraft systems without live flight.

- **Audience:** adult–youth pairs; recommended ages 10+
- **Format:** one 90–120-minute workshop
- **Screen load:** `S3–S4`
- **Equipment:** `E3`
- **Readiness:** `PILOT`

This adaptation draws from [TinyWhoop Workshop](../../SECONDARY/TinyWhoop-Workshop/) but deliberately excludes live aircraft, LiPo handling, RF coordination, and racing. The workshop is complete in simulation.
