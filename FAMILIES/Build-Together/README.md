# Build Together: Family Invention Lab

**Readiness:** PILOT  
**Audience:** Mixed-age family teams of 2–5  
**Format:** One 90–120 minute workshop  
**Screen load:** S0 by default; optional S1 with shared SPIKE kits

Build Together is a mixed-age co-making workshop derived from the repository's [Build Your Block](../../PRIMARY/Build_Your_Block/) studio. Each family makes one shared invention, rotates meaningful roles, tests it with another family, and revises from evidence.

The minimum version uses cardboard, recycled materials, tape, markers, fasteners, and optional LEGO or DUPLO. A site may add simple lights or low-voltage motors. SPIKE is an optional extension, not a requirement.

## Participant outcome

Each family leaves with:

- one shared prototype responding to an open prompt;
- a brief record of what they tried, what happened, and what they would change;
- the repeatable process **wonder → build → test → switch roles → revise → share**.

## Delivery boundary

This package is runnable as a bounded pilot but has no documented delivery and revision evidence. Keep it private in the canonical catalog until at least one delivery is reviewed.
