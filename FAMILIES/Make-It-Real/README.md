# Make It Real: Family Digital Fabrication Lab

A family digital-fabrication `PILOT`: sketch and measure a small useful object, model it in CAD, inspect a fabrication preview, and submit one bounded file to a facilitator-managed production queue.

- **Audience:** family teams with participating caregiver; recommended ages 8+
- **Format:** one 120-minute design workshop; fabrication may finish afterward
- **Screen load:** `S2–S3`
- **Equipment:** `E3–E4`
- **Readiness:** `PILOT`

A single event promises design-to-production insight, not a finished print during class or physical iteration. Machine operation remains facilitator-controlled. A return session is required before claiming a test-and-revise fabrication cycle.
