# Make It Real: Family Digital Fabrication Lab — Pilot Syllabus

## Workshop contract

- **Audience:** family teams with participating caregiver; recommended ages 8+
- **Duration:** 120-minute design workshop; facilitator-managed fabrication may occur afterward
- **Capacity:** set by CAD devices and the verified production queue, not room occupancy
- **Result:** a measured CAD model, fabrication preview, and production ticket

A first workshop does **not** promise a finished object during class. A return session is required for physical test-and-revise work.

## Preflight and materials

Choose one tested, account-ready or no-account CAD route. Test export and slicing on every device. Publish maximum dimensions, material, file type, queue, collection, and failure policy. Inspect machines and ventilation under local procedures. Provide paper, pencils, cardboard, calipers/rulers, sample prints, devices, mice, model objects to measure, and production tickets.

## Flow

1. **Encounter — 0–12:** Compare a handmade, printed, and cut sample. Identify where process constraints changed each design.
2. **Brief — 12–25:** Pick one small purpose: hold, label, repair, remember, or share. Name the user and one critical measurement.
3. **Measure and sketch — 25–42:** Make a dimensioned paper sketch and quick cardboard size model.
4. **CAD demonstration — 42–52:** Show only create shape, enter dimension, align/combine, inspect, and export.
5. **Model sprint — 52–82:** Build the minimum viable object. Rotate designer, measurer, navigator, and checker.
6. **Manufacturing check — 82–98:** Inspect scale, thin sections, unsupported geometry, fit, orientation, and whether hand-making would be better.
7. **Preview and ticket — 98–110:** Facilitator verifies file, records dimensions/material/owner, and accepts or returns it with one actionable reason.
8. **Share and close — 110–120:** Families explain purpose, important measurement, likely failure, and version-two change.

## Safety, access, privacy, and fallback

Only trained facilitators operate, clear, service, or reach into printers/CNC equipment. Never bypass guards or ventilation. Provide tactile samples, large-pointer navigation, shared roles, and a paper/cardboard route. Do not require personal accounts. Use family/team identifiers rather than child names on files. If CAD or production fails, the dimensioned sketch, physical size model, and manufacturing review still complete the workshop.

## Observable assessment

A family can connect purpose to a measurement, create or clearly specify a manufacturable form, identify one process constraint, interpret a fabrication preview, and state a test for the physical result.

## Post-delivery review

Record device/login failures, modeling bottlenecks, actual file acceptance rate, queue duration, material use, machine failures, collection success, and changes needed. Update families honestly if a submitted file cannot be produced.
