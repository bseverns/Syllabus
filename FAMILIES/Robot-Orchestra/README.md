# Robot Orchestra

A mixed-age family robotics `PILOT` in which each household programs one expressive sensor-to-behavior score, then joins a shared performance.

- **Audience:** family teams with participating caregiver; recommended ages 7+
- **Format:** one 120-minute workshop
- **Screen load:** `S2`
- **Equipment:** `E3` — one inventoried LEGO Education SPIKE kit and compatible device per team
- **Readiness:** `PILOT`

Starter builds keep the event focused on sensing, expression, debugging, and collaboration rather than identical assembly. Roles rotate so no experienced participant becomes the sole builder or programmer.
