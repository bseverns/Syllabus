# Simulator Training (Week 0 → Ongoing)

**Why sim first:** Zero repair costs, infinite reps, perfect conditions. It builds stick discipline and confidence before risking airframes.

**Recommended sims:**
- **VelociDrone** (race‑focused): https://velocidrone.com/
- **DRL Sim** (training modules + consoles): https://store.steampowered.com/app/641780/The_Drone_Racing_League_Simulator/
- **Liftoff**: https://store.steampowered.com/app/410340/Liftoff_FPV_Drone_Racing/
- **Uncrashed**: https://store.steampowered.com/app/1428350/Uncrashed__FPV_Drone_Simulator/

**Controller setup:**
- Use the same radio you’ll race with (USB). Mode 2 default. Calibrate sticks in‑sim. Copy “rates” to match field quads later.

**Core drills (15–30 min each, 3–4x/week):**
1. **Boxes & Lines:** Draw rectangles with corners; brake before gate, no yaw wiggle.
2. **Ladders:** Ascend/descend through three gates; minimal throttle spikes.
3. **Figure‑8s:** Opposite direction each session; keep horizon stable.
4. **Gate Party:** 50 clean gates in a row without crash. Reset on mistake.
5. **Time Trials:** 3‑lap hot laps; log PBs weekly.

**Video study:** DRL Academy lessons playlist: https://www.drl.io/academy
