# Field Training Drills (Tiny‑Whoop → 5″)

**Safety first:** Spotters, arm/disarm discipline, pit mode on bench, goggles down only on flight line.

## Warm‑ups (every session)
- **LOS hover + squares** (1 pack): check gyro alignment, trims, failsafe.
- **Gate sighting** (1 pack): slow first laps, call out obstacles with spotter.

## Core race skills
1. **Throttle Stepping:** 10‑20‑30‑40% holds on a straight; smooth ascents/descents.
2. **Gate Entries:** “Brake‑float‑yaw‑roll” sequence; practice early apex and late apex.
3. **Split‑S & Powerloop light:** Introduce only when lines are clean.
4. **Passing Protocol:** Only pass on straights; no dive‑bombing; call “on your left.”
5. **Recovery:** Disarm, turtle‑mode if safe, raise hand, marshal assist.
