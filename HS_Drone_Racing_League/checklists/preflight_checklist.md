# Preflight Checklist (Coach/Pilot)

- [ ] TRUST proof carried (outdoor)
- [ ] Field permission / FRIA status known
- [ ] Weather/wind OK; spotters assigned
- [ ] Airspace checked (outdoor)
- [ ] Quad: frame tight, props good, antenna secure
- [ ] Radio/goggles batteries OK
- [ ] VTX channel set + **pit mode** until takeoff
- [ ] Arming switch verified; failsafe tested
- [ ] Marshal zones clear; spectators behind line
