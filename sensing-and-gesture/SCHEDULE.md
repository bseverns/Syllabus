# Sensing & Gesture (College, 14 Weeks) – Schedule

| Week | Title                                           | Focus                                                       |
|------|-------------------------------------------------|-------------------------------------------------------------|
| 1    | What Is Gesture? What Is Sensing?              | Definitions, examples, body-based warm-ups                  |
| 2    | Drawing Gesture                                 | Scores, diagrams, notations of movement                     |
| 3    | Bodies as Sensors                               | Proprioception, disability, low-tech sensing                |
| 4    | From Gesture to Data                            | Basic microcontrollers & IMU / simple sensors               |
| 5    | Cameras & Pose                                  | Webcam motion, pose estimation (conceptual/technical intro) |
| 6    | Mapping Gesture                                 | Mapping tables, thresholds, temporal patterns               |
| 7    | Gesture, Power, Access                          | Surveillance, race, disability, misrecognition              |
| 8    | Prototype 0 Crit                                | First gesture-driven prototype + critique                   |
| 9    | Systems of Gesture                              | System diagrams, plans vs situated action                   |
| 10   | Final Project Proposals                         | Pitching, scoping, and ethics review                        |
| 11   | Build Sprint I: Core Gesture Pipeline           | Data → interpretation → response                            |
| 12   | Build Sprint II: Choreography & Interface       | Staging interactions, signage, onboarding                   |
| 13   | Showing / Performance Night                     | Public or internal event, observation, logging              |
| 14   | Deinstallation, Documentation & Final Crit      | Final crit + documentation bundles                          |
