# Week 04 — Strong Shapes & Slicing Basics (Digital Factory)
**Time:** 90 min

### Goals
- See how walls, infill, and orientation affect strength/time.
- Slice a file in **UltiMaker / MakerBot Digital Factory** and read time/material estimates.

### Agenda
- **Warm-up (10):** Break-test a 3D-printed beam (teacher demos). Which is stronger and why?
- **Mini-lesson (15):** Digital Factory tour: layer height, walls, infill, supports. Class rule: ≤ 60 min prints.
- **Make (55):** Design **sturdy bookmark** (≤ 120×35×2–3 mm) *or* mini **bridge beam** (span test between books).
- **Queue (10):** Each student uploads STL to **Digital Factory** to view estimate; teacher finalizes.

### Deliverable
- `Firstname_Bookmark_v1.stl` or `Firstname_Beam_v1.stl`.
