# 3D Printing Course (Grades 3–5)

**Tools:** Tinkercad + MakerBot SKETCH printers managed via **UltiMaker / MakerBot Digital Factory**.  
**Schedule:** 11 weeks × 90 minutes (total 16.5 hours).

## Course Goals
- Learn the end-to-end pipeline: imagine → model → slice → print → evaluate → iterate.
- Practice measurement, scale, and spatial reasoning in millimeters.
- Use 3D printing safely, kindly, and ethically (attribution + classroom norms).
- Design with *someone else* in mind (capstone empathy project).

## Highlights
- Week 1: Nameplate tag (first win!)
- Week 2: Caliper cube + personalized key tag
- Week 3: Peg-and-hole tolerance toy or spinning top
- Week 4: Strong bookmark or mini “bridge beam” **+ slicing in Digital Factory**
- Week 5: Tiny Museum remix (with proper credit)
- Week 6: Useful-in-60-minutes challenge (time-aware design)
- Week 7: Articulated chain critter (clearances/orientation)
- Week 8: 2D→3D badge (SVG import)
- Week 9: Iteration round (improve and reprint)
- Weeks 10–11: Capstone: design for a partner (interview → prototype → print)

## Class Constraints (for equitable throughput)
- **Material:** PLA only. **Colors:** limited palette per week.
- **Per-item time budget:** target ≤ 60 min (use Fast‑Draft profile in Digital Factory).
- **Max footprint (class rule):** 120×120×100 mm (even if printer allows more).
- **Naming:** `W##_Firstname_Object_v#` (e.g., `W03_Avery_KeyTag_v2`).

## Accessibility & Equity
- Rotation on who prints first. Everyone gets a print by Week 2.
- Pair design sessions; solo reflection via design journal.
- Multiple ways to show understanding (drawings, talk‑throughs, builds).
