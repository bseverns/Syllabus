# Syllabus — Robotics & Vibe Coding — Level 2

**Format:** 8 × 2 hours (A/B blocks)  
**Prereq:** Level 1 or equivalent  •  **Max robots:** 12  •  **Env:** improvised lab

## Weekly Outline
1. **Calibration & Logging** — Build a quick logging rig; baseline noise; unit tests.
2. **Control Loops** — PWM shaping; PID-lite on encoders or line sensors.
3. **Sensor Fusion** — Complementary/EMA filters; outlier rejection.
4. **Path Behaviors** — Line/wall following; turn cues; recovery states.
5. **Comms & Sync** — IR/LED tempo beacons or radio; addressing and roles.
6. **Choreography Engine** — Presets, transitions, morphs; operator UI.
7. **Dress Rehearsal** — Fault injection; resilience drills; doc capture.
8. **Premiere** — Ensemble demo; reflection; teardown + retrospective.

## Assessment
- **Process (30%)**: logs, test plans, fixes.
- **Technical (35%)**: stable closed-loop behavior + comms.
- **Expression (20%)**: coherent choreography / vibe narrative.
- **Collaboration (10%)**: ensemble readiness.
- **Documentation (5%)**: short video + README of choices.
