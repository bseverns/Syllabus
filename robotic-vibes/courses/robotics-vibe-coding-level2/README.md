# Robotics & Vibe Coding — Level 2

**Duration:** 8 sessions × 2 hours • **Audience:** Level 1 grads / equivalent • **Max builds:** 12 robots

Level 2 deepens the practice: closed-loop control, sensor fusion, ensemble sync, and performance choreography. Students still select a **dialect path** (LEGO Spike / Arduino / MicroPython), with a bias toward Python/C for richer control.

## Learning Goals
- Calibrate and log sensors; reason about noise and drift.
- Build **closed-loop behaviors** (PID-lite) using encoders or line sensors.
- Fuse multiple sensors (e.g., IMU + distance) with simple filters.
- Coordinate **ensembles** via optical/IR/radio beacons and tempo syncing.
- Design and perform a choreographed demo; document with test plans.
