# Pacing Guide (8 × 2h)

Each session: **Block A (50–60)** concept/code; **Block B (50–60)** studio; **Transitions (10–20)** resets.

- **S1**: Logger + baseline metrics; visualize drift.
- **S2**: PID-lite scaffold; tune by ear/graph.
- **S3**: Complementary/EMA fusion; sanity tests.
- **S4**: State machine for pathing + recovery.
- **S5**: Sync beacons; address roles; tempo checks.
- **S6**: Performance presets; morphing; operator UI.
- **S7**: Fault drills; video capture; fix list.
- **S8**: Performance + retrospective.
