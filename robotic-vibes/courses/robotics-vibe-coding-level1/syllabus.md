# Syllabus — Robotics & Vibe Coding — Level 1

**Format:** 8 sessions × 2 hours (A/B blocks)  
**Max robots:** 12  •  **Environment:** improvised lab

## Overview
We treat robotics as an expressive medium. Each week: **Block A** (concept + code‑along), **Block B** (studio lab with feedback). Students select one **dialect path**:
- **LEGO Spike** (Scratch‑style blocks + Python option)
- **Arduino** (C/C++)
- **MicroPython/CircuitPython** (Raspberry Pi Pico)

## Weekly Outline
1. **Sensing the Room** — Safety, tool tour, inputs/outputs, first motion.
2. **Vibe Maps** — Mapping sensor → sound/light; debouncing + smoothing.
3. **Rhythm Engines** — Timers, thresholds, and arpeggios for motion/LEDs.
4. **Behaviors** — State machines; switching modes via buttons/gestures.
5. **Locomotion + Avoidance** — Simple navigation; obstacle response.
6. **Ensembles** — Pairing robots; call‑and‑response over light/sound.
7. **Dress Rehearsal** — Finishing mechanics; performance polish.
8. **Showtime** — Public mini‑demo; reflection + teardown.

## Assessment
- **Process (40%)**: notebooks, iteration, safe practice.
- **Technical (30%)**: working behaviors in chosen dialect.
- **Expression (20%)**: clarity of “vibe” mapping.
- **Collaboration (10%)**: teamwork, studio care.
