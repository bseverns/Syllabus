# Robotics & Vibe Coding — Level 1

**Duration:** 8 sessions × 2 hours • **Audience:** parent/child pairs or advanced HS • **Max builds:** 12 robots

This course blends robotics fundamentals with “vibe coding”: mapping motion and sensor data to sound, light, and expressive behaviors. Students choose a **dialect path** (LEGO Spike / Arduino / MicroPython) while sharing core ideas, demos, and studio time.

## Learning Goals
- Build and program a small robot that senses and responds to its environment.
- Translate sensor values into rhythmic/visual behaviors (“vibe coding”).
- Practice safe prototyping, iteration, and collaboration.
- Present a final mini‑performance or demo.
