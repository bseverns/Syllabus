# Student Guide

Welcome! You’ll build a small robot that responds to the world with motion, lights, and sound. Pick a **path** (LEGO Spike, Arduino, or MicroPython). We’ll learn core ideas together, then you’ll make it yours.

**Tips**
- Tweak one thing at a time; keep notes.
- Use the rubric as a map; process matters.
- Share tools; return bins as you found them.
