# Facilities for Improvised Labs

- **Power**: surge strips taped; cords managed; charging zone.
- **Tables/Floor**: low‑traffic test lane; obstacle course kit (cones/boxes).
- **Storage**: labeled bins per team; daily check‑in/out.
- **Audio**: keep SPL modest; use small amps; hearing safety.
- **Safety**: hot glue station with supervision; eye protection; first aid.
- **Cleanup**: 10‑minute teardown ritual; cable count; battery check.
