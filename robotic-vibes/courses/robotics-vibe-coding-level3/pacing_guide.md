# Pacing Guide (8 × 2h)

Each session: **Block A (50–60)** concept/code; **Block B (50–60)** studio; **Transitions (10–20)** resets.

- **S1**: Addressing, timebase, message schema; smoke tests.
- **S2**: Map/markers; correction loop; error logging.
- **S3**: Behavior Tree or advanced state machine; scene transitions.
- **S4**: Reliability patterns; RF policy; optical fallback beacons.
- **S5**: DMX/MIDI/OSC integration; cue tables; conductor console.
- **S6**: Rehearsal engine; operator UI; dashboard.
- **S7**: Tech run; incident drills; capture artifacts.
- **S8**: Premiere + retrospective.
