# Contributing

1. Fork the repo; create feature branches.
2. For docs, aim for clear, remixable Markdown. Keep student/teacher versions separate when needed.
3. Include checklists, safety notes, and rubrics for anything that touches physical kits or electricity.
4. If adding a course, follow the folder pattern in `/courses/`.
5. For assets (images, PDFs), prefer small, web‑safe formats; include source files when feasible.
