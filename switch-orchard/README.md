# Switch Orchard
**CV-controlled routing + stepped scanning** (AE Modular BRAEDBOARD)  
2-session lab workshop (90–120 min each)

This workshop builds a patchable **routing/switching module** around the **CD4051 analog switch**.
Students learn how **selection**, **addressing**, and **routing** become musical form.

Two modes (same hardware):
- **Manual router:** a knob selects which lane is active.
- **Scanner:** a clock advances the selection automatically (like a tiny sequencer for routing).

**IC count:** 2–4 (depending on options)
- **CD4051** (8-channel analog switch, the “orchard gate”)
- **CD40106** (optional: clean up a noisy clock and/or create a simple clock)
- **CD4017** (optional: step counter for scanning)
- **MCP602** (optional: input/output buffers to reduce loading and keep levels stable)
