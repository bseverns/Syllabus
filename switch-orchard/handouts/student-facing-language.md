# Switch Orchard — Student Guide

## What this module does
The CD4051 is a **chooser**.

It connects the common pin **Z** to exactly one of eight pins **X0–X7**.
Which one? That’s decided by three address lines:

- **A** (least significant bit)
- **B**
- **C** (most significant bit)

Together, A/B/C are like a 3-bit “address” that points to one lane.

## Two modes
### Manual router
Turn a knob to choose which lane is active.

### Scanner
A clock automatically steps the selection, so routing moves over time.

## What you can route
- **Audio** (for slicing / switching textures)
- **CV** (for “moving spotlight” modulation)
- **Triggers** (for distributing rhythms)
