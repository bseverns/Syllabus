# Key Terminology
- **Datum:** A reference plane/edge for measurements or constraints.
- **Overhang angle:** Angle from vertical where unsupported material appears.
- **Bridging:** Spanning a gap in mid-air; relies on cooling and limited sag.
- **Clearance fit / Interference fit:** Positive vs. negative allowance between parts.
- **Snap-fit:** Elastic latch feature designed to deflect and recover.
